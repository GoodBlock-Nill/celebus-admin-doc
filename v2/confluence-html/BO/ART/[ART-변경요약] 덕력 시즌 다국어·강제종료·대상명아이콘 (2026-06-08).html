1. 한 줄 요약

덕력 시즌·보상에 대한 개발팀 피드백 3건을 반영했습니다. ① 시즌명 다국어 ② 수동 [종료] = 강제 종료(취소·미지급) ③ 보상 구간에 대상명(다국어)·아이콘 추가.

세 변경 모두 BO 명세 · 프로토타입 · 앱 명세 전 계층에 정합했습니다.

2. 무엇이 바뀌었나 (Before → After)

#구분BeforeAfter
①시즌명단일 텍스트 1개한국어·영어·일본어 3언어(연·월 기준 3언어 자동 제안)
②수동 [종료] 의미모호(미정산 freeze)강제 종료(취소·미지급). 정상 지급은 자연 종료(자동 정산)만
②-1강제 종료 시 랭킹불명확스냅샷 보존·조회 가능(보상만 미지급)
③보상 구간(대상)대상 기준·값만+ 대상명(다국어) + 대상 아이콘(이미지)

3. 핵심 개념

시즌 종료 2종 구분 (②)

종료 종류트리거동작
자연 종료종료일 도달(말일 23:59)서버 자동 정산 = 랭킹 집계 + 보상 지급 + 종료
강제 종료운영자 [강제 종료](조기)보상 미지급·시즌 취소. 랭킹은 그 시점 스냅샷 보존·조회 가능, 신규 적립·소비는 다음 시즌 귀속

정상 보상 지급은 자연 종료(자동 정산)로만 발생. 강제 종료는 예외 취소 경로.

보상 구간 = 대상 + 상품 (③)

[보상 구간(대상)]  대상 기준(등수/퍼센트/등수범위) · 값
                   + 대상명(한/영/일)       ← 신규 (예: "최우수 팬")
                   + 대상 아이콘(이미지)     ← 신규 (구간마다 다른 아이콘)
   └ 보상 상품 N개 (배송/현장/BIVE/응모권/덕력)

4. 디자이너가 알아야 할 것

시즌 생성·수정 모달 ([ART-401-MD-SEASON])

  • 시즌명을 언어 전환 탭(한/영/일)으로 입력. 연·월 선택 시 3언어 템플릿 자동 제안(수정 가능), 미입력 언어 탭 빨간 점
  • BO 목록·상세·로그는 한국어 시즌명 표시, 앱은 로케일별

시즌 종료 모달 ([ART-401-MD-CLOSE])

  • 버튼/타이틀 강제 종료, 정책 3행: ① 보상 미지급(취소) ② 랭킹 스냅샷 보존·조회 가능 ③ 신규 적립·소비 다음 시즌 귀속 + "되돌릴 수 없음" 경고

보상 설정 (시즌 상세 [ART-401-DETAIL] §2.7)

  • 각 구간에 대상명 입력(한/영/일, 30자) + 대상 아이콘 업로드(정사각형 1:1·JPG·PNG·WebP·5MB 이하)
  • 보상 지급 내역·앱 보상 안내에 아이콘 + 대상명(로케일)으로 노출

앱 ([CEB-DUK-102]·[CEB-DUK-105])

  • 시즌 보상 구간 카드/달성 등급에 대상 아이콘 + 대상명 노출(BO 설정·로케일). 고정 "1위/TOP10" 표기 → BO 적용값 기준

🎨 디자인팀 액션 필요

  • 보상 대상 아이콘 기본 에셋(미설정 구간 대비) 필요 여부 — 현재 필수 업로드 정책

5. 개발자가 알아야 할 것

데이터 모델 (개념)

  • 시즌: 시즌명 → 다국어(KO/EN/JA), 종료 구분(자연/강제) closeType
  • 보상 구간(tier): 기존 대상 기준·값 + 대상명(KO/EN/JA) + 아이콘(이미지)
  • 지급 내역(payout): 정산 시점 snapshot에 대상명·아이콘 포함
