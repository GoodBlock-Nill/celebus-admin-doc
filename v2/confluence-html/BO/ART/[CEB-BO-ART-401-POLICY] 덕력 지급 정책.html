비고덕력 관리 메인의 네 번째 탭. 아티스트 그룹별 자동 적립 활동의 덕력 지급량·사용 여부를 설정한다. 신규 아티스트 생성 시 권장값으로 기본 정책 자동 생성.

0. 공통 정책 참조

참조 문서적용 범위
[CEB-000] 고도화 공통 정책§5.2 덕력 획득 경로(티어 매트릭스)·아티스트별 활동별 지급 정책
[CEB-BO-003] 아티스트(ART) 영역 가이드그룹 단위 정책, 권한 매트릭스
[CEB-BO-SYS-102] 권한 관리 그룹 설정권한 그룹별 읽기·쓰기 범위

1. 화면 목적

운영자가 아티스트 그룹별로 자동 적립 활동의 덕력 지급량과 사용 여부를 설정하는 화면이다. 백엔드는 지급 정책이 설정된 활동에만 덕력을 적립하므로, 본 화면에서 그룹별 정책을 관리한다.

  • 누가: 덕력 운영 권한이 있는 백오피스 관리자
  • 왜: 덕력은 아티스트 그룹별 별도 재화이며, 그룹마다 활동별 지급량을 다르게 운영할 수 있어야 함
  • 결과: 정책에 설정된 덕력값이 회원의 해당 활동 적립에 즉시 적용됨

미설정 상태 부재: 신규 아티스트 그룹 생성 시 권장값으로 기본 정책이 자동 생성되므로, 정책 부재로 인한 미지급은 발생하지 않는다([CEB-000] §5.2).

>

데일리 루프 단일 기준: 출석 체크·일일미션 완료·스트릭(7/14/21/28일)의 덕력 지급량은 본 정책이 단일 기준(SSOT)이다. 일일미션 관리([CEB-BO-DLY-101])는 미션 풀·하루 제시 수만 운영하며 덕력 지급량을 설정하지 않는다. 데일리 루프 미션은 계정 단위로 1일 1회 수행하되, 적립 덕력은 회원이 활동한 시점의 선택(현재) 아티스트 그룹 정책에 따라 지급된다([CEB-000] §5.2.2 귀속 매트릭스).

>

디지털 굿즈 획득 (등급별): BIVE 6등급(Normal/Event/Special/Wicked/Next/Final)별로 지급량·사용 여부를 설정한다(권장값 50/75/100/200/350/500). BIVE 민팅(획득) 시 발행된 BIVE의 등급을 조회해 해당 등급 덕력을 자동 적립하며, 귀속은 굿즈의 아티스트다([CEB-000] §5.2.4·§5.2.2). 미사용 등급은 해당 그룹에서 미지급.

>

SNS 공유 (기억 공유): SNS 공유 덕력은 기억저장소 기억 상세 공유 버튼 전용이다. 계정 기준 1일 1회(00:00 KST 초기화)·공유 버튼 탭 시 즉시 지급(외부 공유 완료 무관)이며, 귀속은 기억의 아티스트다([CEB-000] §5.2.3). 본 매트릭스에서는 그룹별 지급량(기본 25)·사용 여부만 설정한다.

>

응모권 사용 (래플 응모): 래플 응모 덕력은 사용한 응모권 1장 단위로 적립한다(지급 = 설정값 × 사용 응모권 수). 여러 장을 한 번에 응모하든, 한 장씩 나눠 여러 번 응모하든 사용한 응모권 수가 같으면 적립 덕력도 같다(분할·일괄 응모 무관). 귀속은 래플의 아티스트다. 본 매트릭스에서는 그룹별 1장당 지급량(기본 5)·사용 여부만 설정한다.

매트릭스 값 = 활동별 덕력 기본값이다. 동작은 활동의 입력 필드 유무로 갈린다.

- 콘텐츠 생성 시 덕력 입력 필드가 있는 활동(팬퀘스트·게임(프리딕션 마켓·트리비아)·에피소드 등): 생성 화면에서 이 기본값이 입력 필드에 자동 채워지고(prefill), 운영자가 콘텐츠별로 수정하면 입력한 값이 우선 지급된다. 기본값(본 정책)을 수정하면 이후 생성되는 콘텐츠에 새 기본값이 채워진다.

- 입력 필드가 없는 활동(출석·응모권·일일 미션·SNS 공유·기억저장소·디지털 굿즈·스트릭): 본 정책 값으로 직접 지급되며, 사용 안함 시 미지급. 기본값 수정 시 이후 적립부터 새 값 적용([CEB-000] §5.2).

2.4 시각적 스타일

  • 권장값과 다른 입력값은 강조 표시(예: 굵게 또는 색상)로 변경 인지
  • 사용 토글: 사용(초록) / 미사용(회색)
  • 빈 상태 없음 — 신규 아티스트도 권장값 기본 정책이 자동 생성되어 항상 19개 활동 행 노출

3. 화면 내 기능설명

운영자가 이 화면에서 할 수 있는 동작:

  1. 그룹 선택 — 정책을 설정할 아티스트 그룹 전환
  2. 지급 덕력 입력 — 활동별 덕력값 수정
  3. 사용 여부 토글 — 활동별 지급 사용/미사용 전환
  4. 권장값 적용 — 모든 활동을 권장값으로 일괄 채움
  5. 저장 — 변경 사항을 적용(저장 확인 모달 후 즉시 반영)

4. 규칙·로직

4.1 화면 진입 → 정책 표시

  1. 사이드바 [아티스트] > [덕력관리] > [덕력 지급 정책] 탭 진입
  2. 그룹 기본값(첫 활성 그룹)의 정책 매트릭스를 표시
  3. 그룹 전환 시 해당 그룹 정책으로 매트릭스 즉시 교체. 미저장 변경이 있으면 전환 전 확인

4.3 신규 아티스트 기본 정책 자동 생성

  1. 아티스트 그룹이 신규 생성되면 권장값으로 19개 활동 정책 행이 자동 생성된다(사용 여부 전부 ON)
  2. 따라서 '미설정' 상태가 존재하지 않으며, 운영자는 생성된 정책을 조정만 한다
  3. 기존 아티스트 그룹은 권장값 기본 정책으로 일괄 생성(백엔드 마이그레이션)

4.5 저장·적용

  1. [저장] 클릭 → 저장 확인 모달 → 확정 시 정책 저장
  2. 저장 즉시 회원 앱의 해당 활동 적립에 반영(이후 적립부터 적용, 소급 없음)
  3. "지급 정책이 저장되었습니다." 안내 + 마지막 수정 정보 갱신

4.6 권한별 동작

  • 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정에 따른다
  • 쓰기 권한 없으면 입력·토글·[저장]·[권장값 적용] 비활성(조회만)
  • 외부 협력사 권한자는 본인 매핑 소속사 산하 그룹 정책만 조회 가능(쓰기 불가)
