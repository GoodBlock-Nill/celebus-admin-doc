1. 화면 목적

기존 그룹의 정보를 수정하는 화면. 입력 항목·구성은 [CEB-BO-ART-201-Create] 그룹 생성과 동일하며, 진입 시 기존 값이 채워진다.

진입 경로

  • [CEB-BO-ART-301] 그룹 상세 (기본정보 탭) > [수정하기]
  • URL: /artists/groups/{id}/edit

2. UI 설명

2.1 상단 헤더

  • 타이틀: 그룹 수정
  • 우측 상단 액션: [취소하기] / [수정하기]
  • [수정하기]는 변경 사항이 없으면 비활성 상태이다.

4. 규칙·로직

4.1 권한

  • 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.

4.2 입력 검증

  • 그룹명·그룹 소개는 한국어·영어·일본어 모두 입력해야 한다. 수정 시에도 생성과 동일한 필수 검증을 적용해, 필수 항목을 비운 상태로는 저장할 수 없다.
  • 로고·대표이미지는 필수이다(교체만 가능, 비울 수 없음).
  • SNS·Homepage 입력값은 URL 형식을 검증한다.
  • 변경 사항이 있을 때만 [수정하기]가 활성화된다. 변경 판정 대상 = 그룹명·소개(언어별 텍스트)·로고·대표이미지·SNS/Homepage 중 하나라도 진입 시점 값과 달라진 경우.
