1. 한 줄 요약

출석 체크·일일미션 완료·스트릭의 덕력 지급량을 덕력 지급 정책([CEB-BO-ART-401-POLICY]) 단일 기준(SSOT) 으로 확정했습니다(일일미션 영역의 중복 보상값 입력 제거). 데일리 루프 덕력은 선택(현재) 아티스트 그룹 정책에 따라 적립됩니다. 또한 정책 매트릭스의 스트릭 활동을 7/14/30일 → 7/14/21/28일 4종으로 확장(21일 권장 750DUK 신설, 30일→28일)했습니다.

3. 핵심 개념

  • 덕력은 아티스트 그룹별 × 활동별 지급 정책으로 적립된다. 출석·일일미션·스트릭도 이 정책이 단일 기준이며, 일일미션 관리는 미션 풀·하루 제시 수만 운영한다.
  • 데일리 루프 미션은 계정 단위로 1일 1회 수행하되, 적립 덕력은 활동 시점 선택(현재) 아티스트 그룹 정책으로 귀속된다(귀속 매트릭스: 출석·일일미션·스트릭 = 선택 아티스트).
  • 정책 매트릭스 대상은 자동 적립 활동 10종(출석·응모권 사용·일일 미션·SNS 공유·기억저장소 업로드·디지털 굿즈 획득·스트릭 7/14/21/28). Quest 완료·게임 참여는 콘텐츠별 직접 입력으로 매트릭스 제외.
  • 스트릭은 28일(4주) 주기 순환. 7/14/21/28일 마일스톤 보너스는 매 주기 반복 지급.

4. 디자이너가 알아야 할 것

  • 덕력 지급 정책([CEB-BO-ART-401-POLICY]): 매트릭스 스트릭 행이 4개(스트릭 7일/14일/21일/28일)로 노출. [권장값 적용] 시 200/500/750/1,000·사용 ON 일괄 채움.
  • 일일미션 관리([CEB-BO-DLY-101]): 덕력 보상값 입력 UI 제거(하루 제시 미션 수만), 스트릭 섹션 읽기 전용 안내. "덕력 지급량은 지급 정책" 안내 노출.
  • 변경 적용 시점(소급 없음)·미사용 토글 등 지급 정책 화면 동작은 기존과 동일.

5. 개발자가 알아야 할 것

  • 출석·일일미션·스트릭 적립 덕력의 단일 기준 = 지급 정책(그룹 × 활동). 백엔드는 정책이 설정·사용 ON인 활동에만 적립.
  • 적립 귀속 = 활동 시점 선택(현재) 아티스트 그룹. 미사용 활동은 해당 그룹에서 미지급.
  • 스트릭 활동 키: streak_7·streak_14·streak_21(신설)·streak_28(구 streak_30 대체). 28일 주기 순환, 주기 내 1회 지급.
  • 프로토타입 정합: mock/duk.ts DUK_POLICY_ACTIVITIES 스트릭 4행(200/500/750/1000). PolicyTab은 매트릭스 자동 렌더(하드코딩 없음).
