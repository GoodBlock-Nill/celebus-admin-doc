1. 한 줄 요약

앱에 팬퀘스트(Quest/미션) 대표 이미지를 노출하는 화면이 없어, BO Quest 생성·수정·상세에서 대표 이미지 입력·표시를 제거했습니다.

⚠️ 에피소드 대표 이미지([CEB-BO-SQ-202], 앱 퀘스트 메인 카드에 노출)는 별개이며 그대로 유지합니다. 이번 제거 대상은 Quest(미션) 단위 대표 이미지뿐입니다.

2. 무엇이 바뀌었나 (Before → After)

구분BeforeAfter
Quest 생성 — 기본 정보타이틀·설명·유저 가이드 + 대표 이미지(필수 ★)타이틀·설명·유저 가이드 (대표 이미지 제거)
Quest 수정대표 이미지 수정/잠금 매트릭스 포함대표 이미지 항목 제거

게시/검증대표 이미지 등록이 [생성하기] 필수 조건필수 조건에서 제외

3. 왜 (배경)

  • 앱 퀘스트 메인([CEB-FQ-101]) 카드는 에피소드 대표 이미지(에피소드 단위)를 노출한다. 개별 Quest(미션)의 대표 이미지를 보여주는 앱 화면은 없다.
  • Quest 제출 화면([CEB-FQ-205])은 유저 가이드 + 인증샷 업로드만 표시하며, Quest 대표 이미지는 쓰지 않는다.
  • → 운영자가 노출되지 않는 이미지를 필수로 업로드해야 하는 불필요 입력이라 제거.

4. 디자이너가 알아야 할 것

  • Quest 생성/수정([SQ-302-CREATE]·[SQ-303-EDIT]): 기본 정보 섹션에서 대표 이미지 업로드 영역 삭제. (타이틀·설명·유저 가이드 다국어만)
  • Quest 상세([SQ-303]): 좌측 1:1 대표 이미지 카드 삭제 → Quest 정보 / 관리 정보 2열 레이아웃으로 단순화.
  • 에피소드 대표 이미지는 유지 — 에피소드 생성/수정([SQ-202])과 앱 카드 노출은 변동 없음.

5. 개발자가 알아야 할 것

  • 팬퀘스트(Quest) 데이터 모델에서 대표 이미지 필드 제거(생성·수정·상세·목록 무관).
  • 보존: 에피소드 그룹 대표 이미지(SQ-101/201), Quest 제출 인증샷(유저 업로드)은 그대로.
  • 프로토타입 정합:
    • _components/QuestForm.tsx: imageSrc 필드·업로드 UI·필수 검증 제거
    • fanquest/[id]/page.tsx: 대표 이미지 카드 제거 → 2열 그리드
    • fanquest/[id]/edit/page.tsx: 초기값 imageSrc 제거
    • mock/fanquest.ts: QuestDetail.imageSrc 타입·시드 제거 (Raffle imageUrl·QuestSubmission.imageSrc는 유지)
