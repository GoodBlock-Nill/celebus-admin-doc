1. 한 줄 요약

에피소드 내 미션 중 예측 마켓(PM)·서바이벌 트리비아(ST) 유형의 보상 설정을 덕력만으로 축소했습니다. 기존 응모권 입력 + BIVE 토글(자동 민팅)을 PM/ST 미션에서 제거했습니다.

⚠️ 팬퀘스트 유형 미션(보상은 매핑 Quest 상속 + 미션 고유 BIVE 토글)과 메인 에피소드 완료 보상(응모권+덕력+BIVE)은 별개 계층으로 변동 없음.

2. 무엇이 바뀌었나 (Before → After)

미션 유형BeforeAfter
예측 마켓 / 서바이벌 트리비아응모권 + 덕력 + BIVE 토글(+민팅 캠페인)덕력만 (응모권·BIVE 제거)
팬퀘스트매핑 Quest 보상 상속 + 미션 고유 BIVE 토글불변
메인 에피소드 완료 보상응모권 + 덕력 + BIVE (에피소드 레벨)불변

3. 핵심 개념

  • PM/ST 미션은 외부 콘텐츠를 참조하지 않고 보상을 직접 입력하는데, 이 직접 입력 보상을 덕력 1종으로 단순화.
  • BIVE 자동 민팅은 PM/ST 미션 경로에서 제거 — 향후 PM/ST 달성 회원에게 NFT가 필요하면 메인 에피소드 완료 보상 또는 팬퀘스트 경로 활용(§7 Open Item).
  • 진행중(ACTIVE)+PM/ST 수정 잠금(덕력도 진행중엔 read-only, DRAFT에서만 수정) 정책은 그대로 유지 — 이번 변경은 "어떤 보상 필드가 존재하는가"만 축소.

4. 디자이너가 알아야 할 것

  • 미션 추가([SQ-204-CREATE])·수정([SQ-204-EDIT]): PM/ST 보상 섹션 = 덕력 입력 1개만. 응모권 입력란·BIVE 보상 토글/민팅 캠페인 드롭다운 삭제.
  • 미션 상세([SQ-204]): PM/ST는 기본 정보 카드에 덕력 보상만 표시(응모권 행 숨김), BIVE 보상 카드 미노출(단일 컬럼). 팬퀘스트는 기존대로 응모권·BIVE 표시.
  • 에피소드 상세 미션 카드: PM/ST 카드에서 응모권·BIVE 행 숨김, 덕력만.

5. 개발자가 알아야 할 것

  • PM/ST 미션 보상 데이터: 응모권·BIVE·민팅 캠페인 입력 제거. 덕력만.
  • 검증: PM/ST 보상 검증은 덕력(≥0)·완료 조건만. 응모권·BIVE ON 민팅 검증 제거.
  • 팬퀘스트 미션의 미션 고유 BIVE 토글은 유지(수정 화면 §2-3).
  • 프로토타입 정합:
    • quests/create/page.tsx: PM/ST 보상 섹션 응모권·BIVE 블록 제거(덕력만), 검증·상태(rewardEntryTicket·biveRewardYn·mintingEventId·MINTING_EVENT_OPTIONS) 제거, 요약 문구 정정
    • quests/[qid]/edit/page.tsx: PM/ST 응모권 제거(덕력만), BIVE 섹션을 isFanQuest 한정으로
    • quests/[qid]/page.tsx(상세): isFanQuest 조건부 — PM/ST는 덕력만, BIVE 카드·그리드 단일화
