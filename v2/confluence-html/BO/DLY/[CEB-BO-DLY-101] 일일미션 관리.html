1. 화면 목적

운영자가 회원 데일리 루프(출석 체크·일일미션·연속 출석 스트릭)를 운영하는 단일 페이지. 출석·일일미션·스트릭 보너스의 보상값을 조정하고, 일일미션 미션 풀을 추가·수정·삭제·사용여부 전환한다. 회원 대면 동작은 앱 [CEB-FQ-501]에서 이뤄지며, 본 화면은 그 운영 설정만 담당한다.

데일리 루프는 계정 단위 기능이므로 아티스트 구분 없이 모든 회원에게 동일하게 적용된다.

진입 경로

  • 사이드 메뉴 > 일일미션

2. UI 설명

2.1 상단 영역

  • Breadcrumb: 일일미션 > 일일미션 관리
  • 화면 타이틀: 일일미션 관리
  • 안내 문구: 출석·일일미션·연속 출석(스트릭) 보상과 미션 풀을 운영한다는 설명
  • 자정 리셋 안내 박스: "1일 기준 KST 자정(00:00~23:59:59). 매일 자정에 출석·일일미션 진행 상태가 리셋되며 미션 풀에서 그날 제시할 미션이 자동 선택됩니다."

본 페이지는 아래 3개 섹션으로 구성된다: 일일미션 설정 · 미션 풀 · 연속 출석(스트릭) 보너스.

2.2 일일미션 설정 (섹션 1)

운영자가 입력하는 숫자 설정 3종으로 구성된다.

항목타입단위설명

출석 체크 보상숫자 입력덕력앱 진입 시 1일 1회 지급
일일미션 전체 완료 보상숫자 입력덕력그날 제시된 미션을 모두 완료하면 일괄 지급
  • 수급 경고: 하루 제시 미션 수가 현재 사용 중인 미션 수보다 크면 입력 필드 하단에 인라인 경고를 노출한다 — "사용 중인 미션이 N건이라 매일 최대 N건만 제시됩니다." (저장은 차단하지 않음)

2.4 연속 출석(스트릭) 보너스 (섹션 3)

  • 안내 문구: 출석을 연속으로 달성한 마일스톤에서 보너스 지급. 마일스톤(연속 일수)은 정책 고정이며 보상값만 조정 가능. 스트릭은 30일 주기로 순환하여, 30일 도달 시 보너스 지급 후 다음날 1일차로 초기화되어 주기마다 반복된다(출석이 하루라도 끊겨도 0으로 초기화).
  • 마일스톤 3종(연속 7일 / 14일 / 30일) 각각의 보상값을 숫자 입력(덕력)으로 편집한다. 연속 일수는 변경할 수 없다(30일 주기마다 반복 지급).

2.5 변경사항 저장

  • 섹션 1(일일미션 설정)과 섹션 3(스트릭 보너스)의 변경은 페이지 하단 [변경사항 저장] 버튼으로 일괄 커밋한다.
  • 변경 사항이 없거나 입력값이 유효하지 않으면 버튼은 비활성이다.
  • 클릭 시 [변경 내용 요약]을 담은 저장 확인 동작을 거친 뒤 반영된다(§3). 보상값을 0으로 변경한 항목이 있으면 요약에 0 지급 안내를 함께 노출한다.
  • 미션 풀(섹션 2)의 추가·수정·삭제·사용여부 전환은 [변경사항 저장]과 무관하게 각 액션 시점에 즉시 반영된다.
  • 미저장 이탈 가드: 섹션 1·3에 저장하지 않은 변경이 있는 상태에서 화면을 벗어나려 하면 "저장하지 않은 변경사항이 있습니다" 이탈 확인을 노출한다.

시각적 스타일은 프로토타입 참조

4. 규칙·로직

4.1 권한

  • 권한 그룹별 읽기·쓰기 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
  • 쓰기 권한이 없으면 입력·토글·버튼이 비활성 또는 미노출된다.

4.2 보상값

  • 출석·일일미션·스트릭 보상값은 운영자가 자유롭게 변경할 수 있다(권장 기본: 출석 5 덕력 / 일일미션 일괄 25 덕력 / 스트릭 7·14·30일 = 200·500·1,000 덕력).
  • 아티스트별 덕력 지급량 SSOT: 출석·일일미션·스트릭의 아티스트 그룹별 덕력 지급량·사용 여부는 [CEB-BO-ART-401-POLICY] 덕력 지급 정책을 단일 기준으로 한다([CEB-000] §5.2). 본 화면은 일일미션 풀·하루 제시 수 운영을 담당하며, 그룹별 지급량 설정은 지급 정책 화면에서 수행한다(전역 단일값 운영 시 기존 보상값 입력 사용 — 아티스트별 정책 일원화 범위는 별도 정합).
  • 보상 티어·구조 자체의 변경은 [CEB-000] 공통 정책 개정 사항이다.
  • 변경 적용 시점(소급 없음): 보상값·스트릭 보너스 변경은 적용 이후 적립부터 반영된다. 변경 이전에 당일 이미 지급된 출석·일일미션 일괄·스트릭 마일스톤 보상은 소급 변경·재계산되지 않는다([CEB-000] §5.2.1 "즉시 적립은 이벤트 발생 시점 기준" 정합).
  • 보상값 0 입력: 출석·일일미션 보상을 0으로 저장하면 해당 활동은 보상 없이 동작한다. 저장 확인 단계에서 0 지급 안내를 노출한다.

4.3 미션 풀·선택 규칙

  • 미션 풀은 페이지 방문형 미션으로 구성되며, 각 미션은 이동 대상 앱 화면을 1개 가진다. 완료 조건은 해당 화면 1회 진입이다.
  • 같은 이동 대상은 미션 풀에서 중복 등록할 수 없다(미션 풀 8종은 서로 다른 대상이 원칙). 중복 검증은 [CEB-BO-DLY-101-MD-MISSION]에서 수행한다.
  • 미션 선택은 시스템 자동이다. 매일 사용 중인 미션 중 설정 개수만큼 자동 선택하며, 전일과 중복을 피하고 당일 제시 미션은 서로 다르게 선택한다. 이동 대상이 준비 중(Coming Soon)인 미션은 제외하며, 제시 가능한 미션이 0건이면 앱에서 일일미션 카드가 숨겨지고 출석 체크만 노출된다.
  • 운영자는 미션 풀 구성(추가·수정·삭제·사용여부)과 하루 제시 개수만 관리하며, 그날의 개별 미션을 직접 지정하지는 않는다.
  • 이동 대상이 준비 중(Coming Soon)인 화면도 미션으로 등록할 수 있으나, 앱 노출 전까지는 미션 선택에서 자동 제외된다. 추가·수정 모달에서 준비 중 대상에 "준비 중" 표시를 노출한다([CEB-BO-DLY-101-MD-MISSION]).

4.3.1 당일 배정 미션의 삭제·수정 처리 (소급 없음)

  • 그날 제시할 미션은 자정(00:00 KST)에 배정된다. 운영자가 당일 도중 미션을 삭제하거나 이동 대상을 수정해도, 이미 당일 배정·진행 중인 회원의 미션은 그대로 유지되며 완료로 인정된다(당일분 보존).
  • 삭제·이동 대상 변경은 다음날 자정 재선택부터 반영된다. 미션명·설명 등 표시 정보 수정은 회원 화면에 즉시 반영될 수 있으나, 배정 자체는 당일 유지된다.

4.3.2 미션 수급 정합 경고

  • 하루 제시 미션 수 > 사용 중인 미션 수인 경우, 본 화면에 인라인 경고를 노출한다(앱은 가능 범위 내에서만 제시). 저장은 차단하지 않는다(운영자 의도 존중).
  • 사용여부 미사용 전환·삭제로 사용 중인 미션이 0건이 되면 앱 일일미션 카드가 숨겨지므로, 해당 액션 전에 확인을 요구한다.
