1. 한 줄 요약

일일미션 연속 출석 스트릭을 30일 주기로 순환하는 구조로 변경했습니다. 마일스톤은 7/14/30일 3종이며, 30일 도달(주기 완료) 시 보너스 지급 후 다음날 1일차로 초기화되어 새 주기를 시작합니다. 7/14/30일 보너스는 매 30일 주기마다 반복 지급됩니다.

⚠️ 기존 정책: 무한 누적 + 100일(5,000덕력) 최종 마일스톤 + 각 보너스 평생 1회. → 폐기.

3. 핵심 개념

  • 스트릭은 30일 단위 순환 루프다. 1일차부터 누적해 7·14·30일 마일스톤에서 보너스를 받고, 30일째 보너스 수령 후 다음날(31일째 출석)이 새 주기의 1일차가 된다.
  • 연속 출석이 유지되는 한 주기는 계속 반복되며, 매 주기마다 7/14/30일 보너스를 다시 받을 수 있다(지속 인센티브).
  • 초기화 트리거 2가지: ① 출석 하루라도 끊김 → 0으로 초기화 ② 30일 주기 완료 → 다음날 1일차로 재시작.
  • 마일스톤(연속 일수)은 정책 고정이며, 운영자는 각 마일스톤 보상값(덕력)만 조정한다.

4. 디자이너가 알아야 할 것

  • 앱 일일 미션([CEB-FQ-501]) §2.4 스트릭:
    • 마일스톤 라벨·프로그레스: 7/14/30 (100 제거). 프로그레스 바는 0→30일을 반복 순환.
    • 30일 도달: 30일 보너스 지급 후 다음날 프로그레스 바·마일스톤 ✅ 표시가 1일차로 재시작(기존 "100일 이후 숨김" 대체).
    • 스트릭 보너스 가로 나열: 3개(7일 / 14일 / 30일), 30일 주기마다 반복.
    • 보너스 축하 모달: 7/14/30 도달 시 노출(매 주기 반복).
  • BO 일일미션 관리([CEB-BO-DLY-101]) §2.4: 보상값 입력 카드 3개(100일 입력칸 제거). 그리드 4열 → 3열.

5. 개발자가 알아야 할 것

  • 스트릭 카운터는 30일 주기로 순환: day ∈ [1..30]. 30일 보너스 지급 직후, 다음 출석일에 day=1로 리셋(연속 유지 시).
  • 마일스톤 보너스(7/14/30일)는 주기마다 반복 지급 — "평생 1회" 제약 제거. 주기 카운트/회차 식별이 필요할 수 있음(중복 지급 방지는 주기 내 1회 기준).
  • 초기화 조건: (a) 출석 미완료일 발생 → day=0, (b) 30일 주기 완료 → 다음날 day=1.
  • 보상값은 BO 설정값(권장 200/500/1,000). 변경 적용 시점(소급 없음) 원칙 유지.
  • 프로토타입 정합:
    • mock/dailyMission.ts: streakMilestones = 7/14/30 3종(100 제거). 주석에 30일 주기 반복 명시.
    • daily-missions/page.tsx: 스트릭 안내 문구를 주기 순환으로, 보상값 그리드 4열 → 3열.
