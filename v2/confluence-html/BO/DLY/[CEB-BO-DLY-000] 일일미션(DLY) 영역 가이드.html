비고데일리 루프(출석·일일미션·스트릭)의 백오피스 운영 영역. 앱 [CEB-FQ-501] 일일 미션(유저 대면명 "오늘의 할 일")의 미션 풀·보상값을 관리한다. 사이드 메뉴 [일일미션] 진입. 계정 단위 기능(아티스트 무관)

1. 개요

일일미션(DLY) 영역은 회원의 데일리 루프(출석 체크 · 오늘의 일일미션 · 연속 출석 스트릭)를 운영하는 백오피스 영역이다. 운영자는 미션 풀을 구성하고 출석·일일미션·스트릭 보너스의 보상값을 조정한다. 회원 대면 동작은 앱 [CEB-FQ-501] 일일 미션(유저 대면명 "오늘의 할 일")에서 이뤄지며, 백오피스는 그 운영 설정만 담당한다.

데일리 루프는 계정 단위 기능으로, 아티스트 구분 없이 모든 회원에게 동일하게 적용된다(출석·일일미션·스트릭 모두 계정당 1개).

2.2 완료 처리 규칙

  • 미션 추가·수정·삭제, 사용여부 전환, 설정 저장 등 액션 완료는 토스트로 안내한다.
  • 액션 전(前) 확인이 필요한 동작만 확인 모달을 둔다: 미션 삭제 확인, 설정(보상값·스트릭) 저장 확인.

3. 권한

  • 화면별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
  • 미션 풀 추가·수정·삭제·사용여부 전환, 보상값·스트릭 보너스 저장은 쓰기 권한 보유 그룹만 수행한다.

4. 영역 고유 정책

4.1 데일리 루프 구성

구성설명단위
출석 체크앱 진입 시 1일 1회 출석. 스트릭 카운트의 기준계정당 1개
일일미션미션 풀에서 매일 자동 선택해 제시. 모두 완료 시 일괄 보상계정당 1세트

4.2 보상 정책

데일리 루프 보상의 단일 기준은 [CEB-000] 공통 정책 §5.2·§6이다. 본 영역은 그중 보상값을 운영자가 조정하는 화면을 제공한다.

항목권장값(기본)운영자 변경
출석 체크 보상5 덕력가능
일일미션 전체 완료 보상25 덕력 (모두 완료 시 일괄)가능
스트릭 보너스연속 7일 200 덕력 / 14일 500 덕력 / 30일 1,000 덕력 (30일 주기마다 반복 지급)가능
  • 보상값은 권장 기본값이며 운영자가 자유롭게 변경할 수 있다.
  • 보상 티어·구조 자체의 변경은 백오피스 설정이 아니라 [CEB-000] 공통 정책 개정 사항이다.
  • 변경 적용 시점(소급 없음): 보상값·스트릭 변경은 적용 이후 적립부터 반영되며, 변경 이전에 당일 이미 지급된 보상은 소급 변경·재계산되지 않는다([CEB-000] §5.2.1 정합).

4.3 미션 풀·선택 규칙

  • 미션 풀은 페이지 방문형 미션으로 구성된다. 각 미션은 회원이 누르면 이동하는 앱 화면(이동 대상)을 가지며, 해당 화면에 1회 진입하면 완료 처리된다.
  • 기본 미션 풀 8종: V01D 페이지 방문 · 게임존 방문 · 기억저장소 방문 · 덕력 랭킹 확인 · 래플 확인 · 컬렉션 확인 · 서포트 이벤트 확인 · 아티스트 정보 확인.
  • 미션 선택은 시스템 자동이다(운영자 비설정). 운영자는 미션 풀 구성(추가·수정·삭제·사용여부)과 하루 제시 개수만 관리한다.
선택 규칙설명
선택 방식사용 중인 미션 풀에서 매일 설정한 개수만큼(현 2건) 시스템이 자동 선택
중복 방지전일과 동일 미션 연속 선택 회피. 당일 제시 미션은 서로 다르게 선택
미오픈 서비스이동 대상 서비스가 준비 중(Coming Soon)이면 선택에서 제외(미션 등록은 가능, 노출 전까지 미작동)
미션 0건제외 후 제시 가능한 미션이 0건이면 일일미션 카드를 숨기고 출석 체크만 노출
당일 배정 보존미션은 자정 배정. 운영자가 당일 미션을 삭제·이동 대상 수정해도 당일 배정·진행 중인 회원 미션은 유지·완료 인정하며, 변경은 다음날 자정 재선택부터 반영(소급 없음)
수급 정합하루 제시 수 > 사용 미션 수면 가능 범위만 제시. 운영 화면([CEB-BO-DLY-101])에서 수급 경고·0건화 확인을 제공

4.4 시간 기준

  • 하루 기준은 KST 자정(00:00 ~ 23:59:59)이다.
  • 매일 00:00 KST에 출석·일일미션 진행 상태가 리셋되고, 그날 제시할 미션이 미션 풀에서 자동 선택된다.
  • 스트릭은 출석 체크 완료를 기준으로 누적되며, 출석이 하루라도 끊기면 연속 일수가 0으로 초기화된다. 또한 30일 주기로 순환하여, 30일 도달(주기 완료) 시 30일 보너스 지급 후 다음날 1일차로 재시작한다(연속 출석 유지 시 주기 반복). 스트릭은 시즌 초기화와 무관하게 유지된다.
