1. 화면 목적

운영자가 일일미션 풀의 미션 1건을 추가하거나 수정하는 입력 모달. 미션명(한국어·영어·일본어)·설명(선택)·이동 대상·사용여부를 입력한다. 추가·수정 모드는 동일한 입력 폼을 공유하며, 수정 모드는 기존 값을 채운 채로 시작한다.

  • 누가: 일일미션 쓰기 권한이 있는 백오피스 관리자
  • 왜: 데일리 루프에서 회원에게 제시할 페이지 방문형 미션을 운영하기 위해
  • 결과: 미션 풀에 미션 1건이 추가되거나 기존 미션이 갱신된다

진입 경로

  • [CEB-BO-DLY-101] 일일미션 관리 > [미션 추가] (추가 모드)
  • [CEB-BO-DLY-101] 일일미션 관리 > 미션 행 [수정] (수정 모드)

4. 규칙·로직

4.1 권한

  • 권한 그룹별 읽기·쓰기 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
  • 쓰기 권한이 없으면 리스트의 [미션 추가]·[수정]이 미노출되므로 본 모달은 호출되지 않는다.

4.2 입력 규칙

  • 미션명은 한국어·영어·일본어 세 언어를 모두 입력해야 [추가하기]/[저장하기]가 활성화된다.
  • 이동 대상은 필수이며, 같은 이동 대상을 쓰는 미션이 이미 존재하면 선택할 수 없다(미션 풀 중복 금지). 수정 모드에서 자기 자신은 중복 대상에서 제외한다.
  • 설명은 선택이며 미입력 시 앱에서 미션명만 노출된다.
  • 완료 조건(이동 대상 1회 진입)은 시스템 고정이며 본 모달에서 설정하지 않는다.
  • 준비 중(Coming Soon) 대상도 선택·저장할 수 있으나(사전 등록), 앱 노출 전까지 매일 미션 선택에서 자동 제외된다. 선택 시 인라인 안내를 노출한다.
  • 이동 대상 수정으로 대상이 바뀌어도, 당일 이미 배정·진행 중인 회원의 미션은 유지되며 변경은 다음날 자정 재선택부터 반영된다([CEB-BO-DLY-101] §4.3.1).
