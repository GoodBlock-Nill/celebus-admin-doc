1. 화면 목적

운영자가 일일미션 풀에서 미션 1건을 삭제하기 전 확인하는 모달. 삭제는 되돌릴 수 없으므로 대상 미션을 명시하고 확인을 받는다.

진입 경로

  • [CEB-BO-DLY-101] 일일미션 관리 > 미션 행 [삭제]

2. UI 설명

2.1 모달 레이아웃

┌─────────────────────────────────────────────┐
│  미션을 삭제하시겠어요?                       │
├─────────────────────────────────────────────┤
│  '게임존 방문' 미션을 미션 풀에서 삭제합니다. │
│  삭제 후에는 그날의 미션 선택 대상에서        │
│  제외됩니다.                                  │
├─────────────────────────────────────────────┤

└─────────────────────────────────────────────┘

3. 화면 내 기능설명

요소동작
[삭제하기]미션 풀에서 해당 미션 제거 + 모달 닫기 + 완료 토스트(§5)
[취소하기] / [X] / 외부 클릭삭제 취소 + 모달 닫기 (미션 유지)

4. 규칙·로직

4.1 권한

  • 권한 그룹별 삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.

4.2 삭제 규칙

  • 삭제된 미션은 미션 풀에서 제거되어 이후 미션 선택 대상에서 제외된다.
  • 일시적으로 노출을 멈추려는 경우에는 삭제 대신 사용여부를 미사용으로 전환하는 것을 권장한다(미션 풀에 보존).

5. 검증·예외 상황

상황처리·문구
삭제 성공Toast (Success): "일일미션이 삭제되었습니다." → 모달 닫기 + 미션 풀에서 제거
삭제 실패Toast (Error): "삭제에 실패했습니다." (모달 유지)
