1. 화면 목적

운영자가 집행중 이벤트의 결과물(결과 메시지·사진·영상)을 확정하고 완료(완료 전환) 처리하는 입력+확인 모달이다. 완료 시 결과물이 회원 앱 [CEB-DUK-201]에 공개되고 응원 회원에게 결과물 알림이 발송된다.

  • 누가: 서포트 운영 권한이 있는 백오피스 관리자
  • 왜: 완료는 결과물 공개·회원 알림을 유발하는 비가역 전환이므로, 결과물 완성도를 확인하고 확정 받아야 함
  • 결과: 이벤트 상태가 "집행중" → "완료"로 전환되고, 결과물이 공개되며 회원에게 알림이 발송됨

2.2 노출 조건

  • [CEB-BO-SUP-205] 결과물·반환 탭에서 결과물을 입력한 상태로, 헤더 [결과물 등록·완료] 클릭 시 노출.
  • 집행중 상태에서만 [결과물 등록·완료] 버튼이 노출되므로 본 모달도 집행중에서만 호출된다.
  • 결과물·반환 탭에서 입력한 결과 메시지·사진·영상이 본 모달에 prefill되며, 모달에서도 보강·수정할 수 있다.

2.4 푸터

액션동작
[취소]모달 닫기. 입력값은 결과물·반환 탭에 유지(임시 보관). 완료 전환 안 함
[등록하고 완료]Primary 색상. 검증 통과 시 결과물 확정 + 집행중 → 완료 전환 + 알림 발송. 검증 실패 시 첫 오류 필드로 포커스

3. 기능 설명

  1. 결과 메시지 입력 — 한국어/영어/일본어 결과 메시지 작성·보강
  2. 사진·영상 등록 — 최소 1장~최대 10장
  3. 완료 확정 — [등록하고 완료]로 결과물 공개 + 완료 전환 + 알림 발송
  4. 취소 — [취소]/[X]/외부 클릭으로 모달 닫고 집행중 유지

4. 로직·플로우

4.1 모달 진입

  1. 결과물·반환 탭에서 결과 메시지·사진·영상 입력
  2. 헤더 [결과물 등록·완료] 클릭
  3. 본 모달 열림. 탭 입력값이 prefill됨

4.2 입력 → 검증 → 완료

  1. 결과 메시지(다국어)·사진·영상 보강·수정
  2. [등록하고 완료] 클릭 시 검증(§5.1):
    • 결과 메시지 한국어/영어/일본어 모두 입력
    • 사진·영상 최소 1장
    • 형식·용량·동영상 길이 위반 없음
  3. 검증 통과 시:
    • 결과물 확정 (회원 앱 공개)
    • 상태 "집행중" → "완료" 전환
    • 응원 회원에게 결과물 알림 발송
    • 모달 닫기
    • 토스트 "결과물을 등록하고 완료 처리했습니다."
    • 상세 화면 자동 갱신 (상태 배지·결과물 읽기 전용 전환, 헤더 액션 없음)
    • 활동 로그 기록
  4. 검증 실패 시:
    • 첫 오류 필드로 포커스 이동
    • 인라인 에러 메시지 노출 + 완료 차단

4.3 취소

  1. [취소] 또는 모달 외부 클릭 또는 [X] 클릭
  2. 모달 닫기. 입력값은 결과물·반환 탭에 임시 유지. 집행중 상태 유지

5. 검증·예외 상황

5.1 입력 검증

항목룰
결과 메시지 (다국어)한국어/영어/일본어 모두 필수, 각 200자 이하. 한 언어라도 비면 완료 차단
결과 사진·영상최소 1장 필수, 최대 10장. 0장이면 완료 차단
매체 형식·용량·동영상 길이[CEB-BO-000] 미디어 정책 준수 (위반 파일 업로드 거부)

5.2 인라인 에러 메시지

상황메시지
결과 메시지 다국어 미입력"결과 메시지를 한국어·영어·일본어 모두 입력해주세요."
결과 메시지 200자 초과입력 차단 + "200자 이하로 입력하세요."
사진·영상 0장"결과 사진·영상을 최소 1장 등록해주세요."
형식·용량·길이 초과"허용되지 않는 파일입니다." (업로드 거부)

5.3 사전 조건·경합

  • 완료 처리 가능한 이벤트는 "집행중" 상태만 가능.
  • 처리 시점 상태가 집행중이 아니면(경합으로 이미 취소/종료됨) 서버가 거부하고 "이미 상태가 변경되었습니다. 새로고침 후 다시 시도하세요." 토스트로 안내한다([CEB-BO-SUP-201] §4.2).

5.4 권한별 동작

  • 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정에 따른다.
  • 쓰기 권한이 없거나 외부 아티스트 계정이면 [결과물 등록·완료] 버튼이 미노출이므로 본 모달은 호출되지 않는다.

5.5 활동 로그

동작로그 메시지
결과물 등록·완료서포트 이벤트 '{이벤트명}'의 결과물을 등록하고 완료 처리했습니다. (회원 알림 발송)
