1. 화면 목적

[CEB-BO-SUP-203] 응원자 내역 탭에서 회원 행을 클릭했을 때, 해당 회원이 동일 이벤트에 응원한 회차별 개별 내역(회차·응원량·응원 시점)을 표시하는 조회 전용 모달이다. 회원별 목록은 합산만 보여주므로, 다회 응원 회원의 응원 흐름을 운영자가 추적할 수 있게 한다.

  • 누가: 서포트 운영·조회 권한이 있는 백오피스 관리자
  • 왜: 회원이 동일 이벤트에 여러 번 응원할 수 있어(누적 응원) 회차별 추적이 필요
  • 결과: 회차별 응원량·시점과 누적 합계, 반환 상태이면 전액 반환 완료 정보를 확인

3. 기능 설명

운영자가 이 모달에서 할 수 있는 동작:

  1. 회차별 응원 내역 확인 — 회차·응원량·응원 시점 조회
  2. 누적 합계 확인 — 회원의 총 응원 덕력
  3. 반환 상태 확인 — 반환 이벤트이면 전액 반환 완료·반환 시점 표기
  4. 닫기 — [닫기]/[X]/외부 클릭으로 모달 종료

본 모달은 조회 전용으로 입력·저장 동작이 없다.

4. 로직·플로우

4.1 모달 진입

  1. 응원자 내역 탭에서 회원 행 클릭
  2. 본 모달 열림
  3. 해당 회원의 회차별 응원 내역을 응원 시점 오름차순으로 로드
  4. 헤더에 닉네임·총 회수·누적 덕력 표시. 이벤트가 미달성종료·집행취소이거나 회원 개별 반환 처리된 경우 "전액 반환 완료 ({반환 시점})" 추가 표기

4.2 닫기

  1. [닫기] 또는 [X] 또는 모달 외부 클릭
  2. 모달 닫기. 응원자 내역 탭 유지
