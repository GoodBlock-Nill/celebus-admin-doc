1. 화면 목적

소식·일정 수정 중 [삭제]를 눌렀을 때, 삭제한 콘텐츠는 복구할 수 없음을 안내하고 삭제 여부를 확인받는 모달. [삭제]는 수정 화면에만 노출되는 액션이다(작성 화면 없음).

2. UI 설명

요소내용
제목삭제할까요?
본문"삭제한 콘텐츠는 복구할 수 없습니다."
버튼[다시 돌아가기] / [삭제]

시각적 스타일은 프로토타입 참조

3. 기능 설명

버튼동작
다시 돌아가기모달 닫고 수정 화면 유지 (삭제 안 함)
삭제영구 삭제 → 완료 토스트 → [CEB-BO-INF-101] 리스트로 이동

4. 로직·플로우

  • [CEB-BO-INF-201-EDIT] [삭제] → 본 모달 → [삭제] 시 영구 삭제.
  • 삭제 성공 시 완료 토스트: "{타입} '{제목}'을(를) 삭제했습니다." 후 리스트로 복귀한다.
  • 수정 중 입력한 미저장 변경 사항도 삭제와 함께 사라지며, 삭제는 복구할 수 없다.

5. 검증·예외 상황

  • 본 모달은 수정 화면([CEB-BO-INF-201-EDIT])에서만 진입한다(작성 화면에는 [삭제]가 없음).
  • 삭제 실패 시 Toast (Error): "저장에 실패했습니다." (수정 화면 유지)

6. 활동 로그

액션로그 메시지 (한국어)
삭제{타입} '{제목}'을(를) 삭제했습니다.
