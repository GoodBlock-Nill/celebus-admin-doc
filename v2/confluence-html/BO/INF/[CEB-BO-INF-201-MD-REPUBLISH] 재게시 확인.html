0. 공통 정책 참조

참조 문서적용 범위
[CEB-BO-000] 백오피스 공통 정책모달·토스트 공통 규격, 푸시 알림
[CEB-BO-INF-000] 소식·일정 영역 가이드라이프사이클(재게시), 게시일 유지(§4.2), 푸시 알림(§4.6)

1. 화면 목적

상세 화면에서 보관 상태 콘텐츠를 [재게시]할 때, 앱에 다시 노출됨을 안내하고 재게시 여부를 확인받는 모달. 재게시해도 최초 게시일은 그대로 유지된다.

2. UI 설명

요소내용
제목재게시할까요?
본문"게시 즉시 앱 정보 피드에 노출됩니다."
푸시 알림 옵션발송 대상(전체 / 해당 아티스트 팔로워 / 무발송, 기본 무발송) · 발송 시점(즉시 / 예약) · 알림 메시지(한국어·영어·일본어 각 80자, 무발송이 아닐 때만 입력)
버튼[다시 돌아가기] / [재게시]

시각적 스타일은 프로토타입 참조

3. 기능 설명

버튼동작
다시 돌아가기모달 닫고 상세 화면 유지 (재게시 안 함)
재게시재게시 처리 + 선택한 푸시 발송 → 완료 토스트 → 상세 화면 상태를 게시로 갱신

4. 로직·플로우

  • [CEB-BO-INF-201] 상세 (보관 상태) > [재게시] → 본 모달 → [재게시] 시 재게시 확정.
  • 재게시 성공 시 완료 토스트: "{타입} '{제목}'을(를) 게시했습니다."
  • 소식·공지의 게시일은 재게시 시 최초 게시일을 그대로 유지한다(갱신하지 않음, [CEB-BO-INF-000] §4.2). 일정은 게시일 대신 이벤트 일시를 사용한다.

5. 검증·예외 상황

  • 본 모달은 상세 화면이 보관 상태일 때만 진입한다.
  • 재게시 실패 시 Toast (Error): "처리에 실패했습니다."

6. 활동 로그

재게시{타입} '{제목}'을(를) 재게시했습니다.
