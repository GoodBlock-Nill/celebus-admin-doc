비고소식·일정 작성 화면에서 [게시] 시 노출되는 확인 모달. 푸시 알림 옵션 포함

0. 공통 정책 참조

참조 문서적용 범위
[CEB-BO-000] 백오피스 공통 정책모달·토스트 공통 규격, 푸시 알림
[CEB-BO-INF-000] 소식·일정 영역 가이드라이프사이클(게시), 푸시 알림(§4.6)

1. 화면 목적

작성 화면에서 [게시]를 눌렀을 때, 앱 즉시 노출됨을 안내하고 게시 여부를 확인받는 모달. 함께 푸시 알림 발송 옵션을 선택한다.

2. UI 설명

요소내용
제목게시할까요?
본문"게시 즉시 앱 정보 피드에 노출됩니다."
푸시 알림 옵션발송 대상(전체 / 해당 아티스트 팔로워 / 무발송, 기본 무발송) · 발송 시점(즉시 / 예약) · 알림 메시지(한국어·영어·일본어 각 80자, 무발송이 아닐 때만 입력)
버튼[다시 돌아가기] / [게시]
  • 푸시 발송 옵션은 게시 시점에만 노출된다([CEB-BO-INF-000] §4.6). 발송 대상이 무발송이면 알림 메시지·발송 시점 입력은 비활성된다.

시각적 스타일은 프로토타입 참조

3. 기능 설명

버튼동작
다시 돌아가기모달 닫고 작성 화면 유지 (게시 안 함)
게시게시 처리 + 선택한 푸시 발송 → 완료 토스트 → [CEB-BO-INF-101] 리스트로 이동

4. 로직·플로우

  • [CEB-BO-INF-101-CREATE] [게시] → (다국어·타입별 필수 충족 검증 통과 시) 본 모달 → [게시] 시 게시 확정.
  • 게시 성공 시 완료 토스트: "{타입} '{제목}'을(를) 게시했습니다."
  • 게시일은 소식·공지의 경우 본 [게시] 누른 날짜로 자동 기록된다([CEB-BO-INF-000] §4.2). 일정은 게시일 대신 이벤트 일시를 사용한다.

5. 검증·예외 상황

  • 본 모달은 다국어 필수·타입별 필수가 모두 충족돼 [게시]가 활성일 때만 진입한다. 미충족 상태에서는 진입 전 차단 토스트("한국어·영어·일본어를 모두 입력해야 게시할 수 있습니다.")가 [CEB-BO-INF-101-CREATE]에서 노출된다.
  • 푸시 발송 대상이 무발송이 아니면서 알림 메시지가 비어 있으면 [게시] 비활성 처리한다.
  • 게시 실패 시 Toast (Error): "게시에 실패했습니다." (작성 화면 유지)
