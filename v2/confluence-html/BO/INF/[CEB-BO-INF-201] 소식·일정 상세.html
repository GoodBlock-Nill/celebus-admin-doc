1. 화면 목적

개별 소식·일정·공지의 내용을 읽기 전용으로 조회하고 라이프사이클 액션(게시·보관·재게시·삭제)을 수행하는 화면. 내용 수정은 [CEB-BO-INF-201-EDIT] 작성·수정으로 진입한다.

진입 경로

  • [CEB-BO-INF-101] 소식·일정 리스트 > Row 클릭

2. UI 설명

본 화면은 읽기 전용 상세이며, 내용 수정은 [CEB-BO-INF-201-EDIT] 작성·수정에서 수행한다.

2.1 헤더

  • Breadcrumb + 타입 뱃지 + 상태 뱃지
  • 타이틀: {제목(한국어)}
  • 우측 상단 액션 (상태별):
상태노출 액션
임시저장[수정] / [게시] / [삭제]
게시[수정] / [보관]
보관[재게시] / [삭제]

2.2 콘텐츠 표시 (타입별, 읽기 전용)

  • 제목·본문(소식·공지)·일정명(일정)은 언어 전환 탭(한국어/영어/일본어)으로 입력된 다국어 값을 모두 조회할 수 있다. 미입력 언어는 "({언어} 미입력)"으로 표시.
타입표시 항목
소식다국어 제목·본문 / 이미지 썸네일(등록 이미지 전체) / 연관 콘텐츠(콘텐츠 타입 + 콘텐츠명 + URL 링크) / 좋아요
일정다국어 일정명 / 일시 / 장소
공지다국어 제목·본문 / 대표 이미지 / CTA 버튼(라벨 다국어 → 링크) — 라벨은 언어 전환 탭으로 표시
  • 이미지는 등록한 파일을 썸네일 그리드로 표시한다(개수 텍스트가 아님). 미등록 시 "미등록". 소식의 대표 썸네일(앱 카드 등)은 등록 이미지 중 첫 번째 이미지를 사용하며 별도로 지정하지 않는다.
  • 연관 콘텐츠의 썸네일은 운영자가 관리하지 않고 입력한 URL에서 자동 추출되며, 콘텐츠명은 단일 텍스트(다국어 아님)다.
  • 연관 콘텐츠·CTA의 URL은 새 탭으로 열린다.

3. 규칙·로직

3.1 권한

  • 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
  • [수정]·[게시]·[보관]·[재게시]·[삭제]는 쓰기 권한 보유 그룹만 사용한다.

3.2 상태별 액션

각 라이프사이클 액션의 확인 모달은 별도 문서로 분리한다(화면당·모달당 1문서). 본 화면은 액션 트리거만 담당한다.

액션동작확인 모달
[수정][CEB-BO-INF-201-EDIT] 소식·일정 수정으로 이동 (확인 모달 없음)—
[게시]게시(앱 노출) + 완료 토스트. 소식·공지 게시일은 최초 [게시] 시점에 자동 기록[CEB-BO-INF-201-MD-PUBLISH] 게시 확인 (상세)
[재게시]보관 콘텐츠를 다시 게시 + 완료 토스트. 재게시 시 최초 게시일을 그대로 유지(갱신 안 함)[CEB-BO-INF-201-MD-REPUBLISH] 재게시 확인
[보관]앱 노출 종료(데이터 보존) + 완료 토스트[CEB-BO-INF-201-MD-ARCHIVE] 보관 확인
[삭제]영구 삭제 + 토스트 → 리스트 복귀[CEB-BO-INF-201-MD-DELETE] 삭제 확인 (상세)
