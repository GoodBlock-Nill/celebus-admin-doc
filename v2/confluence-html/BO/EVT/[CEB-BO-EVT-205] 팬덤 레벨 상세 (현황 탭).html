1. 화면 목적

개별 아티스트(그룹) 시즌의 레벨업 이력과 디지털 굿즈(BIVE) 지급 연계 현황을 조회하는 화면의 [현황] 탭(읽기 전용). 본 탭은 해당 그룹·해당 시즌 1건만 조회한다. 모든 그룹·시즌을 한 화면에서 통합 조회하려면 [CEB-BO-EVT-401] 보상·레벨업 현황 메뉴를 사용한다.

회원 덕력 변동(기여) 내역은 [CEB-BO-ART-401-HISTORY] 덕력 내역(덕력관리 영역)에서, BIVE 민팅 상세는 [CEB-BO-BIVE-203] 민팅 이벤트 상세에서 조회한다. 래플·서포트 예고는 EVT 자동 지급 대상이 아니므로(임시저장 객체 연결·운영자 수동 게시) 본 현황에 표시되지 않는다.

진입 경로

  • [CEB-BO-EVT-201] 팬덤 레벨 상세 (레벨·곡선 탭) > [현황] 탭
  • URL: /artists/fandom/{id}?tab=status

2.3 레벨업 이력

상단에 참여 유저 수를 시즌 단위 지표로 노출한다. 이는 특정 레벨이 아닌 시즌 전체 1DUK 이상 기여 회원 수다(미팅 정합 2026-06-02 — 레벨별 회원 수는 표기하지 않는다).

4. 규칙·로직

4.1 권한

  • 권한 그룹별 읽기 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
  • 본 탭은 읽기 전용이다(액션 없음).

4.2 조회 기준

  • 본 탭은 진입한 그룹·시즌 1건의 데이터만 조회한다.
  • 레벨업 이력 정렬: 레벨업 일시 내림차순(최신순).
  • BIVE 지급 연계 현황 = 닉네임 검색 + 레벨 + 민팅 상태 AND 조합 필터. BIVE 영역 민팅 상태를 실시간 반영한다.
  • "참여 유저 수"는 시즌 전체 1DUK 이상 기여 회원 단위로만 집계하며 레벨별로 분해하지 않는다.
