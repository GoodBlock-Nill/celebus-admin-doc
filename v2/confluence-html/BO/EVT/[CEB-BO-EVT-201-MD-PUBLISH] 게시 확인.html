1. 화면 목적

운영자가 준비 상태 팬덤 레벨을 게시(준비→진행중)하기 전 확인을 받는 모달. 게시하면 앱에 노출되고 운영이 시작되므로 명시적 확인을 거친다.

  • 누가: 팬덤 레벨 쓰기 권한이 있는 백오피스 관리자
  • 결과: 시즌 상태가 "준비" → "진행중"으로 전환되고 앱 [CEB-EVT-201]에 노출 시작

3. 기능 설명

버튼동작
게시게시 검증 통과 시 시즌 상태 "준비" → "진행중" 전환 + 모달 닫기 + 성공 토스트 + 활동 로그. 상세 헤더 자동 갱신(상태 뱃지 변경 + 액션 버튼 [강제 종료]로 교체)
취소 / [X] / 모달 외부 클릭모달 닫기. 상태 유지

4. 로직·플로우

  1. [CEB-BO-EVT-201] 레벨·곡선 탭 헤더 [게시] 클릭(준비 상태에서만 노출)
  2. 본 확인 모달 열림
  3. [게시] 클릭 → 레벨 곡선 1개 이상 설정 여부 검증
  • 미설정: 모달 닫고 차단 토스트(§5)
  • 설정됨: 진행중 전환 + 성공 토스트(§5) + 활동 로그
  1. [취소]·[X]·외부 클릭: 모달 닫고 준비 상태 유지
