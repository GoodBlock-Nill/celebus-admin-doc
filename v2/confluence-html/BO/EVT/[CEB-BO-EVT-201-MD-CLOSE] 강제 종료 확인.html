1. 화면 목적

운영자가 진행중 시즌을 예외적으로 조기 종료(진행중→종료)하기 전 확인을 받는 모달. 종료는 되돌릴 수 없으므로 신중한 의사결정을 유도한다. 정상 종료는 매년 12월 31일 23:59:59 시스템 자동 종료로 처리되며, 본 [강제 종료]는 아티스트 활동 중단 등 예외 상황에만 사용한다.

  • 누가: 팬덤 레벨 쓰기 권한이 있는 백오피스 관리자
  • 결과: 시즌 상태가 "진행중" → "종료"로 즉시 전환되고 앱 노출이 중단되며, 종료된 시즌은 읽기 전용이 된다

2. UI 설명

├───────────────────────────────────────────┤
│                  [ 취소 ]   [ 강제 종료 ]   │
└───────────────────────────────────────────┘

3. 기능 설명

버튼동작
강제 종료시즌 상태 "진행중" → "종료" 전환 + 모달 닫기 + 성공 토스트 + 활동 로그. 상세 헤더 자동 갱신(상태 뱃지 "종료", 라이프사이클 액션 버튼 미노출, 곡선·보상 [수정] 비활성)
취소 / [X] / 모달 외부 클릭모달 닫기. 시즌 상태(진행중) 유지

4. 로직·플로우

  1. [CEB-BO-EVT-201] 레벨·곡선 탭 헤더 [강제 종료] 클릭(진행중 상태에서만 노출)
  2. 본 확인 모달 열림
  3. [강제 종료] 클릭 → 종료 전환 + 성공 토스트(§5) + 활동 로그
  4. [취소]·[X]·외부 클릭: 모달 닫고 진행중 상태 유지

4.1 종료 후 후속 처리 (시스템)

데이터처리
최종 레벨·누적 덕력종료 시점 기준 확정 보존
디지털 굿즈(BIVE) 지급종료 전 달성 레벨의 자동 민팅분은 그대로 보존(BIVE 영역)
곡선·보상읽기 전용 잠금(수정 불가)
신규 적립·소비발생하지 않음 (차기 시즌은 [CEB-BO-EVT-101]에서 신규 생성)
