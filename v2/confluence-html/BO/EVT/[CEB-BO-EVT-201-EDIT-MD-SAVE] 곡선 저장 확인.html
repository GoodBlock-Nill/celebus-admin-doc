1. 화면 목적

레벨·곡선 수정 화면에서 [저장] 클릭 시, 변경된 곡선이 앱에 반영됨을 안내하고 저장 여부를 확인받는 모달.

3. 기능 설명

버튼동작
저장곡선 저장 처리 + 모달 닫기 + 성공 토스트 + 활동 로그 → 조회 모드 복귀
취소 / [X] / 모달 외부 클릭모달 닫기. 수정 화면 유지(입력값 보존)

4. 로직·플로우

  1. [CEB-BO-EVT-201-EDIT]에서 입력 검증 통과 후 [저장] 클릭 → 본 모달
  2. [저장] 클릭 → 곡선 저장 + 성공 토스트(§5) + 활동 로그 → 조회 모드([CEB-BO-EVT-201]) 복귀
  3. [취소]: 모달만 닫고 수정 화면 유지
  • 본 모달은 [저장] 전 입력 검증(목표 덕력 1 이상·최대 10단계 등, [CEB-BO-EVT-201-EDIT] §5)을 통과해야 노출된다.
