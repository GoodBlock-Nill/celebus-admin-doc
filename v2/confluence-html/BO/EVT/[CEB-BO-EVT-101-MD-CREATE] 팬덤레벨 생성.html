1. 화면 목적

운영자가 아티스트(그룹) 단위 팬덤 레벨을 직접 생성하는 입력 모달. 팬덤 레벨은 자동 생성되지 않으며, 운영자가 본 모달에서 아티스트·시즌 연도·시즌명을 입력하면 준비 상태로 리스트에 추가된다. 레벨 곡선·레벨별 보상은 생성 후 [CEB-BO-EVT-201] 상세에서 설정한다.

  • 누가: 팬덤 레벨 쓰기 권한이 있는 백오피스 관리자
  • 왜: 아티스트별·연도별로 독립된 팬덤 공동 레벨 시즌을 개설하기 위해
  • 결과: 준비 상태의 팬덤 레벨 1건이 리스트 최상단에 추가되고, 운영자가 곡선·보상 설정 단계로 진입할 수 있다

진입 경로

  • [CEB-BO-EVT-101] 팬덤 레벨 리스트 > 우측 상단 [생성]

2.2 본문 구성

영역내용
타이틀"팬덤레벨 생성"

입력 항목아티스트 / 시즌 연도 / 시즌명 (아래 §2.3)

2.3 입력 항목

항목필수타입설명
아티스트필수Dropdown그룹 선택. 데이터 소스 = [CEB-BO-ART-201] 그룹 리스트의 활성(Active) 그룹. 한국어 그룹명 표시
시즌 연도필수Dropdown연도 선택(기본: 올해). 예: "2026년". 선택 연도 1월 1일 ~ 12월 31일이 시즌 기간으로 자동 설정됨 (하단 안내 문구 노출)
시즌명필수Text Input"{아티스트} 팬덤 N기 (YYYY)" 자동 제안(수정 가능). 직접 비우면 자동 제안값으로 저장. 입력 안내: "시즌명 입력"
  • 시즌명 N(기수)은 해당 아티스트의 기존 시즌 수 + 1로 자동 제안된다(예: 기존 1건이면 "2기").
  • 시즌 기간은 운영자가 직접 입력하지 않으며, 시즌 연도 선택값으로 캘린더 연도(1.1~12.31) 전체가 자동 설정된다.

시각적 스타일은 프로토타입 참조

4. 규칙·로직

4.1 권한

  • 권한 그룹별 읽기·쓰기 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
  • 쓰기 권한이 없으면 리스트 [생성] 버튼이 미노출되므로 본 모달은 호출되지 않는다.

4.2 생성 규칙

  • 동일 아티스트·동일 연도 중복 차단: 같은 아티스트에 같은 연도 시즌이 이미 존재하면 [생성]이 비활성화되고 중복 인라인 안내가 노출된다.
  • 생성 시 상태는 준비로 진입한다([CEB-BO-EVT-000] §4.1.1).
  • 시즌 기간은 선택 연도의 1월 1일 ~ 12월 31일로 자동 설정된다(운영자 변경 불가).
  • 레벨 곡선·레벨별 보상은 본 모달에서 입력하지 않으며, 생성 후 [CEB-BO-EVT-201] 상세에서 설정한다.
