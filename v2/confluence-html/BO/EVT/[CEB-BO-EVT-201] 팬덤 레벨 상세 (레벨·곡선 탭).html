1. 화면 목적

개별 아티스트(그룹)의 팬덤 레벨 시즌을 조회·관리하는 상세 화면의 [레벨·곡선] 탭. 시즌 정보와 레벨별 목표 덕력(레벨 곡선)을 조회한다. 또한 상세 화면 공통 헤더의 시즌 라이프사이클 액션([게시] / [강제 종료]) 을 본 탭 문서에서 정의한다(헤더는 3탭 공통이지만 라이프사이클 책임 문서는 본 문서로 둔다).

팬덤 레벨 상세는 3탭 구조이며, 보상 설정은 [CEB-BO-EVT-203] 보상 탭, 레벨업·지급 현황은 [CEB-BO-EVT-205] 현황 탭에서 다룬다.

주요 기능

  • 시즌 정보 조회(시즌명·기간·현재 팬덤 레벨·누적 덕력·참여 팬 수·최고레벨 도달 여부)
  • 레벨 곡선 조회(레벨별 목표 덕력·권장값·달성 여부·달성 일시)
  • 시즌 상태 전환: [게시](준비→진행중) / [강제 종료](진행중→종료)
  • 레벨 곡선 수정 진입([수정] → [CEB-BO-EVT-201-EDIT])

진입 경로

  • [CEB-BO-EVT-101] 팬덤 레벨 리스트 > Row 클릭
  • URL: /artists/fandom/{id}?tab=curve (기본 탭)

2. UI 설명

2.1 상단 헤더 (3탭 공통)

  • Breadcrumb + 뒤로가기: 홈 > 아티스트 > 팬덤레벨 > {그룹명(한국어)}
  • 타이틀: {그룹명} + 현재 시즌명("{아티스트} 팬덤 N기 (YYYY)")
  • 시즌 상태 뱃지: 준비 / 진행중 / 종료
  • 현재 팬덤 레벨 뱃지: "Lv.{N}" (최고레벨 도달 시 "Lv.{N} MAX", 곡선 미설정 시 미노출)
  • 우측 상단 액션: 시즌 상태에 따라 [게시] 또는 [강제 종료] (아래 §2.1.1)

2.1.1 시즌 라이프사이클 액션 (상태별 노출)

현재 상태노출 버튼동작확인 모달
준비[게시]준비 → 진행중. 앱 노출 시작[CEB-BO-EVT-201-MD-PUBLISH] 게시 확인
진행중[강제 종료]진행중 → 종료. 예외적 조기 종료[CEB-BO-EVT-201-MD-CLOSE] 강제 종료 확인
종료(버튼 없음)——
  • 운영자 수동 상태 전환은 [게시] 만 일상적으로 사용한다. 시즌은 매년 12월 31일 23:59:59 자동 종료되며, 종료 시 시스템이 최종 레벨 확정·통계 마감을 자동 처리한다(운영자 정산 작업 없음).
  • [강제 종료]는 아티스트 활동 중단 등 예외적 조기 종료용이다. 라이프사이클 상세는 [CEB-BO-EVT-000] §4.1.1을 따른다.
  • [게시]는 레벨이 5개 이상 설정되어 있어야 가능하다(5개 미만 시 게시 차단 — §7).

4. 규칙·로직

4.1 권한

  • 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
  • [게시]·[강제 종료]·[수정]은 쓰기 권한 보유 그룹만 노출된다(미보유 시 미노출).

4.2 상태 전환 규칙

전환조건
준비 → 진행중 ([게시])레벨 5개 이상 설정 필수(최소 max 레벨 5). 게시 후 앱 노출 시작
진행중 → 종료 (12.31 자동)매년 12월 31일 23:59:59 시스템 자동 종료(최종 레벨 확정·통계 마감 자동 처리)
진행중 → 종료 ([강제 종료])운영자 예외적 조기 종료(확인 모달). 아티스트 활동 중단 등
  • 운영자 정산 작업은 없다 — 디지털 굿즈(BIVE)는 진행중 실시간 자동 민팅, 래플·서포트는 예고 표시 전용.
  • 종료 시즌은 읽기 전용이다. 신규 시즌은 [CEB-BO-EVT-101]에서 생성한다.

4.3 곡선 표시 규칙 (조회)

  • 레벨 수는 최소 5 ~ 최대 10단계(게시하려면 5개 이상 필요). 목표 덕력은 해당 레벨 단독 목표값(누계 아님)이다.
  • 달성 레벨(현재 레벨 이하)은 달성 뱃지·달성 일시를 표시한다.

4.4 [수정] 비활성 조건

조건비활성 사유 안내
최고레벨(MAX) 도달 시즌"최고 레벨 도달 — 시즌 곡선·보상이 확정되어 수정할 수 없습니다."
종료 시즌"종료된 시즌 — 읽기 전용"
쓰기 권한 없음[수정] 버튼 자체 미노출
  • 최고레벨(MAX) 도달 시 시즌 곡선·보상이 확정되어 수정·신규 레벨 추가가 모두 불가하다([CEB-BO-EVT-000] §4.1.2). 추가 확장은 차기 시즌에서 진행한다.
