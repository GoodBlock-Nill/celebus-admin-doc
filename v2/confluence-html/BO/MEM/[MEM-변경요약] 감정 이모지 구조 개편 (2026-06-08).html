1. 한 줄 요약

감정 이모지를 이미지 업로드 전용으로 바꾸고, "아티스트별 매번 등록" → "전역 라이브러리에 1번 등록하고 아티스트에 연결" 구조로 개편했습니다.

개발팀 피드백 2건을 그대로 반영한 것입니다.

  1. 감정은 이미지로 쓰므로 파일 업로드만 가능 → 유니코드 이모지 입력 방식 제거.
  2. 실제 시스템은 전역 등록 후 아티스트 연결 구조 → 명세·프로토타입을 이 구조로 통일.

2. 무엇이 바뀌었나 (Before → After)

구분Before (이전 기획)After (이번 개편)
이모지 등록 방식유니코드 입력 또는 이미지 업로드이미지 업로드 전용
등록 단위아티스트별 세트에 매번 등록전역 라이브러리에 1번 등록 → 아티스트에 연결
이미지·라벨 공유아티스트마다 따로여러 아티스트가 1개 이모지 공유 (재업로드 없음)
관리 화면1개 (관리 화면)2개로 분리 — 라이브러리 / 아티스트 연결
삭제세트에서 삭제2단계 — 연결 해제 / 라이브러리 전역 삭제
기본 6종유니코드 프리셋기본 제공 이미지 6종 (자동 연결)

3. 핵심 개념 — "라이브러리"와 "연결" 2층 구조

┌─────────────────────────────────────────────┐
│  전역 라이브러리 (MEM-502)                    │
│  이모지 = 이미지 + 라벨(한/영/일)             │   ← 1번만 등록
│  [설렘🖼] [감동🖼] [신남🖼] [응원봉🖼] ...     │
└─────────────────────────────────────────────┘
        │ 연결        │ 연결        │ 연결
        ▼             ▼             ▼
   [아티스트 A]   [아티스트 B]   [아티스트 C]      ← 연결 + 순서·사용여부 (MEM-501)
   설렘(1·사용)   설렘(1·사용)   감동(1·사용)
   감동(2·사용)   응원봉(2·미사용) ...

속성이 2개 층으로 나뉩니다.

층속성범위수정하면
라이브러리이미지, 라벨(한/영/일)전역 공유연결된 모든 아티스트에 즉시 반영
연결표시 순서, 사용여부아티스트별 독립해당 아티스트에만 적용, [변경사항 적용] 시 게시

4. 디자이너가 알아야 할 것

화면 2개

화면역할주요 UI
감정 이모지 라이브러리 ([MEM-502])이모지 자체를 전역 등록·수정·삭제이미지·라벨 표 + 연결 아티스트 수 + [이모지 등록]
감정 이모지 연결 관리 ([MEM-501])아티스트별로 이모지 연결·순서·사용여부아티스트 선택 + 연결 세트 표 + [이모지 연결] + [변경사항 적용]

주요 모달

  • 이모지 연결 ([MEM-501-MD-LINK]): 라이브러리에서 다중 선택해 연결. 이미 연결된 건 "연결됨" 표시·선택 불가. "없으면 신규 등록" 진입점 포함.
  • 이모지 등록·수정 ([MEM-502-MD-EMOJI]): 이미지 업로드 + 라벨(한/영/일)만. (사용여부·순서 입력 없음 — 그건 연결 화면 소관)
  • 연결 해제 확인 / 라이브러리 삭제 확인: 각각 아티스트 제거 / 전역 제거.

앱(회원) 화면 — 기억 작성 ([CEB-MEM-201])

  • 감정 선택지는 이미지로 노출(유니코드 문자 ❌). 라디오 1개 단일 선택(기존과 동일).
  • 노출되는 이모지 종류·순서·개수(최대 6개)는 아티스트마다 다름 — 백오피스 설정을 따름.

🎨 디자인팀 액션 필요

  • 기본 제공 이미지 6종 에셋 필요: 설렘 · 감동 · 신남 · 사랑 · 우와 · 행복
  • 이미지 규격: 정사각형(1:1) 권장 · JPG·PNG·WebP · 5MB 이하

5. 개발자가 알아야 할 것

데이터 모델 (개념)

  • LibraryEmoji (전역): 이미지, 라벨(KO/EN/JA), 기본제공여부, 회원사용이력
  • EmojiLink (연결): 아티스트, 이모지 참조(FK), 표시순서, 사용여부
  • 같은 LibraryEmoji를 여러 EmojiLink가 참조 (N:1).

동작 규칙

항목규칙
라이브러리 이미지·라벨 수정즉시 전역 반영 (연결된 모든 아티스트). 게시 대기 없음
연결 구성·순서·사용여부작업본에 누적 → [변경사항 적용] 시 원자적 게시. 적용 전 앱은 직전 적용본 노출
연결 상한아티스트별 최대 40종 연결, 그중 사용(앱 노출) 최대 6종
연결 해제 가능사용여부 = 미사용일 때만 (사용 중이면 먼저 미사용 전환)
라이브러리 삭제 가능연결 아티스트 0 + 회원 사용 이력 없음일 때만 (전역 영구 삭제)
신규 아티스트기본 제공 이미지 6종 자동 연결

삭제 2단계 (혼동 주의)

  • 연결 해제 = 그 아티스트 세트에서만 빠짐. 라이브러리·다른 아티스트·회원 기록 영향 없음.
  • 라이브러리 삭제 = 전역에서 영구 제거. 회원이 쓴 이모지는 기록 보존을 위해 삭제 불가(연결 해제만 가능).
