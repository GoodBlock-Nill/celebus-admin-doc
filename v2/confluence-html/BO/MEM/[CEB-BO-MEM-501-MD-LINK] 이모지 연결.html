1. 화면 목적

라이브러리에 등록된 감정 이모지를 선택해 현재 아티스트에 연결하는 모달이다. 라이브러리에 원하는 이모지가 없으면 신규 등록 경로로 진입한다.

2. UI 설명

2.1 모달 구성

영역내용
헤더"이모지 연결 — {아티스트명}" + [✕] 닫기
안내"라이브러리에서 연결할 이모지를 선택하세요. (연결 {N} / 40종)"
검색라벨(한국어·영어·일본어) 기준 검색
라이브러리 목록이미지 썸네일 + 3언어 라벨 그리드. 다중 선택(체크). 이미 연결된 항목은 "연결됨" 배지 + 선택 비활성
신규 등록 진입"원하는 이모지가 없나요? [신규 등록]" → 등록 모달([CEB-BO-MEM-502-MD-EMOJI]) 열기. 등록 후 목록에 반영
푸터[취소] / [연결] (선택 0건이면 비활성)

4. 규칙·로직

  • 연결은 작업본에 누적되며, 앱 반영은 [CEB-BO-MEM-501]의 [변경사항 적용] 시점이다(즉시 반영 아님).
  • 신규 연결 항목은 세트의 마지막 순서로 추가되며, 기본 미사용으로 연결된다(사용 6종 여유가 있으면 운영자가 [CEB-BO-MEM-501]에서 사용으로 전환).
  • 이미 연결된 이모지는 중복 선택할 수 없다(연결됨 배지·비활성).
  • 연결 후 세트 총량이 40종을 초과할 수 없다. 남은 여유 칸을 초과하는 선택은 [연결] 차단 + 안내.
  • [신규 등록]으로 라이브러리에 추가한 이모지도 본 모달에서 선택해야 아티스트에 연결된다(등록 자체는 연결이 아님).
  • 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
