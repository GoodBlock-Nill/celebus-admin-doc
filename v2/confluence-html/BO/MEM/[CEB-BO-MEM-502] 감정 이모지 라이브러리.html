1. 화면 목적

회원이 기억 작성 시 선택하는 감정 이모지를 전역으로 등록·수정·삭제하는 화면이다.

  • 누가: 기억저장소 운영 권한이 있는 백오피스 관리자
  • 왜: 같은 감정 이모지를 여러 아티스트가 공유하므로, 이모지(이미지·라벨)는 아티스트와 무관하게 한 번만 등록해 라이브러리로 관리한다. 아티스트별 노출은 [CEB-BO-MEM-501]에서 연결로 처리
  • 결과: 라이브러리에 이모지를 등록·수정·삭제하고, 각 이모지가 몇 개 아티스트에 연결됐는지 확인

아티스트별 표시 순서·사용여부·연결은 이 화면이 아니라 [CEB-BO-MEM-501] 감정 이모지 연결 관리에서 수행한다.

4. 규칙·로직

4.1 등록·수정

  • 각 이모지는 이미지 업로드(정사각형 1:1 권장·JPG·PNG·WebP·5MB 이하)와 3언어 라벨(한국어·영어·일본어, 각 20자)로 구성한다. 라벨 중복 허용.
  • 이미지·라벨은 전역 공유 속성이다. 수정 시 이 이모지를 연결한 모든 아티스트의 앱 표시에 즉시 반영된다(콘텐츠 정정 성격, [CEB-BO-MEM-501]의 작업본 적용과 무관).

4.2 삭제 (전역)

  • 라이브러리 삭제는 이모지를 전역에서 영구 제거한다.
  • 삭제 가능 조건: 연결 아티스트가 0 이고 회원 사용 이력이 없는 이모지만 [삭제]할 수 있다. 아래는 [삭제] 비활성(툴팁으로 사유 안내).
    • 연결 아티스트가 1개 이상 → 먼저 각 아티스트에서 연결 해제([CEB-BO-MEM-501-MD-UNLINK])해야 한다.
    • 회원이 이미 사용한 이모지 → 삭제 불가(기억 기록 보존). 연결 해제만 가능.
  • 특정 아티스트에서만 빼려면 삭제가 아니라 [CEB-BO-MEM-501]에서 연결 해제한다.

4.3 권한

  • 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
  • 등록·수정·삭제는 쓰기/삭제 권한 그룹만 사용한다.
