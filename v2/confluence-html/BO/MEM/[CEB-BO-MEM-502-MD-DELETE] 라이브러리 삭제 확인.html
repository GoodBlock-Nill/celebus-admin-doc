0. 공통 정책 참조

참조 문서적용 범위

[CEB-BO-MEM-502] 감정 이모지 라이브러리호출 화면·전역 삭제 차단 규칙

1. 화면 목적

라이브러리에서 감정 이모지를 전역 삭제하기 전 확인하는 모달이다. 비가역 작업이므로 운영자 확인을 거친다.

2. UI 설명

영역내용
헤더"감정 이모지 삭제"
본문"'{라벨}' 이모지를 라이브러리에서 삭제할까요?" + "전역에서 영구 제거되며 복구할 수 없습니다."
푸터[취소] / [삭제]

시각적 스타일은 프로토타입 참조

3. 화면 내 기능설명

요소동작
[삭제]라이브러리에서 해당 이모지 영구 제거 + 모달 닫기 + 완료 토스트
[취소] / 배경모달 닫기 (삭제 안 함)

4. 규칙·로직

  • 호출 화면([CEB-BO-MEM-502])에서 연결 아티스트가 0 이고 회원 사용 이력이 없는 이모지만 [삭제] 버튼이 활성화되어 본 모달로 진입한다.
  • 다음은 [삭제] 버튼이 비활성이므로 본 모달에 진입하지 않는다(버튼 툴팁으로 사유 안내).
    • 연결 아티스트가 1개 이상 → 먼저 각 아티스트에서 연결 해제([CEB-BO-MEM-501-MD-UNLINK])해야 한다.
    • 회원이 이미 사용한 이모지 → 삭제 불가(기억 기록 보존).
  • 특정 아티스트에서만 제거하려면 삭제가 아니라 [CEB-BO-MEM-501]에서 연결 해제한다.
  • 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.

상태처리

삭제 실패Toast (Error): "삭제에 실패했습니다."
