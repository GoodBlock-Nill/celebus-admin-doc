## 3. 래플 생성·추첨 모달 (B 실측)
- 래플 생성: "Raffle 생성" / 3섹션(Raffle 정보·보상 기본 설정·수령 가이드 및 유의사항) / 필드 아티스트·마감일시·대표 이미지·타이틀(100)·설명(200) · 당첨 추첨 수·보상지급 타입(현장/배송)·경품 단위·경품 내역·BIVE 보상 지급 · 수령 가이드 분기(현장=수령 시작/마감일·운영 시간·수령 장소·지참물 / 배송=배송지 입력 마감일·마감 시간·폼 URL) — ✅ TC_0007~0011 전부 정합
- 추첨 모달(raffle 11, 0응모): "Raffle 추첨하기"+"추첨 정보" / "응모자가 없어 추첨할 대상이 없습니다."+[닫기] — ⚪ TC_0021(0건도 [추첨하기] 노출, 클릭 시 안내)
- ⏳ 추첨 가추첨·시드·미리보기·확정(0027)·당첨자 관리(0029/0030)·추첨 확정 통계(0022~0026): 응모자/추첨완료 raffle 데이터 필요(확정 비가역)
- ⏳ 게시/종료/삭제 모달(0031~0033): 임시저장·진행중 raffle 데이터 필요
- 앱 연동(0034~): BO 범위 외

> 래플 데스크/실측: 리스트·상세 구조·생성(전 필드)·추첨 모달(0건). 잔여=특정 상태 raffle 데이터 의존 + 앱 연동.
