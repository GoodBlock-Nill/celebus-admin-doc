- ⚪ **TC_QST_0012**: 참여 방식이 BO에선 "반복 참여" OFF/ON 토글 (문서·QA "참여 방식 일반/반복" 라디오). 의미 동일하나 라벨·컨트롤 정정 필요.

## 9. 테스트 Quest 생성 시도 결과 (0023·0030·0033/0034)

사용자 승인으로 임시저장 Quest를 생성→게시 모달 확인→삭제 정리하려 시도했으나, **자동(스크립트) 생성이 막힘**:
- **마감 일시 필드가 readonly 캘린더 위젯** — 직접 값 입력 불가(달력 팝업에서 날짜 클릭 필요). 스크립트 native set으론 React 날짜 상태 미반영.
- 다국어 입력이 단일 입력 언어 전환식이라 KO/EN 상태 저장 불확실.
- 결과: **[생성하기] 계속 비활성 → 생성 미실행(저장된 데이터 없음)**.

→ TC_0023(임시저장 액션)·0030(게시 모달)·0033/0034(삭제 모달)은 여전히 **실측필요**. 권장: 캘린더 위젯 클릭 기반 인터랙티브 생성(달력에서 날짜 선택) 또는 수동 QA. 진행중 상세에서 [수정하기]·[종료하기]는 확인됨(TC_0023 진행중분).

### §9 보완 — 인터랙티브 생성으로 완결 (2026-06-18)
캘린더 위젯 클릭 방식으로 테스트 Quest 생성→검증→삭제 완료(고아 데이터 없음):
- ✅ **TC_0020** 생성: "확인 버튼을 누르면 신규 Quest가 생성됩니다" 모달 → 임시저장 생성·리스트 복귀
- ✅ **TC_0023** 임시저장 액션 = [삭제하기][수정하기][게시하기] (진행중=[수정하기][종료하기])
- ✅ **TC_0030** 게시 모달 = "Quest 게시 / 확인 버튼을 누르면 Quest가 게시됩니다" [취소][게시] — ⚪ QA "진행중 상태로 게시됩니다"와 문구 차이
- ✅ **TC_0033** 삭제 모달 = "Quest 삭제 / 확인 버튼을 누르면 Quest가 삭제 됩니다" [취소][삭제] → 삭제·리스트 복귀 — ⚪ QA "복구할 수 없습니다(위험 톤)·매핑 해제 안내"와 차이
- ✅ **TC_0034** 진행중·종료 [삭제하기] 미노출(임시저장만)

→ 게시/삭제 모달 문구도 QA 정정 대상(⚪). quests.tsv 반영 완료. **남은 미검증은 검수/제출(앱 데이터)·앱 연동(BO 범위 외)뿐.**
