### 갭 요약 (에디션)
- ⚪ TC_0010: 수정 모달 입력이 literally read-only는 아님(편집 가능하나 [수정하기] 비활성). "read-only" 표현 정정 권장.
- ⚪ BIVE-101 §2-2·§2-3 "수정/삭제 모달" → BO 수정 모달에 **삭제 기능 없음**(수정하기만). 문서 정정 필요.
- ✅ 그 외 리스트 컬럼·정렬·검색·생성 모달(3국어 필수)·수정 제약 정합.
- ⏳ TC_0011(수정 후 저장)은 BIVE 0 에디션 필요 — 후속.

- [BIVE 등록] 버튼 ✅

### 🔴 BIVE 등록 — 미디어 규격 (중대 발견)
BO `/bive/editions/{id}/create` 실측:
| 필드 | BO 실측 안내 |
| --- | --- |
| 미디어 파일(메인) * | **png, jpg, jpeg, webp · 최대 20MB** + "PNG/JPG는 크롭 후 WebP로 저장" |
| 썸네일 이미지 파일 * | **png, jpg, jpeg, webp · 최대 20MB** (동일) |
| 서브 이미지 파일 (선택) | **png, jpg, jpeg, webp · 최대 20MB** |

**문서·QA와의 갭 (🔴/🟡)**:
- 🔴 **GIF가 BO 어디에도 없음** — 메인·서브·썸네일 모두 png/jpg/jpeg/webp. (이번 세션 [CEB-BO-004] v1.15에서 썸네일만 GIF 제외하고 **메인 이미지엔 GIF 유지**했으나, BO는 메인·서브에서도 GIF 없음 → 문서 추가 정정 필요)
- 🔴 **썸네일 크기 = 20MB** (문서·QA의 "저용량 2MB·권장 640px"가 BO 미반영). 즉 "저용량 썸네일 2MB·640px" 스펙(2026-06-16 신설)은 **BO 미구현**(BO는 메인과 동일 20MB) — 🟡 문서-BO 차이(개발 미반영) 또는 스펙 정정 필요
- 🟠 **PNG/JPG → WebP 자동 변환**·**jpeg 확장자 명시**·**"굿즈 유형" 라벨**(미디어 타입) — 문서·QA 미기재
- → QA TC_0018/0019/0020/0021/0022 썸네일 규격(GIF·2MB·640px·확장자) 전면 재검토 필요

**남은 ⏳**: BIVE 등록 기능설정 탭(토글 3종)·검증·저장 / BIVE 상세(헤더 상태별 액션·기본정보·기능설정·민팅관리·민팅이력·활성/비활성/삭제) / 앱 연동 — 후속 실측.

> ⚠️ 본 발견은 이번 세션에 커밋한 GIF/썸네일 문서 변경(commits caee450·80b4c2f 계열)과 직결. 저용량 썸네일 2MB·640px·GIF 정책 vs BO 실제(20MB·자동WebP·GIF없음) 정합 방향 사용자 결정 필요.
