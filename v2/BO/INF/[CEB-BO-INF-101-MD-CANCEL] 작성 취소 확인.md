## 1. 화면 목적

소식·일정 작성 중 [취소]를 눌렀을 때, 작성 중인 내용이 저장되지 않음을 안내하고 이탈 여부를 확인받는 모달.

## 3. 기능 설명

| 버튼 | 동작 |
| --- | --- |
| 다시 돌아가기 | 모달 닫고 작성 화면 유지 |
| 나가기 | 작성 내용 폐기 후 [CEB-BO-INF-101] 소식·일정 리스트로 이동 |

---

## 4. 로직·플로우

[CEB-BO-INF-101-CREATE] [취소] → 본 모달 → [나가기] 시 폐기·이탈 / [다시 돌아가기] 시 작성 유지. 폐기 시 별도 토스트는 없다.

---

## 5. 검증·예외 상황

- 작성 내용 유무와 관계없이 [취소] 시 본 모달이 노출된다.
- [나가기]로 이탈 시 임시저장·게시가 일어나지 않으며, 입력 내용은 보존되지 않는다.
