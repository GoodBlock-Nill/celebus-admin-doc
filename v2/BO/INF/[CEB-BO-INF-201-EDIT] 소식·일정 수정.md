### 진입 경로

## 2. UI 설명

### 2.1 헤더

- Breadcrumb: `홈 > 아티스트 > 소식/일정 > {제목} 수정`
- 타이틀: 소식/일정 수정
- 우측 상단 액션: [취소] / [삭제] / [임시저장] / [게시]
- [삭제]는 수정 화면에만 노출되는 액션이다(작성 화면에는 없음).
- **[게시]는 다국어 필수(한국어·영어·일본어)와 타입별 필수 항목이 모두 충족될 때만 활성**된다. 미충족 시 비활성 처리하고 헤더 하단에 미충족 사유 안내 문구를 노출한다. [임시저장]은 미완성 상태에서도 항상 가능하다.

### 2.2 공통 메타 (사이드 — 설정)

| 항목 | 형식 |
| --- | --- |
| 타입 | Dropdown — 소식 / 일정 / 공지 (선택에 따라 §2.3 입력 폼 분기, 기존 타입으로 채워짐) |
| 연결 아티스트 | Dropdown — 그룹 (기존 값) |
| 공식 출처 | 토글 — 공식 제공 뱃지 표기 (소식·일정만, 공지 미해당) |

### 2.3 타입별 입력 폼

작성([CEB-BO-INF-101-CREATE] §2.3)과 동일한 구성이며, 진입 시 기존 값이 채워진다.

#### A. 소식

| 항목 | 필수 | 형식 |
| --- | --- | --- |
| 제목 | 필수 | 한국어·영어·일본어, 각 50자 |
| 본문 | 필수 | 한국어·영어·일본어 위지윅, 각 5,000자 |
| 이미지 | 선택 | 최대 10장. 첫 번째 이미지가 대표 썸네일로 사용됨 |
| 연관 콘텐츠 | 선택 | 최대 3건 — 콘텐츠 타입(유튜브/X/인스타그램/스포티파이/일반) + 콘텐츠명(단일, 50자) + URL |

- 게시일은 수정 화면에서 입력·변경하지 않는다. 최초 게시일은 그대로 유지된다([CEB-BO-INF-000] §4.2).
- 연관 콘텐츠 3건을 모두 채우면 [콘텐츠 추가] 버튼이 비활성된다. 콘텐츠명은 단일 텍스트(다국어 아님), 썸네일은 URL에서 자동 추출(운영자 미관리)한다.

#### B. 일정

| 항목 | 필수 | 형식 |
| --- | --- | --- |
| 일정명 | 필수 | 한국어·영어·일본어, 각 50자 |
| 날짜 | 필수 | 날짜 선택 |
| 시간 | 필수 | 시간 선택 |
| 장소 | 선택 | 구글 장소 검색에서 선택한 장소명 그대로 사용, 100자 |

- 일정에는 본문·이미지·부제·썸네일·게시일 입력이 없다. 일시는 이벤트 일자이며 게시일과 별개다.

#### C. 공지

| 항목 | 필수 | 형식 |
| --- | --- | --- |
| 제목 | 필수 | 한국어·영어·일본어, 각 50자 |
| 본문 | 필수 | 한국어·영어·일본어 위지윅, 각 5,000자 |
| 대표 이미지 | 선택 | 1장 |
| CTA 버튼 | 선택 | 라벨(한국어·영어·일본어, 각 30자) + 링크 URL(단일) |

> 시각적 스타일은 프로토타입 참조

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- 수정·삭제는 쓰기·삭제 권한 보유 그룹만 사용한다. 권한이 없으면 [CEB-BO-INF-201] 상세에서 [수정]·[삭제]가 미노출된다.

### 4.2 변경 판정·저장 활성

- 진입 시 기존 값이 채워진 상태이며, **변경 사항이 있을 때만 [임시저장]·[게시]가 저장을 수행**한다. 변경 판정 대상 = 타입·연결 아티스트·공식 출처·제목/일정명(언어별)·본문(언어별)·일시·장소·이미지(추가/삭제/순서)·연관 콘텐츠(추가/삭제/내용)·대표 이미지·CTA 라벨/링크 중 하나라도 진입 시점 값과 달라진 경우다.
- 변경이 전혀 없으면 [임시저장]·[게시]를 눌러도 추가 저장 없이 진입 검증만 통과한다(불필요한 수정 로그를 남기지 않음).
- 수정 화면을 떠날 때(미저장 이탈)는 [취소] 확인 모달로 안내한다.

### 4.3 다국어 게시 검증

- [게시] 시 소식·공지의 제목·본문, 일정의 일정명은 한국어·영어·일본어를 모두 입력해야 한다. 1개라도 빈 칸이면 [게시]가 비활성이며, 시도 시 차단 토스트를 노출한다.

### 4.4 타입별 게시 필수 검증

| 타입 | 게시 필수 항목 |
| --- | --- |
| 소식 | 제목·본문(각 3언어) |
| 일정 | 일정명(3언어), 날짜, 시간 |
| 공지 | 제목·본문(각 3언어) |

- 게시일은 게시 필수 항목이 아니며, 수정 시에도 최초 게시일을 변경하지 않는다.

### 4.5 URL 검증

- 연관 콘텐츠 URL·CTA 링크는 올바른 URL 형식이어야 한다. 형식 오류 시 인라인 에러를 노출한다.
