## 1. 화면 목적

상세 화면에서 **게시 상태** 콘텐츠를 [보관]할 때, 앱 노출이 종료되며 데이터는 보존되어 재게시할 수 있음을 안내하고 보관 여부를 확인받는 모달.

---

| 버튼 | [다시 돌아가기] / [보관] |

## 3. 기능 설명

| 버튼 | 동작 |
| --- | --- |
| 다시 돌아가기 | 모달 닫고 상세 화면 유지 (보관 안 함) |
| 보관 | 보관 처리(앱 노출 종료, 데이터 보존) → 완료 토스트 → 상세 화면 상태를 보관으로 갱신 |

---

## 4. 로직·플로우

- [CEB-BO-INF-201] 상세 (게시 상태) > [보관] → 본 모달 → [보관] 시 보관 확정.
- 보관 성공 시 완료 토스트: "{타입} '{제목}'을(를) 보관 처리했습니다."
- 보관은 삭제가 아니며 데이터를 보존한다. 이후 [재게시]([CEB-BO-INF-201-MD-REPUBLISH])로 다시 노출할 수 있고, 재게시해도 최초 게시일은 유지된다([CEB-BO-INF-000] §4.2).

---

## 5. 검증·예외 상황

- 본 모달은 상세 화면이 **게시 상태**일 때만 진입한다.
- 보관 실패 시 Toast (Error): "처리에 실패했습니다."
