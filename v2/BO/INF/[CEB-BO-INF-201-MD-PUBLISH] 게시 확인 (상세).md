## 1. 화면 목적

상세 화면에서 **임시저장 상태** 콘텐츠를 [게시]할 때, 앱 즉시 노출됨을 안내하고 게시 여부를 확인받는 모달. 함께 푸시 알림 발송 옵션을 선택한다.

---

## 2. UI 설명

| 요소 | 내용 |
| --- | --- |
| 제목 | 게시할까요? |
| 본문 | "게시 즉시 앱 정보 피드에 노출됩니다." |
| 푸시 알림 옵션 | 발송 대상(전체 / 해당 아티스트 팔로워 / 무발송, 기본 무발송) · 발송 시점(즉시 / 예약) · 알림 메시지(한국어·영어·일본어 각 80자, 무발송이 아닐 때만 입력) |
| 버튼 | [다시 돌아가기] / [게시] |

> 시각적 스타일은 프로토타입 참조

## 3. 기능 설명

| 버튼 | 동작 |
| --- | --- |
| 다시 돌아가기 | 모달 닫고 상세 화면 유지 (게시 안 함) |
| 게시 | 게시 처리 + 선택한 푸시 발송 → 완료 토스트 → 상세 화면 상태를 게시로 갱신 |

---

## 4. 로직·플로우

- [CEB-BO-INF-201] 상세 (임시저장 상태) > [게시] → 본 모달 → [게시] 시 게시 확정.
- 게시 성공 시 완료 토스트: "{타입} '{제목}'을(를) 게시했습니다." 상세 화면은 그대로 유지되며 상태 뱃지·액션이 게시 상태로 갱신된다.
- 소식·공지의 게시일은 본 [게시] 누른 날짜로 **최초 1회 자동 기록**된다([CEB-BO-INF-000] §4.2). 일정은 게시일 대신 이벤트 일시를 사용한다.

---

## 5. 검증·예외 상황

- 본 모달은 상세 화면이 **임시저장 상태**일 때만 진입한다(게시 상태에서는 [게시] 액션이 없음).
- 보관 상태의 [재게시]는 본 모달이 아니라 [CEB-BO-INF-201-MD-REPUBLISH] 재게시 확인을 사용한다.
- 게시 실패 시 Toast (Error): "처리에 실패했습니다."
