## 1. 화면 목적

기존 멤버의 프로필 정보를 수정하는 화면. 입력 항목·구성은 [CEB-BO-ART-202-Create] 멤버 생성과 동일하며, 진입 시 기존 값이 채워진다.

### 진입 경로

- [CEB-BO-ART-304] 멤버 상세 (기본정보 탭) > [수정하기]
- URL: `/artists/members/{id}/edit`

## 2. UI 설명

### 2.1 상단 헤더

- 타이틀: 멤버 수정
- 우측 상단 액션: [취소하기] / [수정하기]
- [수정하기]는 변경 사항이 없으면 비활성 상태이다.

### 2.2 입력 항목

| 항목 | 필수 | 형식 |
| --- | --- | --- |
| 멤버명 | 필수 | 한국어·영어·일본어, 각 100자 |
| 프로필이미지 | 필수 | 1:1 비율, 최대 5MB. 기존 이미지 표시 + **[변경]**(교체만 — 필수라 제거 없음, [CEB-BO-003] §7.6) |
| 생년월일 | 필수 | 캘린더 날짜 선택 (1900.01.01~오늘, 미래일 선택 불가) |
| 별자리 | 자동 | 생년월일로 자동 도출 (읽기 전용) |
| 키(cm) | 선택 | 정수, 100~250 (0·공백 불가) |
| 소속사 | 선택 | Dropdown — "소속사 없음" + [CEB-BO-ART-202-CP] "사용" 소속사(운영자 노출명 표시) |
| 성별 | 필수 | Dropdown — 남성 / 여성 |
| 멤버소개 | 선택 | 한국어·영어·일본어, 각 255자 |
| 인사말 | 선택 | 한국어·영어·일본어, 각 100자 |
| 취미 | 선택 | 한국어·영어·일본어, 각 100자 |
| 좌우명 | 선택 | 한국어·영어·일본어, 각 100자 |
| 몸무게(kg) | 선택 | 정수, 30~200 (0·공백 불가) |

- 필수 = 멤버명(3언어)·프로필이미지·생년월일·성별. 키·몸무게는 선택(입력 시 정수·범위 검증).

> 시각적 스타일은 프로토타입 참조

### 2.3 확인 모달

| 트리거 | 제목 | 본문 | 버튼 |
| --- | --- | --- | --- |
| [수정하기] | 멤버 수정 | "확인 버튼을 누르면 수정사항이 적용됩니다" / "계속 진행하시겠습니까?" | [다시 돌아가기] / [확인] |

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.

### 4.2 입력 검증

- 멤버명은 한국어·영어·일본어 모두 입력해야 한다. 수정 시에도 생성과 동일한 필수 검증을 적용해, 필수 항목을 비운 상태로는 저장할 수 없다.
- 멤버명·프로필이미지·생년월일·성별은 필수이다(프로필이미지는 교체만 가능, 비울 수 없음).
- 별자리는 생년월일로 자동 계산되며 직접 변경할 수 없다. 생년월일은 미래일을 선택할 수 없다.
- 키·몸무게는 선택이며 입력 시 정수·범위(키 100~250cm·몸무게 30~200kg)를 검증한다.
- **변경 사항이 있을 때만 [수정하기]가 활성화**된다(변경 판정 = 멤버명·이미지·생년월일·성별·키·몸무게·소속사·소개/인사말/취미/좌우명 중 진입 시점 값과 달라진 경우).
