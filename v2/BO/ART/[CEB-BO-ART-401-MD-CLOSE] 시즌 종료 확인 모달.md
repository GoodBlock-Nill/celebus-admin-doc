## 1. 화면 목적

운영자가 **진행중 시즌을 강제 종료(취소·미지급)하기 전 마지막 확인을 받고, 종료 후 데이터 처리 정책 3행을 안내**하는 모달이다. 강제 종료는 되돌릴 수 없고 **보상을 지급하지 않으므로**(정상 지급은 자연 종료=말일 23:59 자동 정산으로만 발생) 신중한 의사결정을 유도한다.

- **누가**: 덕력 운영 권한이 있는 백오피스 관리자
- **왜**: 강제 종료는 잘못 만든 시즌·운영 중단 등 예외 상황에서 시즌을 즉시 취소하는 비가역 행위이므로 명시적 확인 필요
- **결과**: 시즌 상태가 "진행중" → "종료"로 전환되고, **보상은 지급되지 않으며**, 종료 시점까지의 랭킹은 스냅샷으로 보존·조회 가능하고 신규 적립·소비는 다음 시즌에 귀속됨

| 2 | 종료 시점까지의 랭킹은 스냅샷으로 보존되며 조회할 수 있습니다. | 회원이 누적한 덕력 랭킹은 강제 종료 시점 기준 스냅샷으로 보존 — 덕력 랭킹 화면에서 조회 가능(보상만 미지급) |
| 3 | 신규 적립·소비는 다음 시즌에 귀속됩니다. | 강제 종료 이후의 적립·소비는 다음 시즌으로 이관 |

## 3. 화면 내 기능설명

운영자가 이 모달에서 할 수 있는 동작:

1. **종료 정책 확인** — 정산 완료·미정산·랭킹 처리 안내 3행 확인
2. **종료 확정** — [강제 종료] 클릭으로 시즌 종료
3. **취소** — [취소] 또는 [X]로 모달 닫고 시즌 상태 유지

---

## 4. 규칙·로직

### 4.1 모달 진입

1. 시즌 상세에서 [종료] 클릭
2. 본 모달 열림
3. 본문에 대상 시즌의 그룹명·시즌명 표시 + 정책 3행 안내

### 4.2 종료 확정

1. [강제 종료] 클릭
2. 시즌 상태 "진행중" → "종료" 전환 처리
3. 모달 닫기
4. 토스트 "시즌을 강제 종료했습니다."
5. 시즌 상세 화면 자동 갱신 (상태 배지 변경 + [종료] 버튼 미노출 + [수정] 버튼 시즌명만 활성)

### 4.3 취소

1. [취소] 또는 모달 외부 클릭 또는 [X] 클릭
2. 모달 닫기. 시즌 상태 그대로 유지

### 4.4 종료 후 후속 처리 (시스템)

| 데이터 | 처리 |
| --- | --- |
| 보상 | **지급하지 않음** (강제 종료=취소). 정상 지급은 자연 종료 자동 정산으로만 발생 |
| 보상 설정 | 데이터 보존(조회만), 정산·지급 미실행 |
| 시즌 랭킹 | 강제 종료 시점 기준 **스냅샷 보존·조회 가능** ([CEB-BO-ART-401-RANKING]) |
| 신규 적립·소비 | 다음 시즌에 귀속 |

### 4.5 권한별 동작

- 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정에 따른다
- 쓰기 권한 없으면 시즌 상세 상단 [종료] 버튼이 미노출이므로 본 모달은 호출되지 않음
