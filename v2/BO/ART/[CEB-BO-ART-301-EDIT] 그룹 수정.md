## 1. 화면 목적

기존 그룹의 정보를 수정하는 화면. 입력 항목·구성은 [CEB-BO-ART-201-Create] 그룹 생성과 동일하며, 진입 시 기존 값이 채워진다.

### 진입 경로

- [CEB-BO-ART-301] 그룹 상세 (기본정보 탭) > [수정하기]
- URL: `/artists/groups/{id}/edit`

---

## 2. UI 설명

### 2.1 상단 헤더

- 타이틀: 그룹 수정
- 우측 상단 액션: [취소하기] / [수정하기]
- [수정하기]는 변경 사항이 없으면 비활성 상태이다.

### 2.2 입력 항목

| 항목 | 필수 | 형식 |
| --- | --- | --- |
| 그룹명 | 필수 | 한국어·영어·일본어, 각 100자 |
| 그룹 소개 | 필수 | 한국어·영어·일본어, 각 500자 |
| 로고(심볼) | 필수 | 1:1 권장 512×512px, 최대 5MB (jpeg·png·jpg·webp·gif·svg). 기존 이미지 표시 + **[변경]**(교체만) |
| 대표이미지(배너) | 필수 | 16:9 권장 1920×1080px, 최대 5MB. 기존 이미지 표시 + **[변경]**(교체만) |
| Instagram | 선택 | URL |
| X | 선택 | URL |
| YouTube | 선택 | URL |
| TikTok | 선택 | URL |
| Homepage | 선택 | URL |

- 로고·대표이미지는 필수이므로 비워둘 수 없다. 수정 화면에서는 **[변경](다른 이미지로 교체)만 제공**하며 [제거]는 없다([CEB-BO-003] §7.6). 교체 시에도 비율 크롭·형식·5MB 검증을 거친다.
- SNS·Homepage는 선택이며, 입력 시 올바른 URL 형식이어야 한다.

> 시각적 스타일은 프로토타입 참조

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.

### 4.2 입력 검증

- 그룹명·그룹 소개는 한국어·영어·일본어 모두 입력해야 한다. 수정 시에도 생성과 동일한 필수 검증을 적용해, 필수 항목을 비운 상태로는 저장할 수 없다.
- 로고·대표이미지는 필수이다(교체만 가능, 비울 수 없음).
- SNS·Homepage 입력값은 URL 형식을 검증한다.
- **변경 사항이 있을 때만 [수정하기]가 활성화**된다. 변경 판정 대상 = 그룹명·소개(언어별 텍스트)·로고·대표이미지·SNS/Homepage 중 하나라도 진입 시점 값과 달라진 경우.

## 7. 에러·예외 상황

| 상황 | 메시지 |
| --- | --- |
| 필수 미입력 | 해당 항목 인라인 에러 "필수 입력 항목입니다.", [수정하기] 비활성 |
| 다국어 일부 미입력 | 미입력 언어 탭 표시 + 인라인 에러 "한국어·영어·일본어를 모두 입력하세요." |
| URL 형식 오류 | 해당 입력 인라인 에러 "올바른 URL 형식이 아닙니다." |
| 이미지 형식·용량 초과 | 업로드 에러("지원하지 않는 형식입니다. (JPG·PNG·WebP)" / "이미지 용량은 5MB 이하만 등록할 수 있습니다.") |
| 변경 없음 | [수정하기] 비활성 |
| 저장 실패 | Toast (Error): "수정에 실패했습니다." (입력 폼 유지) |
| 미저장 이탈 | [취소하기] 확인 모달 |
