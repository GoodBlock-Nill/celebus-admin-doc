## 1. 화면 목적

운영자가 **아티스트 그룹별·시즌별 회원 덕력 순위**를 조회하는 화면이다. 그룹과 시즌(1개월)을 선택하면 해당 시즌에 획득한 덕력 누적 기준 순위를 확인할 수 있다([CEB-000] §1.4 — 랭킹은 시즌별 획득 덕력 기준).

- **누가**: 덕력 운영·CS·마케팅 권한이 있는 백오피스 관리자
- **왜**: 어떤 회원이 어떤 그룹에 얼마나 활동하는지 확인하고, 보상·이벤트 의사결정에 활용
- **결과**: 그룹·시즌 조건에 맞는 순위 목록을 보고 회원 상세로 이동 가능

## 2. UI 설명

### 2.1 화면 레이아웃

```
[탭 메뉴]  [랭킹 시즌 설정] [덕력 랭킹] [덕력 내역]

────────────────────────────────────────────────────────

[필터 바]
그룹: [V01D ▾]   연도: [2026 ▾]   시즌: [V01D 2026.06 시즌 (진행중) ▾]   회원 검색: [...]

[안내 카드]
V01D · 2026.06 시즌 (진행중) — 활동 회원 N명 · 획득 누적 N,NNN DUK

[랭킹 테이블]
| 순위 | 회원 | 획득 덕력 | 최근 변동일 |
|---|---|---|---|
| ① | 닉네임A | 12,345 DUK | 2026.05.26 17:30 |
| ② | 닉네임B | 11,234 DUK | 2026.05.25 14:05 |
| ③ | 닉네임C | 10,123 DUK | 2026.05.24 21:50 |
| 4 | ...    | ...       | ...               |

[페이지네이션]
```

### 2.2 구성요소

| 영역 | 요소 | 설명 |
| --- | --- | --- |
| 필터 | 그룹 선택 메뉴 | 활성 그룹 5종 중 1종. 기본 첫 번째 그룹 |
| 필터 | **연도 선택 메뉴** | 선택 그룹의 시즌 보유 연도(최신순). 기본 **진행중 시즌의 연도**(없으면 최신) |
| 필터 | **시즌 선택 메뉴** | 선택 연도의 시즌 목록(최신 월 먼저, "{시즌명} ({상태})", 시즌명 한국어). 기본 **진행중 시즌**(없으면 그 연도 최신). 시즌 = 1개월 단위. **강제 종료(미지급) 시즌도 목록에 포함** — 종료 시점 스냅샷 랭킹을 조회할 수 있다(보상만 미지급) |
| 필터 | 회원 검색 | 닉네임 부분 일치 |
| 안내 | 컨텍스트 카드 | 그룹·선택 시즌·상태·활동 회원 수·획득 덕력 합계 한 줄 표시 |
| 리스트 | 랭킹 테이블 | 순위·회원·획득 덕력·최근 변동일 4컬럼 |
| 하단 | 페이지네이션 | 20건/페이지 |

### 2.3 랭킹 테이블 컬럼

| 컬럼 | 표시 |
| --- | --- |
| 순위 | 1·2·3위는 메달 색상 강조 (금·은·동) / 4위 이하는 회색 숫자 |
| 회원 | 회원 닉네임 — 클릭 시 회원 상세 [CEB-BO-USR-201]로 새 창 이동 |
| 획득 덕력 | **해당 시즌에 획득한 덕력 누적** (랭킹 산정 기준, [CEB-000] §1.4). **사용(소비)과 무관하게 획득분만 합산**하며, 사용으로 보유 덕력이 줄어도 랭킹 값은 감소하지 않는다. 천 단위 콤마 + "DUK" |
| 최근 변동일 | 해당 시즌 내 마지막 적립 일시 (YYYY.MM.DD HH:mm) |

### 2.4 시각적 스타일

- 순위 메달: 1위 금색·2위 은색·3위 동색
- 누적 덕력: 보라색 강조 텍스트
- 빈 상태: "해당 필터 조건에 일치하는 회원이 없습니다."

## 3. 화면 내 기능설명

운영자가 이 화면에서 할 수 있는 동작:

1. **그룹별 순위 조회** — 5개 그룹 중 1개 선택
2. **연도 선택** — 선택 그룹의 시즌 보유 연도 중 1개 선택
3. **시즌 선택** — 선택 연도의 시즌(1개월) 목록에서 조회할 시즌 선택
4. **회원 닉네임 검색** — 부분 일치 검색
5. **회원 상세 진입** — 닉네임 클릭 시 새 창으로 이동

---

## 4. 규칙·로직

### 4.1 화면 진입 → 기본 순위 표시

1. 첫 번째 그룹 + 진행중 시즌의 연도(없으면 최신 연도) + 그 연도의 **진행중 시즌**(없으면 최신) 기본 선택
2. 안내 카드에 그룹·선택 시즌·상태 컨텍스트 표시
3. 해당 시즌 획득 덕력 내림차순으로 정렬 후 노출

### 4.2 그룹 변경

1. 그룹 메뉴에서 다른 그룹 선택
2. 해당 그룹의 기본 연도 + 진행중 시즌(없으면 최신)이 자동 선택
3. 순위 테이블·안내 카드 갱신 + 페이지 1로 복귀

### 4.3 연도·시즌 변경

1. 연도 변경 시 → 해당 연도의 기본 시즌(진행중 우선, 없으면 최신)으로 자동 선택
2. 시즌 변경 시 → 해당 시즌(1개월)의 획득 덕력 순위로 테이블·안내 카드 갱신 + 페이지 1로 복귀

### 4.4 회원 닉네임 클릭

1. 새 창으로 회원 상세 [CEB-BO-USR-201] 진입 (기본 탭은 "기본 정보")
2. 현재 랭킹 화면은 그대로 유지

### 4.5 권한별 동작

- 본 화면은 조회 전용 — 모든 운영자 권한에 읽기 권한 부여
- 외부 협력사 권한자는 본인 매핑 소속사 산하 그룹만 조회 가능

### 4.6 동일 누적 덕력 처리

같은 획득 누적 덕력일 경우 **먼저 그 누적에 도달한 회원이 상위 순위**다(도달 시각은 초 단위까지 비교). 동순위 없음, 모두 고유 순위. ([CEB-000] §1.4 랭킹 정의 정합)

집계 귀속: 각 덕력 적립 내역은 **시즌 식별값으로 해당 시즌에 귀속**되어 합산되며(달력상 월이 아니라 시즌 단위), 시즌 기간과 적립 시점이 어긋나도 시즌 귀속 기준을 따른다.

### 4.7 강제 종료 시즌 조회

- 수동 강제 종료(미지급)된 시즌도 시즌 선택 메뉴에 노출되며, **강제 종료 시점 기준 스냅샷 랭킹**을 조회할 수 있다(보상은 미지급).
- 자연 종료(자동 정산) 시즌과 동일하게 순위·획득 덕력을 조회하되, 보상 지급 결과는 [CEB-BO-ART-401-DETAIL] 보상 지급 내역 탭에서 "강제 종료된 시즌으로 지급 내역이 없습니다" 안내로 구분된다.
