## 1. 화면 목적

운영자가 **덕력 운영을 시작하는 진입 페이지**다. 시즌 설정·랭킹 조회·내역 조회 3개 업무를 탭으로 묶어 한 메뉴 안에서 전환할 수 있게 한다.

- **누가**: 덕력 운영·CS·마케팅 권한이 있는 백오피스 관리자
- **왜**: 시즌·랭킹·내역은 같은 도메인의 다른 시점이므로 한 화면에서 빠르게 전환 가능해야 함
- **결과**: 사이드바 진입 시 시즌 설정 탭이 기본 활성화되며, 3개 탭을 자유롭게 전환

### 1.1 덕력 영역 화면 구성

덕력 관리 메뉴는 아래 화면으로 구성된다. 본 화면(덕력 관리)이 진입 허브이며, 각 탭·상세·모달은 별도 명세로 분리되어 있다.

| 구분 | 화면 | 역할 |
| --- | --- | --- |
| 탭 1 | [CEB-BO-ART-401-SEASON] 랭킹 시즌 설정 | 시즌 목록·생성 진입 |
| 탭 2 | [CEB-BO-ART-401-RANKING] 덕력 랭킹 | 회원 덕력 랭킹 조회 (조회 전용) |
| 탭 3 | [CEB-BO-ART-401-HISTORY] 덕력 내역 | 덕력 적립·사용 내역 조회 (조회 전용) |
| 탭 4 | [CEB-BO-ART-401-POLICY] 덕력 지급 정책 | 아티스트 그룹별 자동 적립 활동 덕력 지급량·사용 여부 설정 |
| 상세 | [CEB-BO-ART-401-DETAIL] 시즌 상세 | 시즌 보상 설정·지급 내역 (보상 설정·지급 내역 2개 서브탭) |
| 모달 | [CEB-BO-ART-401-MD-SEASON] 시즌 생성·수정 모달 | 시즌 생성·수정 입력 |
| 모달 | [CEB-BO-ART-401-MD-CLOSE] 시즌 종료 확인 모달 | 시즌 종료 확인 |
| 모달 | [CEB-BO-ART-401-MD-PAYOUT] 지급 상태 변경 모달 | 보상 지급 상태 변경 |

## 3. 화면 내 기능설명

운영자가 이 화면에서 할 수 있는 동작:

1. **4개 탭 전환** — 랭킹 시즌 설정 / 덕력 랭킹 / 덕력 내역 / 덕력 지급 정책
2. **각 탭의 본문 조작** — 본문은 별도 명세 참조

---

## 4. 규칙·로직

### 4.1 화면 진입 → 기본 탭

1. 사이드바 [아티스트] > [덕력관리] 클릭
2. URL `/artists/duk` 진입 시 [랭킹 시즌 설정] 탭이 자동 활성화 (쿼리 `?tab=season`)
3. URL에 `?tab=ranking` 또는 `?tab=history`가 명시되어 있으면 해당 탭이 활성화된 상태로 진입

### 4.2 탭 전환

1. 탭 메뉴에서 다른 탭 클릭
2. URL 쿼리 `?tab=...`가 갱신되며 본문이 해당 탭의 화면으로 교체
3. 각 탭의 필터·페이지 상태는 탭 내부 정책에 따름 (분할 화면 명세 참조)

### 4.3 권한별 동작

- 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정에 따른다
- 덕력 관리 메뉴 자체에 접근 권한이 없으면 사이드바 메뉴 미노출 + 직접 URL 진입 차단
- 각 탭 본문의 쓰기·삭제 권한 분기는 분할 화면 명세에서 정의

## 5. UI 상태별 처리

본 화면은 탭 컨테이너로, 데이터 상태(Loading·Empty·Error)는 각 탭 본문 명세에서 정의한다.

| 상태 | 처리 |
| --- | --- |
| Default | 기본 탭(랭킹 시즌 설정) 활성화, 본문은 해당 탭 명세 |
| 탭 전환 중 | 본문 슬롯이 선택 탭 화면으로 교체 |
| 본문 Loading/Empty/Error | 각 탭 본문 명세의 상태 처리에 따름 |

## 6. 활동 로그

본 화면은 탭 컨테이너 — 활동 로그 대상 아님. 시즌 생성·수정·종료·지급 상태 변경 등 액션 로그는 각 모달 명세([CEB-BO-ART-401-MD-SEASON]·[CEB-BO-ART-401-MD-CLOSE]·[CEB-BO-ART-401-MD-PAYOUT])에서 기록한다.
