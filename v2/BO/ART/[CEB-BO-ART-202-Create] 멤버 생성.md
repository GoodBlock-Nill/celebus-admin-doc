## 1. 화면 목적

신규 아티스트 멤버를 등록하는 화면. 멤버명(다국어)·프로필 이미지·신체 정보·소속사·다국어 소개 항목을 입력해 생성한다.

### 진입 경로

- [CEB-BO-ART-202] 멤버 리스트 > [멤버 생성]
- URL: `/artists/members/create`

---

## 2. UI 설명

### 2.1 상단 헤더

- 타이틀: 멤버 생성
- 우측 상단 액션: [취소하기] / [생성하기]
- [생성하기]는 필수 항목 미충족 시 비활성 상태이다.

### 2.2 입력 항목

| 항목 | 필수 | 형식 |
| --- | --- | --- |
| 멤버명 | 필수 | 한국어·영어·일본어, 각 100자 (3언어 모두 입력해야 생성 가능) |
| 프로필이미지 | 필수 | 1:1 비율, 최대 5MB (JPG·PNG·WebP). 등록 시 1:1 크롭 ([CEB-BO-003] §7.6) |
| 생년월일 | 필수 | 캘린더 날짜 선택 (1900.01.01~오늘, 미래일 선택 불가) |
| 별자리 | 자동 | 생년월일 입력 시 자동 도출 (표준 12별자리, [CEB-BO-003] §7.2 경계표. 읽기 전용, 직접 선택 불가) |
| 키(cm) | 선택 | 정수, 100~250 (0·공백 불가) |
| 소속사 | 선택 | Dropdown — "소속사 없음" + [CEB-BO-ART-202-CP] 등록 소속사 중 "사용" 소속사(운영자 노출명 표시). 기본값 "소속사 없음" |
| 성별 | 필수 | Dropdown — 남성 / 여성 |
| 멤버소개 | 선택 | 한국어·영어·일본어, 각 255자 |
| 인사말 | 선택 | 한국어·영어·일본어, 각 100자 |
| 취미 | 선택 | 한국어·영어·일본어, 각 100자 |
| 좌우명 | 선택 | 한국어·영어·일본어, 각 100자 |
| 몸무게(kg) | 선택 | 정수, 30~200 (0·공백 불가) |

- 필수 = 멤버명(3언어)·프로필이미지·생년월일·성별. 키·몸무게는 선택이며, 입력 시 정수·범위를 검증한다.

> 시각적 스타일은 프로토타입 참조

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.

### 4.2 입력 검증

- 멤버명은 한국어·영어·일본어를 모두 입력해야 한다(셋 중 하나라도 비면 생성 불가).
- 프로필이미지·생년월일·성별은 필수이다. 프로필이미지는 1:1 크롭·형식·5MB 검증을 통과해야 한다.
- 생년월일은 캘린더에서 선택하며 미래일은 선택할 수 없다. 별자리는 생년월일로 자동 계산되어 표시되며 직접 선택할 수 없다.
- 키·몸무게는 선택이며, 입력 시 정수여야 하고 키 100~250cm·몸무게 30~200kg 범위를 벗어나면 인라인 에러로 차단한다.
- 필수 항목이 모두 충족되고 입력 검증을 통과해야 [생성하기]가 활성화된다.

## 7. 에러·예외 상황

| 상황 | 메시지 |
| --- | --- |
| 필수 미입력 | 해당 항목 인라인 에러 "필수 입력 항목입니다.", [생성하기] 비활성 |
| 멤버명 일부 언어 누락 | 미입력 언어 탭 표시 + 인라인 에러 "한국어·영어·일본어를 모두 입력하세요.", [생성하기] 비활성 |
| 키 범위 벗어남 | 인라인 에러 "100~250cm 사이로 입력하세요." |
| 몸무게 범위 벗어남 | 인라인 에러 "30~200kg 사이로 입력하세요." |
| 미래 생년월일 선택 | 미래일은 선택 불가(달력에서 비활성) |
| 이미지 형식 오류 | 업로드 에러 "지원하지 않는 형식입니다. (JPG·PNG·WebP)" |
| 이미지 용량 초과 | 업로드 에러 "이미지 용량은 5MB 이하만 등록할 수 있습니다." |
| 생성 실패 | Toast (Error): "멤버 생성에 실패했습니다." (입력 폼 유지) |
