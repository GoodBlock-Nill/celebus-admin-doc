## 1. 화면 목적

라이브러리에 감정 이모지를 **등록**하거나 기존 이모지를 **수정**하는 입력 모달이다. 등록·수정 겸용으로, 호출 맥락에 따라 빈 폼 또는 기존 값으로 진입한다.

---

## 2. UI 설명

### 2.1 모달 구성

| 영역 | 내용 |
| --- | --- |
| 헤더 | "감정 이모지 등록" (등록) / "감정 이모지 수정" (수정) + [✕] 닫기 |
| 이미지 | 정사각형 이미지 업로드(JPG·PNG·WebP·5MB 이하, 필수) + 미리보기 |
| 감정 라벨 | 한국어·영어·일본어 언어 전환 입력(각 20자, 3언어 필수, **중복 허용**). 미입력 언어 탭에 빨간 점 |
| 수정 시 영향 안내 | (수정 모드) "이 이모지를 연결한 {N}개 아티스트의 앱 표시에 즉시 반영됩니다." 안내 |
| 푸터 | [취소] / [저장] |

> 시각적 스타일은 프로토타입 참조

| [취소] / [✕] | 입력 폐기 후 닫기 |

---

## 4. 규칙·로직

- 항목은 **커스텀 이미지 업로드 전용**(정사각형 권장·JPG·PNG·WebP·5MB 이하)으로 등록한다.
- 등록 모드: 빈 폼. 저장 시 라이브러리에 새 이모지로 추가된다(아티스트 연결은 별도 — [CEB-BO-MEM-501]).
- 수정 모드: 기존 이미지·라벨을 프리필. 저장 시 해당 항목만 갱신한다.
- 라벨은 한국어·영어·일본어 **3언어 모두 필수**. **라벨 중복 허용**.
- 이미지·라벨은 **전역 공유 속성**이므로, **수정은 이 이모지를 연결한 모든 아티스트의 앱 표시에 즉시 반영**된다([CEB-BO-MEM-501]의 작업본 적용과 무관).
- 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
