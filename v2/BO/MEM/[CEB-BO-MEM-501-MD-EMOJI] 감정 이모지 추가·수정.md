## 1. 화면 목적

선택한 아티스트 세트에 감정 이모지를 **추가**하거나 기존 이모지를 **수정**하는 입력 모달이다. 추가·수정 겸용으로, 호출 맥락에 따라 빈 폼 또는 기존 값으로 진입한다.

---

## 2. UI 설명

### 2.1 모달 구성

| 영역 | 내용 |
| --- | --- |
| 헤더 | "감정 이모지 추가" (추가) / "감정 이모지 수정" (수정) + [✕] 닫기 |
| 이모지 방식 | OS 유니코드 이모지 / 커스텀 이미지 중 선택. **옵션 카드(라디오)** — 각 카드에 아이콘 + 명칭 + 한 줄 설명, 선택 카드 강조 |
| 이모지 / 이미지 | 이모지 방식: 미리보기 + 입력란(유니코드, 필수). 이미지 방식: 정사각형 이미지 업로드(JPG·PNG·WebP·5MB 이하, 필수) |
| 감정 라벨 | 한국어·영어·일본어 언어 전환 입력(각 20자, 3언어 필수, **중복 허용**). 미입력 언어 탭에 빨간 점 |
| 사용여부 | 사용 / 미사용 토글. 사용 상한(6) 여유 있으면 추가 시 기본 사용, 도달 시 ON 비활성(미사용 등록) |
| 푸터 | [취소] / [저장] |

> 시각적 스타일은 프로토타입 참조

---

## 4. 규칙·로직

- 항목은 **OS 유니코드 이모지** 또는 **커스텀 이미지**(정사각형 권장·JPG·PNG·WebP·5MB 이하) 중 한 방식으로 등록한다(방식 옵션 카드로 전환).
- 추가 모드: 빈 폼. 저장 시 세트의 마지막 순서로 추가된다.
- 수정 모드: 기존 방식·이모지/이미지·라벨·사용여부를 프리필. 저장 시 해당 항목만 갱신(순서·사용 중 여부는 유지).
- 동일 세트 안에서 **유니코드 이모지 중복 금지**(이미지 방식 제외, 수정 시 자기 자신 제외). **라벨은 중복 허용**.
- 라벨은 한국어·영어·일본어 **3언어 모두 필수**.
- 사용여부는 세트 사용 상한(최대 6종) 여유가 있을 때만 ON 가능. 도달 시 사용여부 ON 비활성(미사용으로만 등록).
- 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
