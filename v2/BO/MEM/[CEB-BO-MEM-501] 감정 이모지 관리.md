## 1. 화면 목적

회원이 기억저장소에서 기억을 작성할 때 선택하는 **감정 이모지 세트를 아티스트별로 등록·관리**하는 화면이다.

- **누가**: 기억저장소 운영 권한이 있는 백오피스 관리자
- **왜**: 감정 이모지는 아티스트마다 다르게 운영하며, 앱에 노출되는 종류·라벨·순서를 운영자가 직접 관리해야 함. 항목은 OS 유니코드 이모지 또는 커스텀 이미지로 등록
- **결과**: 선택한 아티스트의 감정 이모지 세트를 추가·수정·삭제·순서 변경하고, 사용여부를 전환

## 4. 규칙·로직

### 4.1 아티스트별 세트

- 감정 이모지는 **아티스트(그룹)별로 별도 세트**를 운영한다.
- 신규 아티스트는 기본 6종 프리셋(설렘·감동·신남·사랑·어마·행복)으로 시작하며, 운영자가 추가·수정·삭제할 수 있다.

### 4.2 이모지 방식·수량

- 각 항목은 **OS 유니코드 이모지 입력** 또는 **커스텀 이미지 업로드** 중 한 방식으로 등록한다.
  - 커스텀 이미지: 정사각형(1:1) 권장, JPG·PNG·WebP, 5MB 이하.
- 라벨은 한국어·영어·일본어 3언어를 입력한다(각 20자). **라벨은 중복 허용**(동일 라벨 가능).
- 세트당 **등록 최대 40종**까지 가능하며, 그중 **사용(앱 노출)은 최대 6종**까지만 허용한다(앱 감정 선택지 가독성).
  - 등록 40종 도달 시 [감정 이모지 추가] 비활성. 사용 6종 도달 시 추가 사용 전환 차단(미사용으로만 추가·전환).
- 한 세트 안에서 동일 유니코드 이모지는 중복 등록할 수 없다(이미지 방식은 개별 파일, 라벨은 중복 허용).

### 4.3 표시 순서

- 세트의 표시 순서가 **앱 감정 선택지 노출 순서**가 된다.
- 위로/아래로 버튼으로 순서를 변경한다.

### 4.4 사용여부·삭제

- **사용**: 앱 감정 선택지에 노출. **미사용**: 앱 선택지에서 숨김(기존 기억 기록의 이모지 표시는 보존).
- **삭제 가능 조건**: 사용여부가 **미사용**이고 **회원 사용 이력이 없는** 이모지만 [삭제]할 수 있다. 아래는 [삭제] 버튼이 **비활성**된다(버튼 툴팁으로 사유 안내).
  - 사용여부가 **사용**인 이모지 → 먼저 미사용으로 전환해야 삭제 후보가 된다.
  - **회원이 이미 사용한 이모지** → 미사용 전환만 가능하고 삭제 불가(기억 기록 보존).

### 4.5 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- 추가·수정·삭제·순서 변경·사용여부 변경은 쓰기 권한 그룹만 사용한다.

### 4.6 적용(게시) 정책

- BO 화면의 모든 편집(추가·수정·삭제·순서 변경·사용여부 토글)은 **임시(작업본)로만 누적**되며, **편집 즉시 앱에 반영되지 않는다.**
- 운영자가 **[변경사항 적용]**을 누르면, 선택한 아티스트 세트 전체가 **원자적으로 앱에 반영(게시)**된다([CEB-BO-MEM-501-MD-APPLY]).
- 적용 전까지 앱은 **직전 적용본**을 그대로 노출한다(작업 중 회원 화면 흔들림 방지).
- **[되돌리기]**는 미적용 변경을 **마지막 적용본**으로 복원한다(작업 내용 폐기).
- 미적용 변경이 0건이면 [변경사항 적용]·[되돌리기]는 비활성. 아티스트별로 작업본·미적용 변경을 독립 관리한다.
