## 1. 화면 목적

세트에서 감정 이모지를 삭제하기 전 확인하는 모달이다. 비가역 작업이므로 운영자 확인을 거친다.

---

## 2. UI 설명

| 영역 | 내용 |
| --- | --- |
| 헤더 | "감정 이모지 삭제" |
| 본문 | "'{라벨}' {이모지} 이모지를 삭제할까요?" + "{아티스트명} 세트에서 제거되며 복구할 수 없습니다." |
| 푸터 | [취소] / [삭제] |

> 시각적 스타일은 프로토타입 참조

---

## 3. 화면 내 기능설명

| 요소 | 동작 |
| --- | --- |
| [삭제] | 세트에서 해당 이모지 제거 + 모달 닫기 + 완료 토스트 |
| [취소] / 배경 | 모달 닫기 (삭제 안 함) |

---

## 4. 규칙·로직

- 호출 화면([CEB-BO-MEM-501])에서 **사용여부가 미사용이고 회원 사용 이력이 없는** 이모지만 [삭제] 버튼이 활성화되어 본 모달로 진입한다.
- 다음은 [삭제] 버튼이 **비활성**이므로 본 모달에 진입하지 않는다(버튼 툴팁으로 사유 안내).
  - 사용여부가 **사용**인 이모지 → 먼저 미사용으로 전환해야 함.
  - **회원이 이미 사용한 이모지** → 미사용 전환만 가능, 삭제 불가(기억 기록 보존).
- 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
