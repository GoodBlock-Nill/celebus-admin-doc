## 1. 개요

기억저장소 운영(MEM) 영역의 **현재 구현 범위는 감정 이모지 관리**다. 회원이 앱에서 기억을 작성할 때 선택하는 **감정 이모지 세트를 아티스트별로 등록·관리**한다. 회원 작성·게시는 v2 APP에서 이뤄지며, BO는 감정 이모지 세트 설정과 앱 반영(적용)을 담당한다.

| 항목 | 위치 |
| --- | --- |
| 마스터 가이드 | [CEB-BO-001] §2 (#6 MEM) |
| 영역 ID | `CEB-BO-MEM-{번호}` |
| 권한 | [CEB-BO-SYS-102] 권한 관리 그룹 설정 참조 |
| 감정 이모지 규격 | [CEB-000] 공통 정책 §7.5 (단일 기준) |
| 활동 로그 | [CEB-BO-000] §6 |
| 앱 연동 | [CEB-MEM-201] 기억 작성 (감정 이모지 선택) |

> 신고·차단 등 그 밖의 기억저장소 운영 기능은 **추후 기획 예정(미구현)** 이며, 본 가이드에는 포함하지 않는다.

## 3. 권한

- 화면별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- 감정 이모지 등록·수정·삭제·순서 변경·사용여부 변경·[변경사항 적용]은 쓰기 권한 그룹이 수행한다.
- 외부 협력사 권한 그룹의 접근 범위도 [CEB-BO-SYS-102] 설정을 따른다.

## 4. 영역 고유 정책

### 4.1 감정 이모지 정책

- 회원이 기억 작성 시 선택하는 감정 이모지는 **아티스트별 세트**로 운영하며, BO에서 추가·수정·삭제·순서 변경한다.
- 규격(OS 유니코드 이모지 또는 커스텀 이미지·기본 6종 프리셋·등록 최대 40종/사용 최대 6종·아티스트별 세트·한국어·영어·일본어 라벨)은 [CEB-000] §7.5를 단일 기준으로 따른다. 관리 화면은 [CEB-BO-MEM-501] 감정 이모지 관리.
- BO 편집은 **[변경사항 적용] 시에만 앱에 반영**된다(편집 즉시 자동 반영 아님). 적용 전까지 앱은 직전 적용본을 노출한다.
- 사용여부가 **사용**이거나 **회원 사용 이력이 있는** 이모지는 삭제할 수 없다(미사용 전환만 가능 — 기존 기억 기록 보존).
