## 1. 개요

기억저장소 운영(MEM) 영역의 **현재 구현 범위는 감정 이모지 관리**다. 회원이 앱에서 기억을 작성할 때 선택하는 **감정 이모지를 전역 라이브러리에 등록하고 아티스트별로 연결·관리**한다. 회원 작성·게시는 v2 APP에서 이뤄지며, BO는 감정 이모지 등록·연결 설정과 앱 반영(적용)을 담당한다.

| 항목 | 위치 |
| --- | --- |
| 마스터 가이드 | [CEB-BO-001] §2 (#6 MEM) |
| 영역 ID | `CEB-BO-MEM-{번호}` |
| 권한 | [CEB-BO-SYS-102] 권한 관리 그룹 설정 참조 |
| 감정 이모지 규격 | [CEB-000] 공통 정책 §7.5 (단일 기준) |
| 관리 화면 | 연결 [CEB-BO-MEM-501] · 라이브러리 [CEB-BO-MEM-502] |
| 활동 로그 | [CEB-BO-000] §6 |
| 앱 연동 | [CEB-MEM-201] 기억 작성 (감정 이모지 선택) |

> 신고·차단 등 그 밖의 기억저장소 운영 기능은 **추후 기획 예정(미구현)** 이며, 본 가이드에는 포함하지 않는다.

## 4. 영역 고유 정책

### 4.1 감정 이모지 정책

- 감정 이모지는 **전역 라이브러리에 1회 등록**([CEB-BO-MEM-502])하고, 회원이 기억 작성 시 선택하도록 **아티스트별로 연결**([CEB-BO-MEM-501])한다. 같은 이모지를 여러 아티스트가 재업로드 없이 공유한다.
- 규격(**커스텀 이미지 업로드 전용**·기본 제공 이미지 6종·연결 최대 40종/사용 최대 6종·한국어·영어·일본어 라벨)은 [CEB-000] §7.5를 단일 기준으로 따른다.
- **데이터 2층 분리**: 라이브러리 속성(이미지·라벨)은 전역 공유 — 수정 시 연결된 모든 아티스트에 즉시 반영. 연결 속성(표시 순서·사용여부)은 아티스트별 독립.
- 아티스트별 **연결 구성·순서·사용여부** 편집은 **[변경사항 적용] 시에만 앱에 반영**된다(편집 즉시 자동 반영 아님). 적용 전까지 앱은 직전 적용본을 노출한다. 단, 라이브러리 이미지·라벨 수정은 즉시 전역 반영된다.
- **삭제 2단계**: ① 연결 해제([CEB-BO-MEM-501-MD-UNLINK]) = 해당 아티스트에서만 제거(라이브러리 보존, 사용여부 미사용일 때만) ② 라이브러리 삭제([CEB-BO-MEM-502-MD-DELETE]) = 전역 제거(연결 아티스트 0 + 회원 사용 이력 없음일 때만). 회원 사용 이력이 있으면 기억 기록 보존을 위해 전역 삭제 불가.
