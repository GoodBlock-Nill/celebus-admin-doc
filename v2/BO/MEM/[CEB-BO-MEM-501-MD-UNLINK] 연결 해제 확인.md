## 1. 화면 목적

선택 아티스트 세트에서 감정 이모지를 **연결 해제**하기 전 확인하는 모달이다. 연결 해제는 해당 아티스트에서만 제거하며 라이브러리 이모지는 보존된다.

---

| --- | --- |
| 헤더 | "연결 해제" |
| 본문 | "'{라벨}' 이모지를 {아티스트명} 세트에서 연결 해제할까요?" + "라이브러리에는 보존되며, 다른 아티스트 연결과 회원 기록에는 영향이 없습니다." |
| 푸터 | [취소] / [연결 해제] |

## 3. 화면 내 기능설명

| 요소 | 동작 |
| --- | --- |
| [연결 해제] | 세트에서 해당 이모지 연결 제거(작업본 누적) + 모달 닫기 + 완료 토스트 |
| [취소] / 배경 | 모달 닫기 (연결 해제 안 함) |

---

## 4. 규칙·로직

- 호출 화면([CEB-BO-MEM-501])에서 **사용여부가 미사용인** 이모지만 [연결 해제] 버튼이 활성화되어 본 모달로 진입한다.
  - 사용여부가 **사용**인 이모지 → 먼저 미사용으로 전환해야 한다([연결 해제] 버튼 비활성, 툴팁 안내).
- 연결 해제는 **해당 아티스트 세트에서만 제거**하며, **라이브러리 이모지·다른 아티스트 연결·회원 기억 기록은 보존**된다.
- 라이브러리에서 이모지 자체를 전역 삭제하려면 [CEB-BO-MEM-502-MD-DELETE]를 사용한다.
- 연결 해제는 작업본에 누적되며, 앱 반영은 [CEB-BO-MEM-501]의 [변경사항 적용] 시점이다.
- 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
