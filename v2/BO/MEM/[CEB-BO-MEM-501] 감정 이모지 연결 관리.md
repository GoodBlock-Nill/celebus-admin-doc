## 1. 화면 목적

회원이 기억저장소에서 기억을 작성할 때 선택하는 **감정 이모지를 아티스트별로 연결·구성**하는 화면이다.

- **누가**: 기억저장소 운영 권한이 있는 백오피스 관리자
- **왜**: 감정 이모지는 아티스트마다 다르게 운영한다. 전역 라이브러리에 등록된 이모지를 아티스트에 **연결**하고, 앱에 노출되는 **표시 순서·사용여부**를 운영자가 직접 관리해야 함
- **결과**: 선택한 아티스트에 이모지를 연결·연결 해제하고, 표시 순서·사용여부를 변경한 뒤 [변경사항 적용]으로 앱에 게시

> 이모지 이미지·라벨의 등록·수정·삭제는 이 화면이 아니라 [CEB-BO-MEM-502] 감정 이모지 라이브러리에서 수행한다.

## 4. 규칙·로직

### 4.1 아티스트별 연결

- 감정 이모지는 **전역 라이브러리에 등록**하고, 본 화면에서 **아티스트(그룹)별로 연결**한다.
- 같은 이모지를 여러 아티스트가 공유하며, 재업로드·재등록 없이 연결만 추가한다.
- 신규 아티스트는 **기본 제공 이미지 6종**(설렘·감동·신남·사랑·우와·행복)이 자동 연결된 상태로 시작하며, 운영자가 추가 연결·연결 해제·순서·사용여부를 조정할 수 있다.

### 4.2 연결 수량

- 아티스트별 **연결 최대 40종**까지 가능하며, 그중 **사용(앱 노출)은 최대 6종**까지만 허용한다(앱 감정 선택지 가독성).
  - 연결 40종 도달 시 [이모지 연결] 비활성. 사용 6종 도달 시 추가 사용 전환 차단(미사용으로만 연결·유지).
- 동일 라이브러리 이모지는 한 아티스트에 **중복 연결할 수 없다**(연결 모달에서 이미 연결된 항목은 선택 비활성).

### 4.3 표시 순서

- 세트의 표시 순서가 **앱 감정 선택지 노출 순서**가 된다.
- 위로/아래로 버튼으로 순서를 변경한다.

### 4.4 사용여부·연결 해제

- **사용**: 앱 감정 선택지에 노출. **미사용**: 앱 선택지에서 숨김(기존 기억 기록의 이모지 표시는 보존).
- **연결 해제 가능 조건**: 사용여부가 **미사용**인 이모지만 [연결 해제]할 수 있다. 사용 중인 이모지는 먼저 미사용으로 전환해야 한다.
  - 연결 해제는 **해당 아티스트 세트에서만 제거**하며, 라이브러리의 이모지 자체는 보존된다(다른 아티스트 연결·회원 기록 영향 없음).
  - 라이브러리에서 이모지 자체를 삭제하는 것은 [CEB-BO-MEM-502-MD-DELETE]에서 별도로 처리한다(전역 삭제).

### 4.5 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- 연결·연결 해제·순서 변경·사용여부 변경·[변경사항 적용]은 쓰기 권한 그룹만 사용한다.

### 4.6 적용(게시) 정책

- 본 화면의 편집(연결·연결 해제·순서 변경·사용여부 토글)은 **임시(작업본)로만 누적**되며, **편집 즉시 앱에 반영되지 않는다.**
- 운영자가 **[변경사항 적용]**을 누르면, 선택한 아티스트 세트 전체가 **원자적으로 앱에 반영(게시)**된다([CEB-BO-MEM-501-MD-APPLY]).
- 적용 전까지 앱은 **직전 적용본**을 그대로 노출한다(작업 중 회원 화면 흔들림 방지).
- **[되돌리기]**는 미적용 변경을 **마지막 적용본**으로 복원한다(작업 내용 폐기).
- 미적용 변경이 0건이면 [변경사항 적용]·[되돌리기]는 비활성. 아티스트별로 작업본·미적용 변경을 독립 관리한다.
- 단, **라이브러리의 이미지·라벨 수정**은 [CEB-BO-MEM-502]에서 **즉시 전역 반영**되며, 본 화면의 작업본 적용과 무관하다(연결된 모든 아티스트의 앱 표시에 곧바로 적용).
