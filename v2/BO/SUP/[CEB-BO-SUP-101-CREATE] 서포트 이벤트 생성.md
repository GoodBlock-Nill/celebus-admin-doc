## 1. 화면 목적

서포트 이벤트 1건을 신규 작성한다. 작성 완료 시 **임시저장** 상태로 생성되며, 게시는 상세([CEB-BO-SUP-201])에서 별도로 수행한다(래플·게임존과 동일한 2단계 흐름).

| 항목 | 값 |
| --- | --- |
| 화면 경로 | `/artists/support/new` |
| 진입 경로 | [CEB-BO-SUP-101] 리스트 [이벤트 생성] |
| 생성 결과 | 임시저장 상태로 저장 → 리스트로 복귀 |

---

## 2. 입력 폼

### A. 기본 정보 (다국어)

| 필드 | 한국어 | 영어 | 일본어 | 글자수 |
| --- | --- | --- | --- | --- |
| 이벤트명 | 필수 | 필수 | 필수 | 50자 |
| 설명 | 필수 | 필수 | 필수 | 500자 |

> 다국어 입력 칸은 한국어/영어/일본어를 한 줄로 나란히 배치하며, 미입력 언어 칸은 **빨간 점 누락 표시**로 안내한다. 한 언어라도 비면 [생성하기] 검증을 통과하지 못한다.

### B. 대상·목표

| 필드 | 입력 방식 | 규격 |
| --- | --- | --- |
| 그룹(아티스트) | 드롭다운 | 활성 아티스트 목록에서 선택. 필수 |
| 목표 응원량 | 숫자 입력 | 1 이상 정수 (덕력 단위). 필수 |

> 응원은 보유 덕력 1:1 차감이므로 별도 응원 단가는 없다. 목표 응원량(덕력)만 설정한다.

### C. 일정

| 필드 | 입력 방식 | 규격 |
| --- | --- | --- |
| 시작일시 | 날짜+시간 (KST) | 필수. 게시 후 도달 시 모집 시작 |
| 마감일시 | 날짜+시간 (KST) | 필수. 시작일시 이후. 도달 시 미달성이면 자동 미달성종료(전액 반환) |

### D. 대표 이미지 (필수)

| 항목 | 값 |
| --- | --- |
| 필수 여부 | **[생성하기] 시 필수** (미업로드 시 생성 차단) |
| 권장 비율 | **16:9 (가로)** — 업로드 시 16:9로 자르기(크롭) |
| 허용 형식 | JPG / PNG / WEBP |
| 최대 용량 | **개당 5MB** ([CEB-BO-000] 이미지 정책) |
| 미리보기 | 업로드 즉시 미리보기 + 파일명·[제거]로 교체 |
| 거부 처리 | 형식·용량 초과 파일은 거부하고 "허용되지 않는 파일입니다." 안내 |

### E. 아티스트 홈 카드

서포트가 아티스트 홈에 노출되는 카드. 생성 시 함께 입력한다(미팅 정합 2026-06-02).

| 필드 | 입력 방식 | 규격 |
| --- | --- | --- |
| 카드 이미지 | 이미지 업로드 | **필수**. **1:1 비율 아이콘 이미지** — 홈 카드 안에 이미지 전체가 표시된다(배경 채움이 아닌 아이콘 표시). 업로드 시 1:1로 자르기(크롭), JPG/PNG/WEBP, 개당 5MB. 형식·용량 초과 시 거부 |
| 카드 타이틀 (한국어/영어/일본어) | 텍스트 | **필수**, 각 30자 |
| 카드 서브타이틀 (한국어/영어/일본어) | 텍스트 | 선택, 각 50자 |

### F. 유의사항

| 필드 | 입력 방식 | 규격 |
| --- | --- | --- |
| 유의사항 (한국어/영어/일본어) | 텍스트 | 선택, 각 500자. 응원 전 안내·환불 조건 등. 앱 상세에 노출 |

## 4. 검증 규칙

| 검증 시점 | 검증 항목 |
| --- | --- |
| [임시저장] | 이벤트명 한국어 최소 입력 (그 외 항목 추후 보강 가능) |
| [생성하기] | **기본 정보 다국어 + 그룹 + 목표 응원량 + 시작·마감일시 + 대표 이미지 + 아티스트 홈 카드(이미지·타이틀) 필수** — 이벤트명·설명 한국어/영어/일본어 + 그룹 + 목표 응원량 1 이상 정수 + 시작·마감일시(마감 > 시작) + 대표 이미지 + **카드 이미지(1:1 아이콘) + 카드 타이틀 한국어/영어/일본어**. 카드 서브타이틀·유의사항은 선택. 미충족 시 [생성하기] 비활성 + 누락 항목 안내 |

### 필수·검증 상세

| 항목 | 검증 룰 |
| --- | --- |
| 이벤트명·설명 (다국어) | 한국어/영어/일본어 모두 입력. 미입력 언어 칸은 빨간 점 표시 |
| 그룹(아티스트) | 활성 아티스트 목록에서 1개 선택 (미선택 차단) |
| 목표 응원량 | 1 이상 정수(덕력). 0·공백·비정수 차단 |
| 시작·마감일시 | 둘 다 입력 + 마감 > 시작. 마감 ≤ 시작이면 차단 |
| 대표 이미지 | 16:9 크롭·JPG/PNG/WEBP·5MB. 미업로드 시 차단, 형식·용량 초과 거부 |
| 카드 이미지 | 1:1 아이콘·JPG/PNG/WEBP·5MB. 미업로드 시 차단, 형식·용량 초과 거부 |
| 카드 타이틀 (다국어) | 한국어/영어/일본어 모두 입력 (각 30자). 미입력 차단 |
| 카드 서브타이틀·유의사항 | 선택 (미입력 허용) |

- 위 필수 항목이 하나라도 미충족이면 [생성하기]는 비활성 상태이며, 화면 하단에 누락 항목을 한국어로 안내한다.

## 5. 시점별 동작

| 상황 | 동작 |
| --- | --- |
| [임시저장] 클릭 | 이벤트명 한국어 검증 → 임시저장 저장 + 리스트 복귀 + 토스트 (Success) "임시저장되었습니다 (이벤트명 외 항목은 추후 보강 가능)" |
| [생성하기] 클릭 | 필수 검증 통과 시에만 활성 → 임시저장 상태로 저장 + 리스트 복귀 + 토스트 (Success) "서포트 이벤트가 생성되었습니다 (게시 전 임시저장 상태)" |
| [취소] 클릭 | 입력값이 있으면(dirty) [CEB-BO-SUP-101-MD-CANCEL] 생성 취소 확인 모달 노출 → [나가기] 시 입력값 폐기 + 리스트 복귀. 입력값이 없으면 모달 없이 즉시 리스트 복귀 |
| 검증 실패 | [생성하기] 비활성 유지 + 하단 누락 항목 안내. 이미지·다국어 형식 위반은 인라인 거부 안내 |
| 권한 없음 | [CEB-BO-SYS-102] 설정에 따라 화면 미노출 또는 버튼 비활성 |
