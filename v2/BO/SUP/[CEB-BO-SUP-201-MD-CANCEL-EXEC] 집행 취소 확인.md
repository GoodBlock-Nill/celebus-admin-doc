## 1. 화면 목적

운영자가 **달성·집행중 이벤트의 집행을 취소(집행취소 전환)하기 전 확인**을 받는 모달이다. 집행 취소 시 응원 회원 전원에게 응원 덕력이 전액 자동 반환된다.

- **누가**: 서포트 운영 권한이 있는 백오피스 관리자
- **왜**: 집행 취소는 전액 반환을 유발하는 비가역 행위이므로 반환 규모를 보여주고 명시적 확인 필요
- **결과**: 이벤트 상태가 "달성·집행중" → "집행취소"로 전환되고, 응원 회원 전원에게 전액 자동 반환됨

## 2. UI 설명

### 2.1 모달 레이아웃

```
┌───────────────────────────────────────────────┐
│ 집행을 취소할까요?                       [X]  │
├───────────────────────────────────────────────┤
│                                               │
│  ⚠ 응원 회원 {N}명에게 {N} 덕력이            │
│     전액 반환됩니다.                          │
│                                               │
├───────────────────────────────────────────────┤
│                    [취소]   [집행 취소]       │
└───────────────────────────────────────────────┘
```

### 2.2 노출 조건

- [CEB-BO-SUP-201] 기본정보 탭 헤더 [집행 취소] 액션 클릭 시 노출.
- 달성·집행중 상태에서만 [집행 취소] 버튼이 노출되므로 본 모달도 두 상태에서만 호출된다.

### 2.3 본문 구성

| 영역 | 내용 |
| --- | --- |
| 타이틀 | "집행을 취소할까요?" |
| 반환 안내 (강조) | "응원 회원 {N}명에게 {N} 덕력이 전액 반환됩니다." — 반환 규모 강조 |

#### {N} 산출 시점 (스냅샷)

- 응원 회원 수 {N}명·반환 덕력 {N}은 **모달 진입(액션 버튼 클릭) 시점의 누적 응원자 수·누적 응원 덕력 스냅샷**이다([CEB-BO-SUP-201] §4.3).
- 달성·집행중에서는 추가 응원이 차단되므로 모달 표기값과 실제 반환액이 일치한다.

### 2.4 푸터

| 액션 | 동작 |
| --- | --- |
| [취소] | 모달 닫기. 이벤트 상태 유지 (달성·집행중) |
| [집행 취소] | 위험 강조 색상. 달성·집행중 → 집행취소 전환 + 전액 자동 반환 + 성공 토스트 "집행을 취소하고 전액 반환했습니다." |

## 3. 기능 설명

1. **반환 규모 확인** — 반환 대상 회원 수·반환 덕력 확인
2. **집행 취소 확정** — [집행 취소] 클릭으로 집행취소 전환 + 전액 반환
3. **취소** — [취소]/[X]/외부 클릭으로 모달 닫고 상태 유지

---

## 4. 로직·플로우

### 4.1 모달 진입

1. 기본정보 탭에서 [집행 취소] 클릭
2. 진입 시점 누적 응원자 수·누적 응원 덕력 스냅샷으로 {N} 표기
3. 본 모달 열림

### 4.2 집행 취소 확정

1. [집행 취소] 클릭
2. 상태 "달성·집행중" → "집행취소" 전환
3. 응원 회원 전원에게 응원 덕력 즉시 전액 자동 반환 (서버 처리, 반환 사유 "집행 취소" 기록)
4. 모달 닫기
5. 토스트 "집행을 취소하고 전액 반환했습니다."
6. 상세 화면 자동 갱신 (상태 배지·반환 현황 갱신, 헤더 액션 없음)

### 4.3 취소

1. [취소] 또는 모달 외부 클릭 또는 [X] 클릭
2. 모달 닫기. 기존 상태 유지

## 5. 검증·예외 상황

### 5.1 사전 조건

- 집행 취소 가능한 이벤트는 "달성·집행중" 상태만 가능.
- 처리 시점 상태가 달성·집행중이 아니면(경합으로 이미 완료/취소/종료됨) 서버가 거부하고 "이미 상태가 변경되었습니다. 새로고침 후 다시 시도하세요." 토스트로 안내한다([CEB-BO-SUP-201] §4.2).

### 5.2 반환 실패·부분 실패

- 반환은 서버 자동 일괄 처리한다. 일부 회원 반환이 실패하면 해당 회원 상태가 "반환 보류"로 표시되고 서버가 재시도한다(가시성은 [CEB-BO-SUP-205] §4.2 반환 현황에서 확인).

### 5.3 권한별 동작

- 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정에 따른다.
- 쓰기 권한이 없거나 외부 아티스트 계정이면 [집행 취소] 버튼이 미노출이므로 본 모달은 호출되지 않는다.

### 5.4 활동 로그

| 동작 | 로그 메시지 |
| --- | --- |
| 집행 취소 | 서포트 이벤트 '{이벤트명}'을(를) 집행 취소했습니다. 응원 회원 {N}명에게 {N} 덕력을 전액 반환했습니다. |
