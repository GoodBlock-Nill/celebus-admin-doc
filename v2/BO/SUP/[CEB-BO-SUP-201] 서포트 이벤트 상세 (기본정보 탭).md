## 1. 화면 목적

개별 서포트 이벤트의 기본 정보를 조회·수정하고, 헤더에서 라이프사이클 전환(게시·집행 시작·집행 취소·결과물 등록·완료·강제 종료·삭제)을 수행하는 화면. 상세는 **3탭 구조**(기본정보 / 응원자 내역 / 결과물·반환)이며, 본 문서는 [기본정보] 탭이다. 헤더 액션 버튼·상태 배지·기간 표기는 세 탭 공통으로 노출되며, 상태 전환 로직은 본 탭이 소유한다.

### 주요 기능

- 통계 카드 조회 (응원자 수·누적 응원·평균 응원량·달성률)
- 기본 정보 조회·수정 (이벤트명·설명·그룹·목표·기간·대표 이미지·아티스트 홈 카드·유의사항)
- 헤더 라이프사이클 전환 (게시·집행 시작·집행 취소·결과물 등록·완료·강제 종료·삭제)

### 진입 경로

- [CEB-BO-SUP-101] 서포트 이벤트 리스트 > Row 클릭
- URL: `/artists/support/{id}?tab=info` (기본 탭)

### 2.3 통계 카드 (상단, 임시저장 제외)

응원이 시작된 이후(모집중~) 노출된다. 임시저장 상태에서는 통계 카드를 표시하지 않는다.

| 카드 | 값 |
| --- | --- |
| 응원자 수 | 1 덕력 이상 응원한 회원 수 |
| 누적 응원 | 누적 응원 덕력 |
| 평균 응원량 | 누적 응원 / 응원자 수 |
| 달성률 | 누적 응원 / 목표 응원량 (%). 100% 이상 강조 |

### 2.4 기본 정보 (조회 / 수정 모드)

기본은 조회 모드이며, [수정] 클릭 시 입력 컨트롤이 열리는 수정 모드로 전환된다. 진행 상태에 따라 수정 가능 범위가 다르다(§4.5).

| 항목 | 표시 | 수정 가능 범위 |
| --- | --- | --- |
| 이벤트명 (한국어/영어/일본어) | 각 50자 | 임시저장·모집중 |
| 설명 (한국어/영어/일본어) | 각 500자 | 임시저장·모집중 |
| 그룹(아티스트) | 응원 대상 | 변경 불가 (생성 후 고정) |
| 목표 응원량 | 덕력 | 임시저장에서만 (모집중 이후 잠금) |
| 기간 | 시작·마감일시 (KST) | 임시저장에서만 (모집중 이후 잠금) |
| 대표 이미지 | 권장 16:9 | 임시저장·모집중 |
| 아티스트 홈 카드 | 카드 이미지(1:1 아이콘) + 카드 타이틀·서브타이틀(다국어) | 임시저장·모집중 |
| 유의사항 | 응원 전 안내·환불 조건(다국어) — 앱 상세 노출 | 임시저장·모집중 |

- 수정 모드 [수정]·[저장]·[취소] 버튼은 **본문 상단 우측(통계 카드 아래)**에 배치해 조회 중에도 쉽게 찾을 수 있게 한다.
- 변경 사항이 없으면 [저장]은 비활성이다.
- 수정 중 다른 탭으로 전환하거나 화면을 이탈하려 하면 미저장 변경 확인을 받는다(§4.6).
- 잠금된 항목(모집중의 목표·기간, 모든 상태의 그룹)은 비활성으로 표시하고 잠금 사유를 인라인 안내한다.

> 시각적 스타일은 프로토타입 참조

### 2.5 다국어 입력

이벤트명·설명·카드 타이틀은 한국어/영어/일본어를 모두 입력해야 저장·게시할 수 있다. 카드 서브타이틀·유의사항은 선택이다. 미입력 다국어 칸은 빨간 점 등으로 누락 표시한다(상세 글자수·필수 여부는 [CEB-BO-SUP-101-CREATE] §2 정합).

## 4. 규칙·로직

### 4.1 라이프사이클 전환 플로우

[CEB-BO-SUP-000] §4.1 적용. 본 탭 헤더가 전환 진입점을 소유한다.

1. **진입**: 리스트에서 Row 클릭 → `?tab=info` 기본 탭 진입. 현재 상태에 맞는 헤더 액션 버튼·통계 카드(임시저장 제외)·기본 정보(조회 모드) 표시.
2. **게시**: 임시저장에서 [게시] → 확인 모달 → 모집중. 시작일시 도달 시 앱에 노출되어 응원 시작.
3. **자동 전이 (달성)**: 모집중에서 누적 응원 ≥ 목표 응원량이면 서버가 자동으로 달성으로 전환(운영자 버튼 없음). 화면이 열려 있으면 새로고침·재조회 시 달성 상태·집행 대기 액션으로 갱신된다.
4. **자동 전이 (미달성종료)**: 모집중에서 마감일시 도달 + 목표 미달성이면 서버가 자동으로 미달성종료로 전환하고 응원 덕력을 전액 자동 반환한다(운영자 버튼 없음).
5. **집행 시작**: 달성에서 [집행 시작] → 확인 모달 → 집행중. 응원 덕력이 서포트 집행에 사용되며 반환되지 않는다.
6. **집행 취소**: 달성·집행중에서 [집행 취소] → 확인 모달 → 집행취소. 응원 회원 전원에게 전액 자동 반환.
7. **강제 종료**: 모집중에서만 [강제 종료] → 확인 모달 → 미달성종료. 응원 회원 전원에게 전액 자동 반환. (달성·집행중의 중단은 [집행 취소]가 전담)
8. **결과물 등록·완료**: 집행중에서 [결과물·반환] 탭에 결과 메시지·사진·영상 입력 후 [결과물 등록·완료] → 확인 모달 → 완료. 결과물 공개 + 응원 회원에게 알림 발송.
9. **삭제**: 임시저장에서 [삭제] → 확인 모달 → 이벤트 삭제 + 리스트 복귀.
10. **탭 전환**: 헤더 유지, 본문만 교체(§4.7).
11. **실패**: 전환 처리 실패 시 상태는 그대로 유지하고 에러 토스트 노출(§7), 재시도 가능.

### 4.2 동시성·경합 처리

- 운영자가 화면을 열어둔 사이 서버 자동 전이(달성·미달성종료)가 발생할 수 있다. 헤더 액션은 **클릭 시점이 아니라 처리 시점의 서버 상태**를 기준으로 검증한다.
- 예: 달성 화면에서 [집행 취소]를 누르는 사이 다른 경로로 이미 집행 시작/완료가 처리되었다면, 서버가 현재 상태와 맞지 않는 전환을 거부하고 "이미 상태가 변경되었습니다. 새로고침 후 다시 시도하세요." 토스트를 노출한 뒤 최신 상태로 갱신한다.
- 마감 직전 응원으로 모집중→달성이 막 일어난 직후의 [강제 종료] 클릭은 처리 시점 상태가 이미 달성이면 거부된다(강제 종료는 모집중 전용). 이 경우 달성 상태의 [집행 시작]·[집행 취소]로 갱신 안내한다.

### 4.3 반환 대상 수·덕력 산출 시점 ({N} 스냅샷)

- 집행 취소·강제 종료 확인 모달에 표기되는 **응원 회원 수 {N}명 / 반환 덕력 {N}**은 **모달 진입(액션 버튼 클릭) 시점의 누적 응원자 수·누적 응원 덕력 스냅샷**이다.
- 응원은 모집중·달성 상태에서만 발생하며, 집행중·달성에서는 추가 응원이 차단되므로 모달 진입 시점 값과 실제 반환 값이 일치한다.
- 실제 반환은 상태 전이 확정 시점에 서버가 전액(=누적 응원 덕력) 자동 처리한다(§4.4).

### 4.4 반환 (전액·자동)

미달성종료·집행취소·강제 종료 시 응원 회원 전원에게 응원 덕력을 **즉시 전액 자동 반환**한다([CEB-BO-SUP-000] §4.4). 운영자 수동 반환·추가 인증 절차는 없다. 회원별 반환 내역은 [CEB-BO-SUP-205] 결과물·반환 탭에서 조회한다.

### 4.5 상태별 수정 범위

| 상태 | 수정 가능 |
| --- | --- |
| 임시저장 | 전 항목 (이벤트명·설명·목표·기간·이미지·홈 카드·유의사항 / 그룹은 변경 불가) |
| 모집중 | 이벤트명·설명·대표 이미지·홈 카드·유의사항만 (목표·기간·그룹 잠금 — 응원 진행 중 기준 변경 방지) |
| 달성·집행중·완료·미달성종료·집행취소 | 수정 불가 (읽기 전용). 본문에 "읽기 전용 — 현재 상태에서는 수정할 수 없습니다." 안내, [수정] 버튼 미노출 |

### 4.6 수정 중 이탈·탭 전환

- 수정 모드에서 변경 사항이 있는 채로 다른 탭 클릭·화면 이탈 시 "저장하지 않은 변경이 있습니다. 이동할까요?" 확인을 받는다.
- 확인 시 변경 폐기 후 이동, 취소 시 수정 모드 유지.

### 4.7 탭 라우팅

- URL 쿼리 `?tab=info|cheerers|result`로 탭을 구분한다. 기본 탭은 `info`.
- 새로고침·공유 시 URL 쿼리 기준으로 동일 탭이 복원된다.
- 쿼리 누락·잘못된 값이면 기본 탭(`info`)으로 복귀한다.
- 탭 전환 시 헤더(타이틀·배지·기간·액션 버튼)는 유지하고 본문만 교체한다.

### 4.8 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- 쓰기 권한이 없으면 [수정]·헤더 상태 전환 버튼·[삭제]가 **미노출**된다(disabled가 아니라 노출 제거).
- 외부 아티스트 계정은 자기 아티스트 이벤트만 조회할 수 있으며, 상태 전환·수정·삭제 버튼은 모두 **미노출**된다(조회 전용).
