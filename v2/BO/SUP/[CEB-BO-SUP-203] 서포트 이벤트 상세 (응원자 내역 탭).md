## 1. 화면 목적

서포트 이벤트에 응원한 회원을 **회원별로 합산**해 조회하는 화면. 서포트 이벤트 상세 **3탭 구조**(기본정보 / 응원자 내역 / 결과물·반환) 중 [응원자 내역] 탭이다. 한 회원은 동일 이벤트에 **여러 번 응원**할 수 있으므로(앱 [CEB-DUK-201] 누적 응원), 회원별 합산을 보여주되 행 클릭으로 회차별 개별 응원 내역까지 확인할 수 있다. 본 탭은 조회 전용이며, 응원은 회원 앱에서만 발생한다.

### 진입 경로

- [CEB-BO-SUP-201] 기본정보 탭 > [응원자 내역] 탭
- URL: `/artists/support/{id}?tab=cheerers`

---

## 2. UI 설명

### 2.1 상단 헤더 (세 탭 공통)

- 헤더(Breadcrumb·타이틀·그룹 배지·상태 배지·기간·상태 전환 버튼)는 [CEB-BO-SUP-201]과 동일하게 유지된다. 상태 전환 액션은 [CEB-BO-SUP-201]이 소유한다.

### 2.2 탭 메뉴 (3탭)

| # | 탭명 | URL | 문서 |
| --- | --- | --- | --- |
| 1 | 기본정보 | `?tab=info` | [CEB-BO-SUP-201] |
| 2 | **응원자 내역** | `?tab=cheerers` | 본 문서 |
| 3 | 결과물·반환 | `?tab=result` | [CEB-BO-SUP-205] |

### 2.3 요약 (상단)

| 항목 | 값 |
| --- | --- |
| 응원자 수 | 1 덕력 이상 응원한 회원 수 (중복 제거) |
| 총 응원 횟수 | 이벤트 전체 응원 건수 (회원별 다회 합산) |
| 누적 응원 | 누적 응원 덕력 |

### 2.4 회원별 목록 (테이블)

| 컬럼 | 데이터 예시 | 설명 |
| --- | --- | --- |
| 닉네임 | "덕력회원05" | 응원 회원 |
| 누적 응원량(덕력) | 1,200 | 회원의 전체 응원 합산 |
| 응원 횟수 | 3회 | 회원이 응원한 횟수 (2회 이상 강조) |
| 최초 응원 | 2026.05.27 14:21 | 회원의 첫 응원 시점 (KST) |
| 최근 응원 | 2026.05.30 09:05 | 회원의 마지막 응원 시점 (KST) |
| 반환 여부 | "반환 완료" / "-" | 미달성종료·집행취소 시 "반환 완료" 표시 |

- 정렬: **누적 응원량 내림차순(많은 순)** 고정.
- 페이지네이션: 하단 중앙, 페이지당 10건. 필터·검색은 없다(조회 전용 합산 목록).
- **행 클릭 시 [CEB-BO-SUP-203-MD-CHEER-DETAIL] 응원 상세 모달**(회차별 응원 내역)을 연다.
- 읽기 전용 (응원은 회원 앱에서만 발생).

> 시각적 스타일은 프로토타입 참조

## 4. 규칙·로직

### 4.1 정렬·합산

- 정렬: 누적 응원량 내림차순(많은 순) 고정.
- 회원별 합산: 동일 회원의 여러 회차 응원을 합산하여 1행으로 표시한다. 회차별 분해는 응원 상세 모달에서 확인한다.
- 응원 횟수 2회 이상인 회원은 강조 표시한다.

### 4.2 반환 표기

- 미달성종료·집행취소 상태에서는 응원 회원 전원에게 전액 자동 반환이 이루어지므로, 목록 [반환 여부] 컬럼에 전원 "반환 완료"가 표시된다.
- 회원별 반환 시점·반환 덕력 상세는 [CEB-BO-SUP-205] 결과물·반환 탭에서, 회차별 응원과 반환 시점 표기는 응원 상세 모달에서 확인한다.

### 4.3 탭 라우팅

- URL 쿼리 `?tab=cheerers`로 본 탭에 진입한다. 새로고침·공유 시 동일 탭 복원, 잘못된 값이면 기본 탭(`info`)으로 복귀([CEB-BO-SUP-201] §4.7과 동일).

### 4.4 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- 본 탭은 조회 전용이므로 별도 쓰기 액션이 없다. 외부 아티스트 계정도 자기 아티스트 이벤트의 응원자 내역을 조회할 수 있다.

## 6. 활동 로그

본 탭(조회)은 로그를 기록하지 않는다. 응원은 회원 앱에서 발생하며, 응원·반환 내역은 [CEB-BO-SUP-401] 응원·반환 변동 내역에서 추적한다.
