## 1. 화면 목적

운영자가 **임시저장 서포트 이벤트를 게시(모집대기 전환)하기 전 확인**을 받는 모달이다. 게시하면 모집대기 상태가 되고(앱 미노출), 시작일시에 도달하면 서버가 자동으로 모집중으로 전환해 앱에 노출되고 응원이 시작된다.

- **누가**: 서포트 운영 권한이 있는 백오피스 관리자
- **왜**: 게시는 시작일시 예약·회원 노출을 확정하므로 명시적 확인 필요
- **결과**: 이벤트 상태가 "임시저장" → "모집대기"로 전환됨 (시작일시 도달 시 모집중 자동 전환)

## 3. 기능 설명

1. **게시 확인** — 게시 후 동작·필수 설정 안내 확인
2. **게시 확정** — [게시] 클릭으로 모집대기 전환 (시작일시 도달 시 자동 모집중)
3. **취소** — [취소]/[X]/외부 클릭으로 모달 닫고 상태 유지

---

## 4. 로직·플로우

### 4.1 모달 진입

1. 기본정보 탭에서 [게시] 클릭
2. 본 모달 열림

### 4.2 게시 확정

1. [게시] 클릭
2. 서버가 **필수값 전체**(이벤트명·설명 3언어·그룹·목표 응원량·시작/마감일시·대표 이미지·홈 카드 이미지·홈 카드 타이틀) 입력 여부 검증
3. 통과 시 상태 "임시저장" → "모집대기" 전환 (시작일시 도달 시 서버가 자동으로 모집중 전환·앱 노출)
4. 모달 닫기
5. 토스트 "서포트 이벤트를 게시했습니다. (시작일시에 모집 시작)"
6. 상세 화면 자동 갱신 (상태 배지 변경 + 헤더 액션 갱신)

### 4.3 취소

1. [취소] 또는 모달 외부 클릭 또는 [X] 클릭
2. 모달 닫기. 임시저장 상태 유지

---

## 5. 검증·예외 상황

### 5.1 사전 조건

- 게시 가능한 이벤트는 "임시저장" 상태만 가능.
- **모든 필수값이 입력되어 있어야 게시 가능**(이벤트명·설명 3언어·그룹·목표 응원량·시작/마감일시·대표 이미지·홈 카드 이미지·홈 카드 타이틀). 미입력 항목이 있으면 게시 차단 토스트 "필수 항목을 모두 입력해야 게시할 수 있습니다."로 안내하고 상태를 유지한다(미입력 항목은 기본정보 탭에서 보강).

### 5.2 권한별 동작

- 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정에 따른다.
- 쓰기 권한이 없거나 외부 아티스트 계정이면 [게시] 버튼이 미노출이므로 본 모달은 호출되지 않는다.

### 5.3 활동 로그

| 동작 | 로그 메시지 |
| --- | --- |
| 게시 | 서포트 이벤트 '{이벤트명}'을(를) 게시했습니다. |
