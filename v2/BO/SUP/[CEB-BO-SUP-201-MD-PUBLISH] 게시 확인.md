## 1. 화면 목적

운영자가 **임시저장 서포트 이벤트를 게시(모집중 전환)하기 전 확인**을 받는 모달이다. 게시 후 시작일시에 도달하면 앱에 노출되어 응원이 시작된다.

- **누가**: 서포트 운영 권한이 있는 백오피스 관리자
- **왜**: 게시는 회원 노출·응원 시작을 유발하므로 명시적 확인 필요
- **결과**: 이벤트 상태가 "임시저장" → "모집중"으로 전환됨

### 2.2 노출 조건

- [CEB-BO-SUP-201] 기본정보 탭 헤더 [게시] 액션 클릭 시 노출.
- 임시저장 상태에서만 [게시] 버튼이 노출되므로 본 모달도 임시저장에서만 호출된다.

| 보조 안내 | "목표 응원량·기간이 설정되어 있어야 합니다." |

### 2.4 푸터

## 3. 기능 설명

1. **게시 확인** — 게시 후 동작·필수 설정 안내 확인
2. **게시 확정** — [게시] 클릭으로 모집중 전환
3. **취소** — [취소]/[X]/외부 클릭으로 모달 닫고 상태 유지

---

## 4. 로직·플로우

### 4.1 모달 진입

1. 기본정보 탭에서 [게시] 클릭
2. 본 모달 열림

### 4.2 게시 확정

1. [게시] 클릭
2. 서버가 목표 응원량·기간 설정 여부 검증
3. 통과 시 상태 "임시저장" → "모집중" 전환
4. 모달 닫기
5. 토스트 "서포트 이벤트를 게시했습니다."
6. 상세 화면 자동 갱신 (상태 배지 변경 + 헤더 액션 갱신)

### 4.3 취소

1. [취소] 또는 모달 외부 클릭 또는 [X] 클릭
2. 모달 닫기. 임시저장 상태 유지

---

## 5. 검증·예외 상황

### 5.1 사전 조건

- 게시 가능한 이벤트는 "임시저장" 상태만 가능.
- 목표 응원량·시작·마감일시가 모두 설정되어 있어야 한다. 미설정이면 게시 차단 토스트 "목표 응원량과 기간을 먼저 설정해주세요."로 안내하고 상태를 유지한다.

### 5.2 권한별 동작

- 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정에 따른다.
- 쓰기 권한이 없거나 외부 아티스트 계정이면 [게시] 버튼이 미노출이므로 본 모달은 호출되지 않는다.

### 5.3 활동 로그

| 동작 | 로그 메시지 |
| --- | --- |
| 게시 | 서포트 이벤트 '{이벤트명}'을(를) 게시했습니다. |
