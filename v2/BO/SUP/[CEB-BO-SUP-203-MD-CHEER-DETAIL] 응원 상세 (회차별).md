## 1. 화면 목적

[CEB-BO-SUP-203] 응원자 내역 탭에서 회원 행을 클릭했을 때, 해당 회원이 동일 이벤트에 응원한 **회차별 개별 내역**(회차·응원량·응원 시점)을 표시하는 조회 전용 모달이다. 회원별 목록은 합산만 보여주므로, 다회 응원 회원의 응원 흐름을 운영자가 추적할 수 있게 한다.

- **누가**: 서포트 운영·조회 권한이 있는 백오피스 관리자
- **왜**: 회원이 동일 이벤트에 여러 번 응원할 수 있어(누적 응원) 회차별 추적이 필요
- **결과**: 회차별 응원량·시점과 누적 합계, 반환 상태이면 전액 반환 완료 정보를 확인

## 2. UI 설명

### 2.1 모달 레이아웃

```
┌───────────────────────────────────────────────┐
│ {닉네임} 응원 내역                       [X]  │
│ 총 {N}회 · 누적 {N} 덕력                       │
│ (반환 시) · 전액 반환 완료 ({반환 시점})       │
├───────────────────────────────────────────────┤
│  회차      응원량(덕력)        응원 시점       │
│  1회차              500   2026.05.27 14:21    │
│  2회차              300   2026.05.29 10:02    │
│  ... (10건/페이지)                            │
│  ─────────────────────────────────────────    │
│  누적(전체)       12,400                       │
│                          ‹ 1 2 3 … ›  (페이저) │
├───────────────────────────────────────────────┤
│                                      [닫기]    │
└───────────────────────────────────────────────┘
```

### 2.2 노출 조건

- [CEB-BO-SUP-203] 응원자 내역 탭에서 회원 행 클릭 시 노출.
- 응원 0건 회원은 목록에 행 자체가 없으므로 본 모달은 호출되지 않는다.

### 2.3 본문 구성

| 영역 | 내용 |
| --- | --- |
| 헤더 타이틀 | "{닉네임} 응원 내역" |
| 헤더 요약 | "총 {N}회 · 누적 {N} 덕력" |
| 헤더 반환 표기 (반환 상태일 때만) | " · 전액 반환 완료 ({반환 시점})" — 반환 강조 색 |
| 회차 테이블 | 회차 / 응원량(덕력) / 응원 시점 (응원 시점 **오름차순**). **10건/페이지 페이지네이션** — 회차 번호는 전체 기준 연속(2페이지 첫 행 = 11회차) |
| 페이지네이션 | 회차가 10건 초과면 테이블 하단에 페이저 노출(10건 이하면 미노출). 페이지 이동 시 헤더 요약·합계는 전체 기준 고정 |
| 합계 행 | "누적(전체)" + 회원의 전체 누적 응원량 (현재 페이지 합이 아닌 **전체 합**, 강조) |

### 2.4 푸터

| 액션 | 동작 |
| --- | --- |
| [닫기] | 모달 닫기. 응원자 내역 탭으로 복귀 (선택·스크롤 위치 유지) |
| [X] / 외부 클릭 | [닫기]와 동일 |

## 3. 기능 설명

운영자가 이 모달에서 할 수 있는 동작:

1. **회차별 응원 내역 확인** — 회차·응원량·응원 시점 조회
2. **누적 합계 확인** — 회원의 총 응원 덕력
3. **반환 상태 확인** — 반환 이벤트이면 전액 반환 완료·반환 시점 표기
4. **닫기** — [닫기]/[X]/외부 클릭으로 모달 종료

본 모달은 조회 전용으로 입력·저장 동작이 없다.

---

## 4. 로직·플로우

### 4.1 모달 진입

1. 응원자 내역 탭에서 회원 행 클릭
2. 본 모달 열림
3. 해당 회원의 회차별 응원 내역을 응원 시점 오름차순으로 로드, **1페이지(10건)** 표시
4. 헤더에 닉네임·총 회수·누적 덕력 표시(전체 기준). 이벤트가 미달성종료·집행취소이거나 회원 개별 반환 처리된 경우 "전액 반환 완료 ({반환 시점})" 추가 표기
5. 회차 10건 초과 시 페이저로 페이지 이동(회차 번호는 전체 기준 연속 유지)

### 4.2 닫기

1. [닫기] 또는 [X] 또는 모달 외부 클릭
2. 모달 닫기. 응원자 내역 탭 유지
