## 1. 화면 목적

운영자가 **임시저장·모집대기 서포트 이벤트를 삭제하기 전 확인**을 받는 모달이다. 삭제된 이벤트는 복구할 수 없다. 두 상태는 아직 응원이 발생하지 않아 삭제할 수 있다. **모집 시작 이후 상태(모집중~)** 는 응원·반환 데이터가 발생하므로 삭제 대상이 아니며, 종료가 필요하면 강제 종료(모집중)·집행 취소를 사용한다.

- **누가**: 서포트 운영(삭제) 권한이 있는 백오피스 관리자
- **왜**: 삭제는 비가역 행위이므로 명시적 확인 필요
- **결과**: 임시저장·모집대기 이벤트가 삭제되고 [CEB-BO-SUP-101] 리스트로 복귀함

## 2. UI 설명

### 2.1 모달 레이아웃

```
┌───────────────────────────────────────────────┐
│ 이벤트를 삭제할까요?                     [X]  │
├───────────────────────────────────────────────┤
│                                               │
│  삭제된 서포트 이벤트는 복구할 수 없습니다.   │
│                                               │
├───────────────────────────────────────────────┤
│                       [취소]   [삭제]         │
└───────────────────────────────────────────────┘
```

### 2.2 노출 조건

- [CEB-BO-SUP-201] 기본정보 탭 헤더 [삭제] 액션 클릭 시 노출.
- [삭제] 버튼은 **임시저장·모집대기 상태에서만** 노출되므로 본 모달도 두 상태에서만 호출된다.

### 2.3 본문 구성

| 영역 | 내용 |
| --- | --- |
| 타이틀 | "이벤트를 삭제할까요?" |
| 본문 (강조) | "삭제된 서포트 이벤트는 복구할 수 없습니다." |

### 2.4 푸터

| 액션 | 동작 |
| --- | --- |
| [취소] | 모달 닫기. 이벤트 유지 (임시저장·모집대기) |
| [삭제] | 위험 강조 색상. 임시저장·모집대기 이벤트 삭제 후 리스트로 복귀 |

## 3. 기능 설명

1. **삭제 비가역성 확인** — 복구 불가 안내 확인
2. **삭제 확정** — [삭제] 클릭으로 이벤트 삭제
3. **취소** — [취소]/[X]/외부 클릭으로 모달 닫고 이벤트 유지

---

## 4. 로직·플로우

### 4.1 모달 진입

1. 기본정보 탭에서 [삭제] 클릭
2. 본 모달 열림

### 4.2 삭제 확정

1. [삭제] 클릭
2. 임시저장·모집대기 이벤트 삭제 처리
3. 모달 닫기
4. 토스트 "서포트 이벤트를 삭제했습니다."
5. [CEB-BO-SUP-101] 리스트로 복귀

### 4.3 취소

1. [취소] 또는 모달 외부 클릭 또는 [X] 클릭
2. 모달 닫기. 임시저장 이벤트 유지

---

## 5. 검증·예외 상황

### 5.1 사전 조건

- 삭제 가능한 이벤트는 "임시저장·모집대기" 상태만 가능(아직 응원 0건).
- 모집 시작 이후 상태(모집중~)는 [삭제] 버튼 자체가 미노출이므로 본 모달은 호출되지 않는다. 진행 이벤트를 끝내려면 강제 종료(모집중, [CEB-BO-SUP-201-MD-FORCE-END])·집행 취소를 사용한다.

### 5.2 권한별 동작

- 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정에 따른다.
- 삭제 권한이 없거나 외부 아티스트 계정이면 [삭제] 버튼이 미노출이므로 본 모달은 호출되지 않는다.

### 5.3 활동 로그

| 동작 | 로그 메시지 |
| --- | --- |
| 이벤트 삭제 | 서포트 이벤트 '{이벤트명}'을(를) 삭제했습니다. |
