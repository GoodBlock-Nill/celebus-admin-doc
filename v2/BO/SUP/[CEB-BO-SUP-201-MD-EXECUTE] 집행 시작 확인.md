## 1. 화면 목적

운영자가 **달성 이벤트의 서포트 집행을 시작(집행중 전환)하기 전 확인**을 받는 모달이다. 집행을 시작하면 응원 덕력이 서포트 집행에 사용되며 더 이상 반환되지 않는다.

- **누가**: 서포트 운영 권한이 있는 백오피스 관리자
- **왜**: 집행 시작 후에는 응원 덕력이 반환되지 않으므로(집행 비용으로 사용) 명시적 확인 필요
- **결과**: 이벤트 상태가 "달성" → "집행중"으로 전환됨

- [CEB-BO-SUP-201] 기본정보 탭 헤더 [집행 시작] 액션 클릭 시 노출.
- 달성 상태에서만 [집행 시작] 버튼이 노출되므로 본 모달도 달성에서만 호출된다.

## 3. 기능 설명

1. **집행 안내 확인** — 응원 덕력이 반환되지 않음을 확인
2. **집행 확정** — [집행 시작] 클릭으로 집행중 전환
3. **취소** — [취소]/[X]/외부 클릭으로 모달 닫고 상태 유지

---

## 4. 로직·플로우

### 4.1 모달 진입

1. 기본정보 탭에서 [집행 시작] 클릭
2. 본 모달 열림

### 4.2 집행 확정

1. [집행 시작] 클릭
2. 상태 "달성" → "집행중" 전환 (응원 덕력은 집행 비용으로 확정, 반환 대상 아님)
3. 모달 닫기
4. 토스트 "서포트 집행을 시작했습니다."
5. 상세 화면 자동 갱신 (헤더 액션이 [결과물 등록·완료]·[집행 취소]·[강제 종료]로 갱신)

### 4.3 취소

1. [취소] 또는 모달 외부 클릭 또는 [X] 클릭
2. 모달 닫기. 달성 상태 유지

---

## 5. 검증·예외 상황

### 5.1 사전 조건

- 집행 시작 가능한 이벤트는 "달성" 상태만 가능.
- 처리 시점 상태가 달성이 아니면(경합으로 이미 집행/취소/종료됨) 서버가 거부하고 "이미 상태가 변경되었습니다. 새로고침 후 다시 시도하세요." 토스트로 안내한다([CEB-BO-SUP-201] §4.2).

### 5.2 권한별 동작

- 권한은 [CEB-BO-SYS-102] 권한 관리 그룹 설정에 따른다.
- 쓰기 권한이 없거나 외부 아티스트 계정이면 [집행 시작] 버튼이 미노출이므로 본 모달은 호출되지 않는다.

### 5.3 활동 로그

| 동작 | 로그 메시지 |
| --- | --- |
| 집행 시작 | 서포트 이벤트 '{이벤트명}'의 집행을 시작했습니다. (응원자: {N}명, 누적: {N} 덕력) |

- 로그의 응원자 수·누적 덕력은 집행 시작 시점의 누적 응원 스냅샷이다.
