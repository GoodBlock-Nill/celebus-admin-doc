## 1. 화면 목적

서포트 이벤트 생성 화면 [CEB-BO-SUP-101-CREATE]에서 운영자가 입력 중인 내용이 있는 상태로 [취소]를 눌렀을 때, 작성 내용이 사라진다는 사실을 알리고 이탈 여부를 재확인하는 모달이다.

- **누가**: 서포트 운영 권한이 있는 백오피스 관리자
- **왜**: 다국어 이벤트명·설명·이미지·홈 카드 등 입력 분량이 많아, 실수로 이탈해 작성 내용을 잃는 것을 방지
- **결과**: [나가기] 선택 시 입력값 폐기 후 리스트로 복귀 / [계속 작성] 선택 시 생성 화면에 머무름

## 2. UI 설명

### 2.1 모달 레이아웃

```
┌───────────────────────────────────────────────┐
│ [모달 타이틀]                          [X]   │
│  작성을 취소할까요?                          │
├───────────────────────────────────────────────┤
│                                               │
│  지금 나가면 입력한 내용이 저장되지 않고      │
│  모두 사라집니다.                             │
│                                               │
│  · 작성 중인 내용을 보관하려면 [임시저장]을  │
│    이용하세요.                                │
│                                               │
├───────────────────────────────────────────────┤
│                  [계속 작성]   [나가기]       │
└───────────────────────────────────────────────┘
```

### 2.2 노출 조건

- 생성 화면 [CEB-BO-SUP-101-CREATE]에서 [취소] 클릭 시, **입력값이 하나라도 변경된 상태(dirty)**이면 본 모달이 열린다.
- 입력값이 전혀 없는 초기 상태(dirty 아님)에서 [취소]를 누르면 본 모달 없이 즉시 리스트로 복귀한다.

#### dirty 판정 기준

| 항목 | dirty 판정 |
| --- | --- |
| 다국어 이벤트명·설명 | 한 칸이라도 입력되면 dirty |
| 그룹 선택 | 그룹을 선택하면 dirty |
| 목표 응원량 | 값이 입력되면 dirty |
| 시작·마감일시 | 한쪽이라도 선택되면 dirty |
| 대표 이미지·홈 카드 이미지 | 업로드되면 dirty |
| 카드 타이틀·서브타이틀·유의사항 | 한 칸이라도 입력되면 dirty |

- 위 항목 중 하나라도 초기값과 달라지면 dirty로 간주해 본 모달을 노출한다.

## 3. 기능 설명

운영자가 이 모달에서 할 수 있는 동작:

1. **계속 작성** — [계속 작성] 또는 [X]로 모달을 닫고 작성을 이어간다
2. **나가기** — [나가기]로 입력값을 폐기하고 리스트로 이동한다

---

## 4. 로직·플로우

### 4.1 모달 진입

1. 생성 화면에서 [취소] 클릭
2. 입력값 변경 여부(dirty) 판정
3. dirty이면 본 모달 열림 / dirty 아니면 모달 없이 즉시 리스트 복귀

### 4.2 나가기 확정

1. [나가기] 클릭
2. 입력값 전체 폐기
3. 모달 닫기
4. [CEB-BO-SUP-101] 리스트로 복귀 (별도 토스트 없음)

### 4.3 계속 작성

1. [계속 작성] 또는 모달 외부 클릭 또는 [X] 클릭
2. 모달 닫기. 입력값 그대로 유지하여 작성 계속
