## 1. 화면 목적

서포트 이벤트의 **결과물 입력·공개**와 **반환 현황 조회**를 담당하는 화면. 서포트 이벤트 상세 **3탭 구조**(기본정보 / 응원자 내역 / 결과물·반환) 중 [결과물·반환] 탭이다. 집행중 상태에서 결과 메시지(다국어)와 사진·영상을 입력하고, 헤더 [결과물 등록·완료]로 완료 처리한다. 미달성종료·집행취소 이벤트는 전액 자동 반환 현황을 조회한다.

### 진입 경로

- [CEB-BO-SUP-201] 기본정보 탭 > [결과물·반환] 탭
- URL: `/artists/support/{id}?tab=result`

## 2. UI 설명

### 2.1 상단 헤더 (세 탭 공통)

- 헤더(Breadcrumb·타이틀·그룹 배지·상태 배지·기간·상태 전환 버튼)는 [CEB-BO-SUP-201]과 동일하게 유지된다. [결과물 등록·완료] 버튼도 헤더에 노출되며 본 탭의 입력값을 확정한다.

### 2.2 탭 메뉴 (3탭)

| # | 탭명 | URL | 문서 |
| --- | --- | --- | --- |
| 1 | 기본정보 | `?tab=info` | [CEB-BO-SUP-201] |
| 2 | 응원자 내역 | `?tab=cheerers` | [CEB-BO-SUP-203] |
| 3 | **결과물·반환** | `?tab=result` | 본 문서 |

### 2.3 결과물 입력 영역

집행 완료 후 결과 메시지(다국어)와 사진·영상을 등록한다. 상단 [결과물 등록·완료] 처리 시 회원 앱에 공개된다.

| 항목 | 값 | 입력 |
| --- | --- | --- |
| 결과 메시지 (한국어/영어/일본어) | 각 200자 | 집행중에 입력 가능 / 완료 후 읽기 전용 |
| 결과 사진·영상 | 최대 10장 (회원 앱 갤러리) | 집행중에 추가·제거 / 완료 후 읽기 전용 |

#### 상태별 결과물 영역 표시

| 상태 | 표시 |
| --- | --- |
| 임시저장·모집중·달성 | "집행중 상태에서 결과물을 등록할 수 있습니다." 안내 (입력 비활성) |
| 집행중 | 결과 메시지·사진·영상 입력 가능 + "입력 후 상단 [결과물 등록·완료] 버튼으로 완료 처리하면 회원 앱에 공개됩니다." 안내 |
| 완료 | 입력값 읽기 전용 표시. 등록 매체 없으면 "등록된 사진·영상이 없습니다." |
| 미달성종료·집행취소 | 결과물 입력 영역 미노출 (반환 현황만 표시) |

> 결과물 등록·완료는 본 탭에서 입력한 뒤 헤더 [결과물 등록·완료] → [CEB-BO-SUP-205-MD-COMPLETE] 모달에서 확정한다. 완료 전이와 함께 응원 회원에게 결과물 알림이 발송된다.

### 2.4 반환 현황 (읽기 전용)

미달성종료·집행취소 상태일 때 ① 요약 ② 회원별 반환 내역으로 구성한다. 정상 진행·완료 이벤트는 "반환된 응원이 없습니다. (정상 집행·완료 이벤트는 반환 없음)" 안내만 표시한다.

#### 요약

| 항목 | 값 |
| --- | --- |
| 반환 사유 | 목표 미달성 / 집행 취소 / 강제 종료 (배지) |
| 반환 방식 | 서버 자동 · 즉시 전액 |
| 반환율 | 100% |
| 반환 대상 | 응원 회원 수 |
| 반환 총 덕력 | 반환된 총 덕력 (= 누적 응원 덕력) |
| 반환 완료 시점 | 상태 전이 시각 |

#### 회원별 반환 내역 (테이블)

| 컬럼 | 데이터 예시 | 설명 |
| --- | --- | --- |
| 닉네임 | "덕력회원05" | 반환 대상 회원 |
| 반환 덕력 | 1,200 | 회원의 누적 응원 = 반환액 (반환 강조 색) |
| 원 응원 횟수 | 3회 | 반환 전 응원한 횟수 |
| 반환 시점 | 2026.05.31 23:59 | 회원별 반환 처리 시각 |
| 상태 | "반환 완료" | 반환 상태 배지 |

- 정렬: 반환 덕력 내림차순(많은 순). 회차별 응원 내역은 [CEB-BO-SUP-203] 응원자 내역 탭의 응원 상세 모달 참조.
- 운영자 수동 반환 버튼은 없다(반환은 서버 자동 처리, §4.2).

> 시각적 스타일은 프로토타입 참조

## 4. 규칙·로직

### 4.1 결과물 입력·공개

- 결과 메시지는 한국어/영어/일본어 각 200자이며, 완료 처리 시 **3개 언어 모두 입력 필수**다(미입력 시 완료 차단, [CEB-BO-SUP-205-MD-COMPLETE] §5).
- 결과 사진·영상은 **최소 1장** 필요하며 최대 10장까지 등록한다(허용 형식·용량·동영상 길이는 [CEB-BO-000] 미디어 정책).
- 완료 처리 전까지 본 탭에서 자유롭게 입력·수정한다. 완료 후에는 읽기 전용으로 전환되고 회원 앱 [CEB-DUK-201] 갤러리에 공개된다.

### 4.2 반환 (전액·자동)

- 미달성종료·집행취소·강제 종료 시 응원 회원 전원에게 응원 덕력을 **즉시 전액 자동 반환**한다([CEB-BO-SUP-000] §4.4).
- 반환은 상태 전이 시점에 서버가 일괄 처리한다. 운영자 수동 반환·추가 인증 절차는 없다.
- 반환 사유 3종(목표 미달성·집행 취소·강제 종료)은 상태 전이 시점에 기록되어 본 탭 요약에 표시된다.
- 반환 처리·부분 실패 가시성: 반환은 일괄 자동 처리이며, 일부 회원 반환이 실패하면 해당 행 상태가 "반환 완료"가 아닌 "반환 보류"로 표시되고 서버가 재시도한다. 요약의 반환 대상·반환 총 덕력은 처리 완료 건 기준으로 갱신되며, 전건 완료 시 반환율 100%로 확정된다.

### 4.3 탭 라우팅

- URL 쿼리 `?tab=result`로 본 탭에 진입한다. 새로고침·공유 시 동일 탭 복원, 잘못된 값이면 기본 탭(`info`)으로 복귀([CEB-BO-SUP-201] §4.7과 동일).

### 4.4 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- 결과물 입력·[결과물 등록·완료]는 쓰기 권한 보유 그룹만 사용 가능하다. 권한이 없거나 외부 아티스트 계정이면 입력 컨트롤·완료 버튼이 미노출되고 조회만 가능하다.
