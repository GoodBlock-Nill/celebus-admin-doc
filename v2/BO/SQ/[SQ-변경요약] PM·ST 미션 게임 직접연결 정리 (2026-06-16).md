## 1. 한 줄 요약

> **개발자 이해가 맞습니다.** PM/ST(예측 마켓·서바이벌 트리비아) 미션은 **특정 게임에 직접 연결되지 않습니다.** 회원이 해당 아티스트의 PM/ST 게임에 참여(또는 정답·승리)하면 미션의 **판정 유형 × 기준 횟수 N**에 따라 서버가 자동으로 미션을 완료 처리합니다. 혼선을 준 잔존 항목(BO "소스 참조값", 앱 PM 딥링크의 특정 게임 지정)을 정리했고, **백오피스↔앱 완료 조건도 통일**했습니다 — 모든 PM/ST 판정 유형은 "N회 참여" 또는 "N번 정답·승리" 모델이며(예측 정답=예측 적중, **트리비아 승리=게임 자체 생존(서바이벌 규칙)**), 앱에 남아 있던 고정 임계치(트리비아 10문제 중 7문제) 표기를 폐기했습니다.

## 3. 핵심 개념

- PM/ST 미션은 **판정 유형**(예측 참여 / 예측 정답 / 트리비아 참여 / 트리비아 승리)과 **기준 횟수 N**만 미션에 저장한다. 특정 게임 ID·소스 참조값 같은 하드링크는 없다.
- 기준 횟수 N은 **모든 PM/ST 판정 유형에 적용**한다(참여형=N회 참여, 정답·승리형=N번 정답·승리). 예측 정답=예측 적중, **트리비아 승리=게임 자체 생존(서바이벌 규칙)**.
- 완료는 **회원이 그 아티스트의 PM/ST 게임에 참여/정답·승리** → 서버가 판정 유형 × N 기준으로 자동검증 → 미션 자동 완료(승인).
- 완료 인정 조건: ① 해당 아티스트 게임일 것 ② 판정 유형 × N 충족(참여형=N회 참여 / 정답·승리형=N번 정답·승리) ③ 에피소드 해금 이후 참여분.
- 팬퀘스트 미션만 1:1 매핑(하드링크)을 유지한다.

## 4. 디자이너가 알아야 할 것

- **앱 [CEB-FQ-101] PM 미션**: [참여하기] 버튼·문구는 유지하되, 누르면 **해당 아티스트의 진행 중 예측 마켓 게임**으로 이동(미션에 묶인 특정 게임 화면 아님). 진행 중 게임 없으면 기존대로 "게임 준비중" + [알림 설정].
- 미션 카드에 특정 게임명/번호를 노출하지 않는다(미션은 판정 유형만 보유).

## 5. 개발자가 알아야 할 것

- BO 미션 필드에서 **소스 참조값 제거**. PM/ST 미션 저장 필드 = 다국어 타이틀 · 판정 유형 · **기준 횟수 N(모든 PM/ST 판정 유형)** · 덕력 · 반복 주기/기간.
- 완료 처리: 회원의 아티스트 PM/ST 게임 참여/정답·승리 이벤트 → 미션 판정 유형 × N 매칭 → 자동 완료. 퀘스트 화면 진입/게임 종료 복귀 시 서버가 이력 확인해 상태 갱신. **트리비아 승리 판정 = 게임 자체 생존(서바이벌 규칙)**이며 고정 정답 개수 임계치는 사용하지 않는다.
- 앱 PM [참여하기] 딥링크 타겟 = 아티스트 진행 중 PM 게임(리스트 CEB-GAM-201 / 진행 게임 CEB-GAM-202). 특정 미션-게임 매핑을 조회하지 않는다.
