## 1. 화면 목적

운영자가 일일미션 풀에서 미션 1건을 **삭제하기 전 확인**하는 모달. 삭제는 되돌릴 수 없으므로 대상 미션을 명시하고 확인을 받는다.

### 진입 경로

- [CEB-BO-DLY-101] 일일미션 관리 > 미션 행 [삭제]

```
┌─────────────────────────────────────────────┐
│  미션을 삭제하시겠어요?                       │

│  '게임존 방문' 미션을 미션 풀에서 삭제합니다. │
```

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.

### 4.2 삭제 규칙

- 삭제된 미션은 미션 풀에서 제거되어 **다음날 자정 미션 선택부터 제외**된다. **당일 이미 배정·진행 중인 회원의 미션은 유지되며 완료로 인정**된다(당일분 보존·소급 없음, [CEB-BO-DLY-101] §4.3.1).
- 삭제로 **사용 중인 미션이 0건**이 되면 앱 일일미션 카드가 숨겨지므로, 본 모달에 0건화 경고 문구를 함께 노출한다(§5).
- 일시적으로 노출을 멈추려는 경우에는 삭제 대신 사용여부를 **미사용**으로 전환하는 것을 권장한다(미션 풀에 보존).

## 5. 검증·예외 상황

| 상황 | 처리·문구 |
| --- | --- |
| 사용 미션 0건화 | 본문에 경고 추가: "삭제 후 사용 중인 미션이 0건이 되어 앱에 일일미션이 표시되지 않습니다." (삭제는 진행 가능) |
| 당일 배정 회원 | 당일 이미 배정·진행 중인 회원의 미션은 유지·완료 인정. 제외는 다음날 자정부터 반영 |
| 삭제 성공 | Toast (Success): "일일미션이 삭제되었습니다." → 모달 닫기 + 미션 풀에서 제거 |
| 삭제 실패 | Toast (Error): "삭제에 실패했습니다." (모달 유지) |
