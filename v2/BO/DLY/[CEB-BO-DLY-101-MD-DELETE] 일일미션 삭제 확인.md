## 1. 화면 목적

운영자가 일일미션 풀에서 미션 1건을 **삭제하기 전 확인**하는 모달. 삭제는 되돌릴 수 없으므로 대상 미션을 명시하고 확인을 받는다.

### 진입 경로

- [CEB-BO-DLY-101] 일일미션 관리 > 미션 행 [삭제]

---

## 2. UI 설명

### 2.1 모달 레이아웃

```
┌─────────────────────────────────────────────┐
│  미션을 삭제하시겠어요?                       │
├─────────────────────────────────────────────┤
│  '게임존 방문' 미션을 미션 풀에서 삭제합니다. │
│  삭제 후에는 그날의 미션 선택 대상에서        │
│  제외됩니다.                                  │
├─────────────────────────────────────────────┤
│              [ 취소하기 ]   [ 삭제하기 ]      │
└─────────────────────────────────────────────┘
```

### 2.2 본문 구성

| 영역 | 내용 |
| --- | --- |
| 타이틀 | "미션을 삭제하시겠어요?" |
| 본문 | "'{미션명}' 미션을 미션 풀에서 삭제합니다. 삭제 후에는 그날의 미션 선택 대상에서 제외됩니다." |
| 액션 | [취소하기] / [삭제하기] |

> 시각적 스타일은 프로토타입 참조

---

## 3. 화면 내 기능설명

| 요소 | 동작 |
| --- | --- |
| [삭제하기] | 미션 풀에서 해당 미션 제거 + 모달 닫기 + 완료 토스트(§5) |
| [취소하기] / [X] / 외부 클릭 | 삭제 취소 + 모달 닫기 (미션 유지) |

---

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.

### 4.2 삭제 규칙

- 삭제된 미션은 미션 풀에서 제거되어 이후 미션 선택 대상에서 제외된다.
- 일시적으로 노출을 멈추려는 경우에는 삭제 대신 사용여부를 **미사용**으로 전환하는 것을 권장한다(미션 풀에 보존).
