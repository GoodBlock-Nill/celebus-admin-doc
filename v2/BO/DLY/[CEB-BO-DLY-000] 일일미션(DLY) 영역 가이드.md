## 1. 개요

일일미션(DLY) 영역은 회원의 **데일리 루프**(출석 체크 · 오늘의 일일미션 · 연속 출석 스트릭)를 운영하는 백오피스 영역이다. 운영자는 미션 풀을 구성하고 하루 제시 미션 수를 설정한다. 회원 대면 동작은 앱 [CEB-FQ-501] 일일 미션(유저 대면명 "오늘의 할 일")에서 이뤄지며, 백오피스는 그 운영 설정만 담당한다.

데일리 루프 미션은 **계정 단위로 1일 1회 수행**한다(출석·일일미션·스트릭 모두 계정당 1개). 다만 적립되는 **덕력 지급량·사용 여부는 본 영역에서 설정하지 않으며**, [CEB-BO-ART-401-POLICY] 덕력 지급 정책을 단일 기준으로 한다. 덕력은 회원이 활동한 시점의 **선택(현재) 아티스트 그룹 정책**에 따라 지급된다([CEB-000] §5.2·§5.2.2).

| 사이드 메뉴 | 일일미션 |
| 권한 | [CEB-BO-SYS-102] 권한 관리 그룹 설정 |
| 데일리 루프 보상 정책 | [CEB-000] 공통 정책 §5.2 보상 매트릭스 · §6 데일리 루프 |
| 덕력 지급량 단일 기준 | [CEB-BO-ART-401-POLICY] 덕력 지급 정책 (출석·일일미션·스트릭, 선택 아티스트 귀속) |
| 활동 로그 | [CEB-BO-000] 백오피스 공통 정책 |

## 4. 영역 고유 정책

### 4.1 데일리 루프 구성

| 구성 | 설명 | 단위 |
| --- | --- | --- |
| 출석 체크 | 앱 진입 시 1일 1회 출석. 스트릭 카운트의 기준 | 계정당 1개 |
| 일일미션 | 미션 풀에서 매일 자동 선택해 제시. 모두 완료 시 일괄 보상 | 계정당 1세트 |
| 스트릭 | 28일 주기(4주) 연속 출석 일수. 마일스톤(7/14/21/28일) 도달 시 보너스, 28일 주기마다 반복 | 계정당 1개 |

### 4.2 보상 정책 (덕력 지급량은 지급 정책 단일 기준)

데일리 루프 보상의 단일 기준은 [CEB-000] 공통 정책 §5.2·§6이며, **출석·일일미션·스트릭의 덕력 지급량·사용 여부는 [CEB-BO-ART-401-POLICY] 덕력 지급 정책이 단일 기준(SSOT)** 이다. 일일미션 영역은 **덕력 지급량을 설정하지 않으며**, 미션 풀과 하루 제시 미션 수만 운영한다.

| 활동 | 권장값(기본) | 설정 위치 |
| --- | --- | --- |
| 출석 체크 | 5 덕력 | [CEB-BO-ART-401-POLICY] 지급 정책 (아티스트 그룹별) |
| 일일미션 전체 완료 | 25 덕력 (모두 완료 시 일괄) | [CEB-BO-ART-401-POLICY] 지급 정책 (아티스트 그룹별) |
| 스트릭 보너스 | 연속 7일 200 / 14일 500 / 21일 750 / 28일 1,000 덕력 (28일 주기마다 반복) | [CEB-BO-ART-401-POLICY] 지급 정책 (아티스트 그룹별) |

- **선택 아티스트 귀속**: 데일리 루프 미션은 계정 단위로 1일 1회 수행하되, 적립 덕력은 회원이 활동한 시점의 **선택(현재) 아티스트 그룹 정책**에 따라 지급된다([CEB-000] §5.2.2 귀속 매트릭스).
- 그룹별 지급량 조정·미사용 토글·소급 없음 정책은 모두 지급 정책 화면([CEB-BO-ART-401-POLICY])에서 관리한다.
- 보상 티어·구조 자체의 변경은 [CEB-000] 공통 정책 개정 사항이다.

### 4.3 미션 풀·선택 규칙

- 미션 풀은 **페이지 방문형** 미션으로 구성된다. 각 미션은 회원이 누르면 이동하는 앱 화면(이동 대상)을 가지며, 해당 화면에 **1회 진입**하면 완료 처리된다.
- 기본 미션 풀 8종: V01D 페이지 방문 · 게임존 방문 · 기억저장소 방문 · 덕력 랭킹 확인 · 래플 확인 · 컬렉션 확인 · 서포트 이벤트 확인 · 아티스트 정보 확인.
- **미션 선택은 시스템 자동**이다(운영자 비설정). 운영자는 미션 풀 구성(추가·수정·삭제·사용여부)과 하루 제시 개수만 관리한다.

| 선택 규칙 | 설명 |
| --- | --- |
| 선택 방식 | 사용 중인 미션 풀에서 매일 설정한 개수만큼(현 2건) 시스템이 자동 선택 |
| 중복 방지 | 전일과 동일 미션 연속 선택 회피. 당일 제시 미션은 서로 다르게 선택 |
| 미오픈 서비스 | 이동 대상 서비스가 준비 중(Coming Soon)이면 선택에서 제외(미션 등록은 가능, 노출 전까지 미작동) |
| 미션 0건 | 제외 후 제시 가능한 미션이 0건이면 일일미션 카드를 숨기고 출석 체크만 노출 |
| 당일 배정 보존 | 미션은 자정 배정. 운영자가 당일 미션을 삭제·이동 대상 수정해도 당일 배정·진행 중인 회원 미션은 유지·완료 인정하며, 변경은 다음날 자정 재선택부터 반영(소급 없음) |
| 수급 정합 | 하루 제시 수 > 사용 미션 수면 가능 범위만 제시. 운영 화면([CEB-BO-DLY-101])에서 수급 경고·0건화 확인을 제공 |

### 4.4 시간 기준

- 하루 기준은 KST 자정(00:00 ~ 23:59:59)이다.
- 매일 00:00 KST에 출석·일일미션 진행 상태가 리셋되고, 그날 제시할 미션이 미션 풀에서 자동 선택된다.
- 스트릭은 출석 체크 완료를 기준으로 누적되며, 출석이 하루라도 끊기면 연속 일수가 0으로 초기화된다. 또한 **28일 주기(4주)로 순환**하여, 28일 도달(주기 완료) 시 28일 보너스 지급 후 다음날 1일차로 재시작한다(연속 출석 유지 시 주기 반복). 스트릭은 시즌 초기화와 무관하게 유지된다.
