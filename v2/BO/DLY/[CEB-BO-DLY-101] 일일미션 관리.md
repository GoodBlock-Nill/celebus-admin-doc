## 1. 화면 목적

운영자가 회원 **데일리 루프**(출석 체크·일일미션·연속 출석 스트릭)를 운영하는 단일 페이지. 출석·일일미션·스트릭 보너스의 **보상값**을 조정하고, 일일미션 **미션 풀**을 추가·수정·삭제·사용여부 전환한다. 회원 대면 동작은 앱 [CEB-FQ-501]에서 이뤄지며, 본 화면은 그 운영 설정만 담당한다.

데일리 루프는 계정 단위 기능이므로 아티스트 구분 없이 모든 회원에게 동일하게 적용된다.

### 진입 경로

- 사이드 메뉴 > 일일미션

## 2. UI 설명

### 2.1 상단 영역

- Breadcrumb: `일일미션 > 일일미션 관리`
- 화면 타이틀: 일일미션 관리
- 안내 문구: 출석·일일미션·연속 출석(스트릭) 보상과 미션 풀을 운영한다는 설명
- 자정 리셋 안내 박스: "1일 기준 KST 자정(00:00~23:59:59). 매일 자정에 출석·일일미션 진행 상태가 리셋되며 미션 풀에서 그날 제시할 미션이 자동 선택됩니다."

본 페이지는 아래 3개 섹션으로 구성된다: **일일미션 설정 · 미션 풀 · 연속 출석(스트릭) 보너스**.

### 2.2 일일미션 설정 (섹션 1)

운영자가 입력하는 숫자 설정 3종으로 구성된다.

| 항목 | 타입 | 단위 | 설명 |
| --- | --- | --- | --- |
| 하루 제시 미션 수 | 숫자 입력 | 건 | 미션 풀에서 매일 자동 선택해 제시하는 미션 개수 (현 2건) |
| 출석 체크 보상 | 숫자 입력 | 덕력 | 앱 진입 시 1일 1회 지급 |
| 일일미션 전체 완료 보상 | 숫자 입력 | 덕력 | 그날 제시된 미션을 모두 완료하면 일괄 지급 |

### 2.3 미션 풀 (섹션 2)

| 영역 | 내용 |
| --- | --- |
| 섹션 헤더 | "미션 풀 (사용 N종 / 전체 M종)" + 우측 [미션 추가] |
| 시스템 안내 박스 | "미션 선택은 시스템 자동입니다." — 매일 사용 중인 미션 중 설정 개수만큼 자동 선택, 전일 중복 회피, 당일 상이, 부족 시 미노출. 운영자는 미션 풀 구성만 관리 |

미션 풀 테이블 컬럼:

| 컬럼 | 데이터 예시 | 설명 |
| --- | --- | --- |
| 미션명 | 게임존 방문 | 한국어 미션명(기본 언어). 설명 입력 시 하단에 회색 보조 텍스트로 노출 |
| 이동 대상 | 게임존 메인 | 회원이 미션 카드를 누르면 이동하는 앱 화면 |
| 사용여부 | 사용 / 미사용 | 토글. 미사용 미션은 미션 선택 대상에서 제외 |
| 관리 | 수정 / 삭제 | 행별 [수정]·[삭제] 아이콘 버튼 |

- [미션 추가] / 행 [수정] → [CEB-BO-DLY-101-MD-MISSION] 추가·수정 모달
- 행 [삭제] → [CEB-BO-DLY-101-MD-DELETE] 삭제 확인 모달
- 사용여부 토글은 클릭 즉시 반영되며 완료 토스트를 노출한다.

### 2.4 연속 출석(스트릭) 보너스 (섹션 3)

- 안내 문구: 출석을 연속으로 달성한 마일스톤에서 1회성으로 지급. 마일스톤(연속 일수)은 정책 고정이며 보상값만 조정 가능. 출석이 하루라도 끊기면 연속 일수 0으로 초기화.
- 마일스톤 4종(연속 7일 / 14일 / 30일 / 100일) 각각의 보상값을 숫자 입력(덕력)으로 편집한다. 연속 일수는 변경할 수 없다.

### 2.5 변경사항 저장

- 섹션 1(일일미션 설정)과 섹션 3(스트릭 보너스)의 변경은 페이지 하단 [변경사항 저장] 버튼으로 일괄 커밋한다.
- 변경 사항이 없거나 입력값이 유효하지 않으면 버튼은 비활성이다.
- 클릭 시 [변경 내용 요약]을 담은 저장 확인 동작을 거친 뒤 반영된다(§3).
- 미션 풀(섹션 2)의 추가·수정·삭제·사용여부 전환은 [변경사항 저장]과 무관하게 각 액션 시점에 즉시 반영된다.

> 시각적 스타일은 프로토타입 참조

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 읽기·쓰기 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- 쓰기 권한이 없으면 입력·토글·버튼이 비활성 또는 미노출된다.

### 4.2 보상값

- 출석·일일미션·스트릭 보상값은 운영자가 자유롭게 변경할 수 있다(권장 기본: 출석 5 덕력 / 일일미션 일괄 25 덕력 / 스트릭 7·14·30·100일 = 200·500·1,000·5,000 덕력).
- 보상 티어·구조 자체의 변경은 [CEB-000] 공통 정책 개정 사항이다.

### 4.3 미션 풀·선택 규칙

- 미션 풀은 페이지 방문형 미션으로 구성되며, 각 미션은 이동 대상 앱 화면을 1개 가진다. 완료 조건은 해당 화면 1회 진입이다.
- 같은 이동 대상은 미션 풀에서 **중복 등록할 수 없다**(미션 풀 8종은 서로 다른 대상이 원칙). 중복 검증은 [CEB-BO-DLY-101-MD-MISSION]에서 수행한다.
- 미션 **선택은 시스템 자동**이다. 매일 사용 중인 미션 중 설정 개수만큼 자동 선택하며, 전일과 중복을 피하고 당일 제시 미션은 서로 다르게 선택한다. 이동 대상이 준비 중(Coming Soon)인 미션은 제외하며, 제시 가능한 미션이 0건이면 앱에서 일일미션 카드가 숨겨지고 출석 체크만 노출된다.
- 운영자는 미션 풀 구성(추가·수정·삭제·사용여부)과 하루 제시 개수만 관리하며, 그날의 개별 미션을 직접 지정하지는 않는다.

### 4.4 입력 검증

| 항목 | 검증 |
| --- | --- |
| 하루 제시 미션 수 | 1 이상의 정수 |
| 출석 보상 / 일일미션 완료 보상 / 스트릭 보상값 | 0 이상의 정수 |
| [변경사항 저장] 활성 | 모든 입력 유효 + 직전 저장값 대비 변경 존재 |

### 4.5 시간 기준

- 하루 기준은 KST 자정(00:00 ~ 23:59:59)이며, 매일 00:00 KST에 출석·일일미션이 리셋되고 그날 제시 미션이 자동 선택된다.
