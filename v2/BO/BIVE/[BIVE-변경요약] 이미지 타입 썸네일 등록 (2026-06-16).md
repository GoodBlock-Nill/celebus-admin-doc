## 1. 한 줄 요약

> 이미지 타입 BIVE 등록 시 **저용량 썸네일(★, 필수)** 업로드 필드를 신설하고, **전 미디어 타입(이미지·영상·음성)의 썸네일 규격을 단일 저용량 규격(최대 2MB·권장 가로 640px·WebP 우선)으로 통일**했습니다. 도감·컬렉션 리스트·홈 프리뷰는 이 썸네일을 사용하고(원본 직접 로딩 금지), 상세 화면만 원본을 노출합니다.

> 기존: 이미지 타입은 메인 이미지 + 서브 이미지(선택)만 있어 **썸네일 필드 부재** → 리스트가 원본(최대 20MB) 직접 로딩. 영상/음성 썸네일도 "최대 20MB"라 저용량이 아니었음.

## 3. 핵심 개념

- 모든 BIVE는 미디어 타입(이미지·영상·음성)과 무관하게 **저용량 썸네일(★, 필수)** 을 보유한다. 단일 규격 = PNG·JPG·GIF·WebP, 최대 2MB(권장 가로 640px, WebP 우선).
- 이미지 타입은 메인 이미지(★)·서브 이미지(선택)·썸네일(★) **3종**. 영상·음성 타입은 메인(★)·썸네일(★) 2종(보조 칸이 썸네일).
- 도감·컬렉션 리스트·홈 BIVE 프리뷰·카드는 썸네일을 사용하고, 상세 화면만 원본을 노출한다.
- 확보 방식 = **운영자 수동 업로드**(서버 자동 리사이징 채택 안 함). 메인 또는 썸네일 미등록 시 [등록]/활성화 불가.

## 4. 디자이너가 알아야 할 것

- **BIVE 등록([CEB-BO-BIVE-202-CREATE])**: 이미지 타입 선택 시 메인·서브 grid(2열) **아래에 썸네일 박스 1개**를 별도 행으로 추가. 박스 안내 "PNG/JPG/GIF/WebP · 최대 2MB · 권장 가로 640px · WebP 우선". 영상·음성 타입은 기존 2박스(보조=썸네일) 유지하되 안내 문구를 2MB로 갱신.
- **BIVE 상세([CEB-BO-BIVE-202])**: 이미지 타입 미디어 카드 미리보기를 3장(메인·서브·썸네일)으로 확장. 썸네일 카드 라벨 "썸네일 (저용량)".
- **앱 도감([CEB-COL-101])·홈 프리뷰([CEB-HOM-001] §2.7)**: 카드는 저용량 썸네일 사용(표시 동작 동일, 데이터 소스만 썸네일). 상세 미리보기는 원본.

## 5. 개발자가 알아야 할 것

- 이미지 타입 BIVE 데이터에 **썸네일 필드 추가**(필수). 전 타입 썸네일 규격 검증 = PNG·JPG·GIF·WebP, 최대 2MB. 규격 초과·비허용 확장자 시 업로드 거부.
- 등록/활성화 검증: 메인 + 썸네일 미등록 시 [등록] 비활성화·활성화 불가. 이미지 타입 서브 이미지만 선택.
- 리스트·도감·카드·앱 미리보기 API/렌더는 **썸네일 URL**을 사용, 상세만 원본. 영상/음성 기존 썸네일도 2MB 규격으로 통일.
- 타입 변경 시 기존 업로드 파일(메인·서브·썸네일 전부) 초기화는 기존 정책 유지.
