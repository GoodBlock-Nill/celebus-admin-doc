## 1. 화면 목적

개별 아티스트(그룹)의 팬덤 레벨 시즌에 설정된 **레벨별 보상**을 조회하는 화면의 **[보상] 탭**. 레벨을 선택하면 해당 레벨에 설정된 보상 행(디지털 굿즈 / 래플 예고 / 서포트 예고)을 노출 순서대로 조회한다. 본 탭은 조회 전용이며, 보상 추가·수정·삭제는 [CEB-BO-EVT-203-EDIT] 레벨별 보상 수정에서 수행한다.

### 진입 경로

- [CEB-BO-EVT-201] 팬덤 레벨 상세 (레벨·곡선 탭) > [보상] 탭
- URL: `/artists/fandom/{id}?tab=reward`

---

## 2. UI 설명

### 2.1 상단 헤더 (3탭 공통)

- 헤더 구성(타이틀·시즌명·상태 뱃지·현재 레벨 뱃지·라이프사이클 액션)은 [CEB-BO-EVT-201] §2.1과 동일하다. 라이프사이클 액션([게시]/[강제 종료])은 [CEB-BO-EVT-201]이 소유한다.

### 2.2 탭 메뉴 (3탭, 상호 배타)

| # | 탭명 | URL | 문서 |
| --- | --- | --- | --- |
| 1 | 레벨·곡선 | `?tab=curve` | [CEB-BO-EVT-201] |
| 2 | **보상** | `?tab=reward` | 본 문서 |
| 3 | 현황 | `?tab=status` | [CEB-BO-EVT-205] |

### 2.3 레벨 선택

- 레벨 선택 스텝퍼: Lv.1 ~ 설정된 최대 레벨 중 1개 선택. 선택 레벨의 보상 행만 노출된다.
- 선택 레벨 옆에 달성/미달성 뱃지를 표시한다.

### 2.4 보상 목록 (조회, 읽기 전용)

선택 레벨에 설정된 보상 행을 노출 순서대로 카드로 표시한다.

| 표시 항목 | 설명 |
| --- | --- |
| 보상 종류 | 디지털 굿즈 / 래플 예고 / 서포트 예고 |
| 노출 순서 | 앱 보상 리스트 표시 순서 |
| (디지털 굿즈) 보상 타이틀 | 앱 표시명 (한국어·영어·일본어) |
| (디지털 굿즈) BIVE 민팅 캠페인 | 연결된 캠페인명 + "연결 기능 · 아티스트 키우기 보상" + 등록 BIVE 미리보기 + "BIVE 자동 민팅" 표시 |
| (래플 예고) 안내 텍스트 | 한국어·영어·일본어 (예: "Lv.5 달성 시 사인 굿즈 래플 진행 예정") |
| (서포트 예고) 안내 텍스트 | 한국어·영어·일본어 (예: "Lv.10 달성 시 서포트 이벤트 예정") |

- 본 탭은 **조회 전용**이다. 우측 상단 [수정]으로 [CEB-BO-EVT-203-EDIT] 레벨별 보상 수정으로 진입한다.
- 최고레벨(MAX) 도달 시즌·종료 시즌은 [수정]이 **비활성**이며 비활성 사유 안내가 노출된다(§4.3).
- 하단 안내: "디지털 굿즈(BIVE)는 레벨 달성 시 BIVE 영역이 기여 회원 전원에게 자동 민팅합니다. 래플·서포트 예고는 앱 안내 표시 전용이며, 실제 운영은 각 영역(래플·서포트)에서 별도 진행합니다."

> 시각적 스타일은 프로토타입 참조

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- [수정]은 쓰기 권한 보유 그룹만 노출된다.

### 4.2 보상 정책 (조회)

- 보상 종류는 디지털 굿즈(BIVE) / 래플 예고 / 서포트 예고 3종이다([CEB-BO-EVT-000] §4.4).
- 디지털 굿즈만 실제 자동 지급(BIVE 자동 민팅) 대상이며, 래플·서포트 예고는 앱 안내 표시 전용이다.
- 레벨별 보상 설정은 선택이다. 보상 미설정 레벨은 "등록된 보상이 없습니다."로 표시된다(§5).

### 4.3 [수정] 비활성 조건

| 조건 | 비활성 사유 안내 |
| --- | --- |
| 최고레벨(MAX) 도달 시즌 | "최고 레벨 도달 — 시즌 곡선·보상이 확정되어 수정할 수 없습니다." |
| 종료 시즌 | "종료된 시즌 — 읽기 전용" |
| 쓰기 권한 없음 | [수정] 버튼 자체 미노출 |

## 6. 활동 로그
