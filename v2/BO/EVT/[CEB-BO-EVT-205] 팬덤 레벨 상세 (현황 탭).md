## 1. 화면 목적

개별 아티스트(그룹) 시즌의 **레벨업 이력**과 **디지털 굿즈(BIVE) 지급 연계 현황**을 조회하는 화면의 **[현황] 탭**(읽기 전용). 본 탭은 **해당 그룹·해당 시즌 1건**만 조회한다. 모든 그룹·시즌을 한 화면에서 통합 조회하려면 [CEB-BO-EVT-401] 보상·레벨업 현황 메뉴를 사용한다.

> 회원 덕력 변동(기여) 내역은 [CEB-BO-ART-401-HISTORY] 덕력 내역(덕력관리 영역)에서, BIVE 민팅 상세는 [CEB-BO-BIVE-203] 민팅 이벤트 상세에서 조회한다. 래플·서포트 예고는 앱 안내 표시 전용이라 본 현황 지급 대상이 아니다.

### 진입 경로

- [CEB-BO-EVT-201] 팬덤 레벨 상세 (레벨·곡선 탭) > [현황] 탭
- URL: `/artists/fandom/{id}?tab=status`

## 2. UI 설명

### 2.1 상단 헤더 (3탭 공통)

- 헤더 구성(타이틀·시즌명·상태 뱃지·현재 레벨 뱃지·라이프사이클 액션)은 [CEB-BO-EVT-201] §2.1과 동일하다. 라이프사이클 액션은 [CEB-BO-EVT-201]이 소유한다. 본 탭은 액션 버튼이 없다(조회 전용).

### 2.2 탭 메뉴 (3탭, 상호 배타)

| # | 탭명 | URL | 문서 |
| --- | --- | --- | --- |
| 1 | 레벨·곡선 | `?tab=curve` | [CEB-BO-EVT-201] |
| 2 | 보상 | `?tab=reward` | [CEB-BO-EVT-203] |
| 3 | **현황** | `?tab=status` | 본 문서 |

### 2.3 레벨업 이력

상단에 **참여 유저 수**를 시즌 단위 지표로 노출한다. 이는 특정 레벨이 아닌 **시즌 전체 1DUK 이상 기여 회원 수**다(미팅 정합 2026-06-02 — 레벨별 회원 수는 표기하지 않는다).

| 표시 | 설명 |
| --- | --- |
| 참여 유저 수 | "{숫자}명 (시즌 전체 기여 회원)" — 시즌 단위 지표 |

| 컬럼 | 설명 |
| --- | --- |
| 레벨 | 달성 레벨 (Lv.{N}) |
| 달성 일시 | 레벨업 달성 일시 (YYYY.MM.DD HH:mm KST) |
| 연결 보상 | 해당 레벨 보상 요약 (디지털 굿즈 캠페인명 / 래플·서포트 예고 문구) |

- 보상 미설정 레벨도 레벨업 이력에는 표시되며(연결 보상 "-"), BIVE 지급 행은 생성되지 않는다.

### 2.4 디지털 굿즈(BIVE) 지급 연계 현황

디지털 굿즈 보상은 레벨 달성 시 BIVE 영역이 자동 민팅한다. 본 표는 그 연계 결과를 조회한다(상세는 [CEB-BO-BIVE-203]).

| 필터 | 타입 | 설명 |
| --- | --- | --- |
| 레벨 | Dropdown | 레벨(전체) / Lv.{N} — 지급 대상 레벨로 필터 |
| 민팅 상태 | Dropdown | 민팅 상태(전체) / 대기 / 민팅중 / 완료 — BIVE 영역 민팅 상태 연계 |

| 컬럼 | 설명 |
| --- | --- |
| 회원 | 닉네임 |
| 레벨 | 보상 대상 레벨 |
| 캠페인 | 연결된 BIVE 민팅 캠페인명 |
| 지급 상태 | BIVE 영역 민팅 상태 (대기 / 민팅중 / 완료) |
| 일시 | YYYY.MM.DD HH:mm (KST) |

- 안내: "디지털 굿즈 보상만 지급 대상입니다. 래플·서포트 예고는 앱 안내 표시 전용이라 표시되지 않습니다."
- 하단 링크: "전체 통합 조회는 보상·레벨업 현황 메뉴" → [CEB-BO-EVT-401]로 이동.

> 시각적 스타일은 프로토타입 참조

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 읽기 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- 본 탭은 **읽기 전용**이다(액션 없음).

### 4.2 조회 기준

- 본 탭은 진입한 그룹·시즌 1건의 데이터만 조회한다.
- 레벨업 이력 정렬: 달성 일시 내림차순(최신순).
- BIVE 지급 연계 현황 = 레벨 + 민팅 상태 AND 조합 필터. BIVE 영역 민팅 상태를 실시간 반영한다.
- "참여 유저 수"는 시즌 전체 1DUK 이상 기여 회원 단위로만 집계하며 레벨별로 분해하지 않는다.

### 4.3 EVT-205(본 탭) vs EVT-401 구분

| 구분 | [CEB-BO-EVT-205] 현황 탭 | [CEB-BO-EVT-401] 보상·레벨업 현황 |
| --- | --- | --- |
| 조회 범위 | 진입 그룹·해당 시즌 1건 | 전체 그룹·전체 시즌 통합 |
| 진입 | 상세 탭(`?tab=status`) | 사이드 메뉴 / 상세·리스트 연계 |
| 그룹·시즌 필터 | 없음(고정) | 있음(그룹·시즌·기간·닉네임) |
| 용도 | 해당 시즌 모니터링 | CS 대응·정산 점검·전체 모니터링 |
