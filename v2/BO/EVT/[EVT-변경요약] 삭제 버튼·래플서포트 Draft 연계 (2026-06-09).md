## 1. 한 줄 요약

> ① 팬덤레벨 상세 헤더에 **[삭제]** 를 추가했고, **'준비'(게시 전) 상태에서만** 노출한다. ② 레벨별 보상의 **래플·서포트** 를 "안내 텍스트(예고)" 입력에서 **기존 임시저장(Draft) 래플·서포트 객체를 연결**하는 방식으로 바꿨다. 레벨 달성 시 **자동 게시하지 않고**, 운영자가 래플·서포트 영역에서 검토 후 **수동 게시**한다.

> ⚠️ 디지털 굿즈(BIVE) 자동 민팅 보상은 **변동 없음**.

## 3. 핵심 개념

- **삭제 범위**: 준비 시즌은 운영 데이터(누적 덕력·레벨업 이력·BIVE 지급)가 없으므로 안전하게 영구 삭제 가능. 게시 이후 시즌은 강제 종료·자동 종료로 마감(삭제 불가). 연결한 래플·서포트 객체는 각 영역에 보존되고 연결만 해제된다.
- **연결 방식**: EVT에서 래플·서포트를 신규 생성하지 않는다. RFL/SUP 영역에서 미리 만든 **임시저장(Draft)** 객체를 드롭다운으로 선택만 한다.
- **타이틀 독립성**: 앱 팬덤레벨 화면에는 EVT에서 입력한 다국어 타이틀이 표시되며, 이는 연결한 래플·서포트 객체 자체의 타이틀과 별개다.
- **수동 게시**: 레벨 달성은 어떤 자동 게시·운영자 알림도 트리거하지 않는다. 운영자가 래플·서포트 영역에서 검토 후 수동 게시한다.
- 연결 없이 다국어 타이틀만 입력해 앱 예고만 노출하는 것도 허용한다.

## 4. 디자이너가 알아야 할 것

- **팬덤레벨 상세([EVT-201])**: 헤더 준비 상태에 [삭제](위험 톤) + [게시] 병렬. 진행중=[강제 종료], 종료=액션 없음. 삭제 확인 모달([EVT-201-MD-DELETE]) — 제목 "팬덤레벨을 삭제할까요?", 본문 "삭제하면 복구할 수 없습니다. / 준비 상태 팬덤레벨만 삭제할 수 있습니다.", 버튼 [취소]/[삭제하기].
- **레벨별 보상 수정([EVT-203-EDIT])**: 래플·서포트 보상 행 = **(1) 연결 객체 Dropdown(임시저장 상태만, "연결 안 함" 옵션) + (2) 다국어 타이틀(앱 표시명)**. 연결 대상 없으면 앰버 안내("임시저장 래플·서포트가 없습니다…"). 디지털 굿즈 BIVE 블록은 그대로.
- **보상 탭 조회([EVT-203])**: 래플·서포트는 연결 객체명·상태 + 다국어 타이틀 표시("연결 안 함 — 타이틀만 노출" 포함).

## 5. 개발자가 알아야 할 것

- 팬덤레벨 삭제: 준비 상태에서만 허용(서버 검증). 진행중·종료는 [삭제] 미노출 + 직접 호출 차단.
- 레벨별 보상 데이터: 래플·서포트 보상에 **연결 객체 식별값(linkedRaffleId·linkedSupportId, nullable)** + 다국어 타이틀 유지. 안내 텍스트 단독 입력 폐기.
- 연결 대상 필터: 같은 그룹/아티스트의 **임시저장(Draft) 상태** 래플·서포트만. 레벨 달성은 자동 게시 트리거가 아니다(EVT는 게시 권한 없음, RFL/SUP에서 수동 게시).
- 프로토타입 정합:
  - `artists/fandom/[id]/page.tsx`: 준비 상태 [삭제] 버튼 + 삭제 확인 모달(ConfirmModal) → 리스트 복귀 + 토스트
  - `artists/fandom/[id]/_components/RewardTab.tsx`: 래플·서포트 행에 Draft 객체 Dropdown 추가, 안내 입력 → 다국어 타이틀로, 안내 문구를 수동 게시로 교체
  - `mock/fandom.ts`: `FandomReward`에 `linkedRaffleId`·`linkedSupportId` 추가
  - `mock/fanquest.ts`·`mock/support.ts`: `getDraftRaffles`·`getDraftSupports` 헬퍼 추가(임시저장 필터)
