## 1. 화면 목적

운영자가 **준비 상태 팬덤 레벨을 게시**(준비→진행중)하기 전 확인을 받는 모달. 게시하면 앱에 노출되고 운영이 시작되므로 명시적 확인을 거친다.

- **누가**: 팬덤 레벨 쓰기 권한이 있는 백오피스 관리자
- **결과**: 시즌 상태가 "준비" → "진행중"으로 전환되고 앱 [CEB-EVT-201]에 노출 시작

## 3. 기능 설명

| 버튼 | 동작 |
| --- | --- |
| 게시 | 게시 검증 통과 시 시즌 상태 "준비" → "진행중" 전환 + 모달 닫기 + 성공 토스트 + 활동 로그. 상세 헤더 자동 갱신(상태 뱃지 변경 + 액션 버튼 [강제 종료]로 교체) |
| 취소 / [X] / 모달 외부 클릭 | 모달 닫기. 상태 유지 |

---

## 4. 로직·플로우

1. [CEB-BO-EVT-201] 레벨·곡선 탭 헤더 [게시] 클릭(준비 상태에서만 노출)
2. 본 확인 모달 열림
3. [게시] 클릭 → **레벨 5개 이상 설정 여부 검증**
   - 5개 미만: 모달 닫고 차단 토스트(§5)
   - 5개 이상: 진행중 전환 + 성공 토스트(§5) + 활동 로그
4. [취소]·[X]·외부 클릭: 모달 닫고 준비 상태 유지

## 5. 검증·예외 상황

| 상황 | 처리·문구 |
| --- | --- |
| 레벨 5개 미만 게시 시도 | Toast (Error): "레벨을 5개 이상 설정해야 게시할 수 있습니다." (게시 차단, 준비 상태 유지) |
| 게시 성공 | Toast (Success): "'{시즌명}' 팬덤레벨을 게시했습니다." |
| 게시 실패 | Toast (Error): "게시에 실패했습니다." |
| 쓰기 권한 없음 | 상세 헤더 [게시] 미노출 → 본 모달 호출되지 않음 |
