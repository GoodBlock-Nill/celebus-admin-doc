## 1. 화면 목적

운영자가 **준비(게시 전) 상태 팬덤 레벨 시즌을 영구 삭제**하기 전 확인을 받는 모달. 게시 이후 시즌은 운영 데이터(누적 덕력·레벨업 이력·디지털 굿즈 지급)가 쌓이므로 삭제할 수 없으며, 진행중·종료 시즌은 강제 종료·자동 종료로 마감한다. 따라서 삭제는 **준비 상태에서만** 허용한다.

- **누가**: 팬덤 레벨 삭제 권한이 있는 백오피스 관리자
- **결과**: 준비 시즌과 설정한 레벨 곡선·보상이 영구 삭제되고, 팬덤 레벨 리스트로 복귀한다

## 3. 기능 설명

| 버튼 | 동작 |
| --- | --- |
| 삭제하기 | 준비 시즌 영구 삭제(시즌·곡선·보상 설정 일괄) + 모달 닫기 + 성공 토스트 + 활동 로그 + [CEB-BO-EVT-101] 팬덤 레벨 리스트로 복귀 |
| 취소 / [X] / 모달 외부 클릭 | 모달 닫기. 시즌(준비) 유지 |

## 4. 로직·플로우

1. [CEB-BO-EVT-201] 레벨·곡선 탭 헤더 [삭제] 클릭(**준비 상태에서만 노출**)
2. 본 확인 모달 열림
3. [삭제하기] 클릭 → 시즌 영구 삭제 + 성공 토스트(§5) + 활동 로그 + 리스트 복귀
4. [취소]·[X]·외부 클릭: 모달 닫고 준비 상태 유지

### 4.1 삭제 범위

| 데이터 | 처리 |
| --- | --- |
| 시즌 기본 정보 | 영구 삭제 |
| 레벨 곡선 설정 | 영구 삭제 |
| 레벨별 보상 설정 | 영구 삭제(연결한 임시저장 래플·서포트 객체는 각 영역에 그대로 보존 — 연결만 해제) |
| 운영 데이터 | 준비 시즌은 누적 덕력·레벨업 이력이 없으므로 삭제 영향 없음 |
