## 1. 화면 목적

레벨별 보상 수정 화면에서 [저장] 클릭 시, 변경된 보상이 앱에 반영됨을 안내하고 저장 여부를 확인받는 모달.

---

## 2. UI 설명

### 2.1 모달 레이아웃

```
┌───────────────────────────────────────────┐
│  보상을 저장할까요?                          │
├───────────────────────────────────────────┤
│  · 변경된 레벨 보상이 앱에 반영됩니다.        │
├───────────────────────────────────────────┤
│                    [ 취소 ]   [ 저장 ]      │
└───────────────────────────────────────────┘
```

### 2.2 본문 구성

| 영역 | 내용 |
| --- | --- |
| 제목 | "보상을 저장할까요?" |
| 본문 | "변경된 레벨 보상이 앱에 반영됩니다." |
| 버튼 | [취소] / [저장] |

> 시각적 스타일은 프로토타입 참조

---

## 3. 기능 설명

| 버튼 | 동작 |
| --- | --- |
| 저장 | 보상 저장 처리 + 모달 닫기 + 성공 토스트 + 활동 로그 → 조회 모드 복귀 |
| 취소 / [X] / 모달 외부 클릭 | 모달 닫기. 수정 화면 유지(입력값 보존) |

---

## 4. 로직·플로우

1. [CEB-BO-EVT-203-EDIT]에서 입력 검증 통과 후 [저장] 클릭 → 본 모달
2. [저장] 클릭 → 보상 저장 + 성공 토스트(§5) + 활동 로그 → 조회 모드([CEB-BO-EVT-203]) 복귀
3. [취소]: 모달만 닫고 수정 화면 유지

- 본 모달은 [저장] 전 입력 검증(디지털 굿즈 한국어 타이틀 필수 등, [CEB-BO-EVT-203-EDIT] §5)을 통과해야 노출된다.
