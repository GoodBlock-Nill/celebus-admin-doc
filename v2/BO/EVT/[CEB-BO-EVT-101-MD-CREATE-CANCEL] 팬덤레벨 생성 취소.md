## 4. 로직·플로우

[CEB-BO-EVT-101-MD-CREATE] 생성 모달에서 [취소](또는 입력값이 있는 상태로 모달 외부 클릭·[X]) → 본 확인 모달 → [확인] 시 폐기·이탈 / [다시 돌아가기] 시 작성 유지.

- 입력값이 전혀 없는 상태에서는 본 확인 모달 없이 생성 모달이 바로 닫힌다.

---

## 5. 검증·예외 상황

- 작성 내용이 있을 때만 본 확인 모달이 노출된다(빈 입력은 즉시 닫기).
- [확인] 시 생성은 수행되지 않으므로 활동 로그·토스트가 발생하지 않는다.
