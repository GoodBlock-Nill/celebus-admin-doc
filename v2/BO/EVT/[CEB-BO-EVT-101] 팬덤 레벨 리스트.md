## 1. 화면 목적

운영자가 아티스트(그룹)별 팬덤 레벨을 **수동 생성·관리**하는 화면. 운영자는 [생성]으로 아티스트·시즌 단위 팬덤레벨을 직접 생성하고(준비), 상태(준비/진행중/종료)별로 조회하며, 개별 팬덤레벨 상세로 진입한다. **자동 생성되지 않는다.**

### 진입 경로

- 사이드 메뉴 > 아티스트 > 팬덤레벨

---

## 2. UI 설명

### 2.1 상단 영역

- Breadcrumb: `홈 > 아티스트 > 팬덤레벨`
- 화면 타이틀: 팬덤레벨
- 우측 상단 액션: [생성] (Primary) — [CEB-BO-EVT-101-MD-CREATE] 팬덤레벨 생성 모달

### 2.2 상태 카운터 (3개)

| 카운터 | 의미 |
| --- | --- |
| 준비 | 생성 후 게시 전 (곡선·보상 설정 단계) |
| 진행중 | 앱 노출·운영 중 |
| 종료 | 시즌 마감 |

- 첫 진입 시 상태 필터는 **전체**다(특정 상태로 고정하지 않음).
- 카운터 클릭 시 해당 상태로 필터링되고, **같은 카운터를 다시 클릭하면 전체로 해제**된다(토글).

### 2.3 검색·필터 영역

| 구분 | 요소 | 타입 | 설명 |
| --- | --- | --- | --- |
| 필터 | 상태 | Dropdown | 상태(전체) / 준비 / 진행중 / 종료 |
| 필터 | 시즌 | Dropdown | 시즌(전체) / 시즌 연도별 |
| 입력 | 그룹명 | Text Input | 부분 일치 검색 (입력 안내: "그룹명 입력") |
| 버튼 | 초기화 | Dark Button | 상태·시즌 필터·검색어 리셋 |

### 2.4 생성

- 우측 상단 [생성] 클릭 시 [CEB-BO-EVT-101-MD-CREATE] 팬덤레벨 생성 모달이 열린다(자동 생성 없음).
- 모달에서 아티스트·시즌 연도·시즌명을 입력해 **준비** 상태로 생성하면 리스트 최상단에 추가된다. 레벨 곡선·보상 등 상세 항목은 생성 후 [CEB-BO-EVT-201] 상세에서 설정한다.
- 입력 항목·중복 차단·성공 토스트 등 상세 규칙은 [CEB-BO-EVT-101-MD-CREATE]를 따른다.

### 2.5 목록 영역 (테이블)

| 컬럼 | 데이터 예시 | 설명 |
| --- | --- | --- |
| 상태 | 준비 / 진행중 / 종료 | 상태 뱃지 |
| 그룹 | V01D | 아티스트 그룹명 (한국어 우선) |
| 현재 시즌 | V01D 팬덤 2기 (2026) | "{아티스트} 팬덤 N기 (YYYY)" |
| 시즌 기간 | 2026.01.01 ~ 2026.12.31 | 캘린더 연도 |
| 레벨 수 | 10 | 설정된 레벨 단계 수 (미설정 시 "-") |
| 현재 팬덤 레벨 | Lv.4 | 현재 달성 레벨 (최고레벨 도달 시 "Lv.10 MAX", 미설정 시 "-") |
| 누적 덕력 | 1,240,000 | 시즌 내 팬덤 전체 누적 획득 덕력 |
| 참여 팬 수 | 8,210 | 시즌 내 1DUK 이상 기여 회원 수 |
| 업데이트 일시 | 2026.05.28 17:21 | YYYY.MM.DD HH:mm (KST) |

- Row 클릭 → [CEB-BO-EVT-201] 팬덤 레벨 상세 이동
- 페이지네이션: 하단 중앙

> 시각적 스타일은 프로토타입 참조

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 읽기·쓰기 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.

### 4.2 정렬·필터

- 기본 정렬: **누적 덕력 내림차순**(많은 순). 사용자 변경 불가.
  - 곡선·누적 덕력이 아직 없는 준비 시즌(누적 덕력 0, 레벨 수 "-")은 누적 덕력 0으로 간주되어 목록 하단에 정렬된다.
  - 누적 덕력이 동일하면 2차 정렬로 업데이트 일시 내림차순(최신순)을 적용한다.
- 첫 진입 기본 필터: 전체. 상태 카운터 재클릭 시 전체로 해제(토글).
- 상태 필터 + 시즌 필터 + 그룹명 검색 = AND 조합. 그룹명 검색은 한국어·영어 통합 부분 일치.
- 필터·검색어 변경 시 1페이지로 이동하며, 결과가 현재 페이지 수보다 적으면 마지막 페이지로 보정한다.
- 페이지당 10건.

### 4.3 상태 정의

| 상태 | 의미 | 앱 노출 |
| --- | --- | --- |
| 준비 | 생성 후 게시 전 (상세에서 곡선·보상 설정) | 미노출 |
| 진행중 | 앱 노출·운영 중 | 노출 |
| 종료 | 시즌 마감 | 미노출 |

> 운영자 상태 전환은 [게시](준비→진행중)만 수행하며, 종료는 12.31 자동(또는 [강제 종료])이다. 상세 정의는 [CEB-BO-EVT-000] §4.1.1 참조.

## 6. 활동 로그

목록 조회는 로그를 기록하지 않는다. 팬덤레벨 생성 로그는 [CEB-BO-EVT-101-MD-CREATE] 생성 모달에서 발생하며, 곡선·보상·상태 전환 로그는 [CEB-BO-EVT-201]·[CEB-BO-EVT-201-EDIT]·[CEB-BO-EVT-203-EDIT]에서 발생한다.

| 액션 | 로그 메시지 (한국어) | 발생 위치 |
| --- | --- | --- |
| 팬덤레벨 생성 | '{시즌명}' 팬덤레벨을 생성했습니다. (그룹: {그룹명}) | [CEB-BO-EVT-101-MD-CREATE] |
