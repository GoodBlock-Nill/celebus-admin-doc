## 1. 화면 목적

팬덤 레벨 시즌의 **레벨 곡선**(레벨 수·레벨별 목표 덕력)을 수정하는 화면. [CEB-BO-EVT-201] 레벨·곡선 탭에서 [수정] 진입 시 기존 곡선이 채워진 상태로 열린다. 레벨 추가·삭제·목표 덕력 입력·권장 곡선 일괄 적용을 제공한다.

### 진입 경로

- [CEB-BO-EVT-201] 팬덤 레벨 상세 (레벨·곡선 탭) > [수정]
- URL: `/artists/fandom/{id}?tab=curve` 의 수정 모드

> 본 화면은 별도 페이지 이동이 아니라 레벨·곡선 탭 내 **수정 모드**로 동작한다(조회 ↔ 수정 모드 전환). 운영 일관성을 위해 입력·검증·저장 규칙을 독립 문서로 분리해 정의한다.

## 2. UI 설명

### 2.1 상단 헤더

- 타이틀: `{그룹명}` + 시즌명 (조회 탭과 동일 헤더)
- 우측 상단 액션: [권장 곡선 적용] / [저장] / [취소]
- **[저장]은 변경 사항이 없으면 비활성** 상태이다(§4.2).

### 2.2 레벨 곡선 입력 테이블

| 컬럼 | 입력/표시 |
| --- | --- |
| 레벨 | Lv.1 ~ (최대 10). 최종 레벨에 MAX 표시 |
| 레벨업 목표 덕력 (DUK) | Text Input(숫자, 천 단위 콤마). 달성 레벨은 입력 비활성(회색) |
| 권장값 | 권장 곡선 참고값 (회색, 참고 전용) |
| 달성 여부 | 달성 / 미달성 뱃지 |
| 달성 일시 | 레벨업 달성 일시 (미달성 시 "-") |
| 삭제 | 행 삭제 [X] (달성 레벨은 비활성) |

- 하단 [레벨 추가]: 미달성 신규 레벨을 추가(최대 10단계). 추가 시 권장 곡선 다음 단계값이 기본 채워진다.
- 안내 문구: "진행중 시즌에도 미달성 레벨(현재 레벨 초과)을 추가할 수 있습니다. 신규 레벨 보상은 추가 이후 달성 시점부터 적용되며 기존 지급분은 변경되지 않습니다."

### 2.3 헤더 액션

| 요소 | 동작 |
| --- | --- |
| [권장 곡선 적용] | 권장 곡선값을 각 레벨 목표 덕력에 일괄 채움 + 토스트 "권장 곡선값을 적용했습니다." |
| [저장] | 입력 검증 후 [CEB-BO-EVT-201-EDIT-MD-SAVE] 곡선 저장 확인 모달 |
| [취소] | 변경이 있으면 [CEB-BO-EVT-201-EDIT-MD-CANCEL] 곡선 수정 취소 모달, 변경 없으면 즉시 조회 모드 복귀 |

> 시각적 스타일은 프로토타입 참조

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- 최고레벨(MAX) 도달 시즌·종료 시즌은 [CEB-BO-EVT-201] 조회 탭에서 [수정]이 비활성이므로 본 수정 화면에 진입할 수 없다.

### 4.2 변경 판정·[저장] 활성

- **변경 사항이 있을 때만 [저장]이 활성화**된다. 변경 판정 대상 = 레벨 수(추가·삭제)·각 레벨 목표 덕력 중 하나라도 진입 시점 값과 달라진 경우.
- 변경이 전혀 없으면 [저장]은 비활성이고, [취소]는 확인 모달 없이 바로 조회 모드로 복귀한다.

### 4.3 달성 레벨·신규 레벨 규칙

- **이미 달성된 레벨**(현재 레벨 이하)은 목표 덕력 수정·삭제가 불가하다(입력·삭제 비활성).
- **신규 레벨 추가**는 미달성 레벨(현재 레벨 초과)에 대해서만 가능하다. 신규 레벨 보상은 추가 이후 달성 시점에 기여 회원(1DUK 이상)에게 적용되며, 기존 달성·지급분은 소급 변경되지 않는다([CEB-BO-EVT-000] §4.1.2).
- 레벨은 최대 10단계까지 설정할 수 있다.

### 4.4 카운터 모델

- 각 레벨은 0부터 시작해 목표 도달 시 다음 레벨 진입과 동시에 카운터 0으로 리셋된다([CEB-BO-EVT-000] §4.2). 목표 덕력은 해당 레벨 단독 목표값이다.
