## 1. 화면 목적

팬덤 레벨 시즌의 **레벨별 보상**을 추가·수정·삭제하는 화면. [CEB-BO-EVT-203] 보상 탭에서 [수정] 진입 시 선택 레벨의 보상 행이 채워진 상태로 열린다. 보상 종류(디지털 굿즈 / 래플 예고 / 서포트 예고)별 입력·노출 순서 조정을 제공한다.

### 진입 경로

- [CEB-BO-EVT-203] 팬덤 레벨 상세 (보상 탭) > [수정]
- URL: `/artists/fandom/{id}?tab=reward` 의 수정 모드

> 본 화면은 보상 탭 내 **수정 모드**로 동작한다(조회 ↔ 수정 모드 전환). 입력·검증·저장 규칙을 독립 문서로 정의한다.

## 2. UI 설명

### 2.1 상단 헤더

- 타이틀: `{그룹명}` + 시즌명 (조회 탭과 동일 헤더)
- 레벨 선택 스텝퍼: Lv.1 ~ 최대 레벨. 선택 레벨의 보상을 편집한다.
- 우측 상단 액션: [보상 추가] / [저장] / [취소]
- **[저장]은 변경 사항이 없으면 비활성** 상태이다(§4.2).

### 2.2 보상 행 입력

선택 레벨에 보상 행을 추가하고 인라인 편집한다.

| 입력 항목 | 보상 종류 | 설명 |
| --- | --- | --- |
| 보상 종류 | 공통 | Dropdown — 디지털 굿즈 / 래플 예고 / 서포트 예고. 변경 시 무효 입력 필드 초기화 |
| 노출 순서 | 공통 | 숫자 입력. 앱 보상 리스트 표시 순서 |
| 보상 타이틀 (한국어·영어·일본어) | 디지털 굿즈 | 앱 표시명. **한국어 필수**(§5) |
| BIVE 민팅 캠페인 | 디지털 굿즈 | Dropdown — "아티스트 키우기 보상" 연결 기능 활성 BIVE 캠페인. 선택 시 등록 BIVE 미리보기·연결 기능 표시 (§2.3) |

| 다국어 타이틀 (한국어·영어·일본어) | 래플 예고 / 서포트 예고 | 앱 팬덤레벨 화면 표시명. 연결 객체 자체 타이틀과 별개 |

| 항목 | 정책 |
| --- | --- |

| 표시 형식 | 캠페인명 + 선택 시 "연결 기능 · 아티스트 키우기 보상 / 등록 BIVE 미리보기"(등록 BIVE 이름 칩 목록) + "BIVE 자동 민팅" 안내 |

| 민팅 안내 | "레벨 달성 시 BIVE 영역이 기여 회원(1DUK 이상)에게 자동 민팅합니다." |

| 항목 | 정책 |

| 보상 종류 변경 시 | 래플 예고↔서포트 예고 전환 시 연결 객체는 초기화된다(다국어 타이틀은 유지) |

## 4. 규칙·로직

### 4.1 권한

- 권한 그룹별 읽기·쓰기·삭제 범위는 [CEB-BO-SYS-102] 권한 관리 그룹 설정을 따른다.
- 최고레벨(MAX) 도달 시즌·종료 시즌은 [CEB-BO-EVT-203] 조회 탭에서 [수정]이 비활성이므로 본 수정 화면에 진입할 수 없다.

### 4.2 변경 판정·[저장] 활성

- **변경 사항이 있을 때만 [저장]이 활성화**된다. 변경 판정 대상 = 보상 행 추가·삭제·보상 종류·보상 타이틀(3언어)·BIVE 캠페인·예고 텍스트(3언어)·노출 순서 중 하나라도 진입 시점 값과 달라진 경우.
- 변경이 없으면 [저장]은 비활성이고, [취소]는 확인 모달 없이 바로 조회 모드로 복귀한다.

### 4.3 달성 레벨 잠금

- **이미 달성된 레벨**(현재 레벨 이하)의 보상은 지급(BIVE 자동 민팅)이 완료됐으므로 추가·수정·삭제가 불가하다(소급 없음). 달성 레벨 선택 시 입력·삭제가 비활성되고 안내가 노출된다(§5).
- 진행중 시즌에도 **미달성 레벨**의 보상은 자유롭게 수정할 수 있다.

### 4.4 보상 종류 변경

- 보상 종류를 바꾸면 이전 종류에서만 쓰던 입력 필드(BIVE 캠페인, 연결 래플·서포트)는 초기화된다. 디지털 굿즈로 바꾸면 활성 캠페인 첫 항목이 기본 선택된다. 래플 예고↔서포트 예고 간 전환 시 연결 객체는 초기화되고 다국어 타이틀은 유지된다.
