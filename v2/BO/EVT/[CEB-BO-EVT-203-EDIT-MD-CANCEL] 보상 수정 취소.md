## 1. 화면 목적

레벨별 보상 수정 중 저장하지 않은 변경이 있는 상태로 [취소]·탭 전환·뒤로가기 등 이탈을 시도할 때, 변경 내용이 사라짐을 안내하고 이탈 여부를 확인받는 모달. 백오피스 공용 확인 모달로 제공한다(브라우저 기본 확인창 사용 안 함).

## 3. 기능 설명

| 버튼 | 동작 |
| --- | --- |
| 다시 돌아가기 | 본 확인 모달만 닫고 수정 화면 유지(변경 보존) |
| 이동 | 변경 폐기 후 이탈 — [취소] 진입이면 조회 모드 복귀, 탭 전환 진입이면 해당 탭으로 이동, 뒤로가기 진입이면 리스트로 이동 |

---

## 4. 로직·플로우

본 모달은 다음 이탈 시점에 **변경 사항이 있을 때만** 노출된다.

| 진입 시점 | [이동] 시 결과 |
| --- | --- |
| 수정 화면 [취소] | 조회 모드([CEB-BO-EVT-203]) 복귀 |
| 다른 탭으로 전환([CEB-BO-EVT-201]/[CEB-BO-EVT-205]) | 해당 탭으로 이동 |
| 뒤로가기·브레드크럼 이탈 | [CEB-BO-EVT-101] 리스트 등 대상 화면으로 이동 |

- 변경 사항이 없으면 본 모달 없이 즉시 이탈한다.

---

## 5. 검증·예외 상황

- 변경 판정 대상은 [CEB-BO-EVT-203-EDIT] §4.2(보상 행·종류·타이틀·캠페인·예고 텍스트·노출 순서)를 따른다. 변경이 없으면 본 모달은 노출되지 않는다.
- [이동] 시 저장은 수행되지 않으므로 활동 로그·토스트가 발생하지 않는다.
