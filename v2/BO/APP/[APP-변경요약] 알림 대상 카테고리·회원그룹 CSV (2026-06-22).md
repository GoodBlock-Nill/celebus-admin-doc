## 1. 한 줄 요약

> 알림 카테고리를 **수동 알림·자동 트리거·회원 앱 알림함 공통 4종(아티스트·이벤트·게임존·공지)** 으로 일원화하고, 새 알림 작성([CEB-BO-APP-302]) 대상 섹션에 **① 카테고리 공통 필수 선택 신설** + **② 특정 회원 그룹 CSV 파일 첨부 전용 + 업로드 회원 명단(닉네임·이메일·페이지당 20명·총 회원 수)** 을 정의했습니다.

카테고리 4종은 **이미 회원 앱 알림함([CEB-NTF-510])이 보유한 필터 탭**과 동일하다. BO에서 카테고리를 지정할 수단이 없던 갭을 메우고, 자동 트리거 카테고리(기존 5종)까지 동일 4종으로 통일해 **수동·자동·앱 알림함이 단일 카테고리 체계**로 정합되었다.

## 2. 변경 내용

### 2-1. 카테고리 (대상 섹션 공통·필수)

| 항목 | 내용 |
| --- | --- |
| 위치 | 대상 섹션 상단 — 대상 종류(전역/아티스트 팬덤/특정 회원 그룹)와 **무관하게 공통 노출** |
| 옵션 | 아티스트 / 이벤트 / 게임존 / 공지 (단일 선택) |
| 필수 | **필수** — 미선택 시 [발송]·[예약 발송] 차단 |
| 용도 | 회원 앱 알림함([CEB-NTF-510]) 카테고리 탭 분류·필터 기준 |
| 공통 체계 | **수동·자동 트리거·앱 알림함 공통 4종** — 자동 트리거 기존 5종(래플/응원·퀘스트/BIVE/회원 활동/시스템 공지)을 4종으로 통일 매핑(래플·퀘스트→이벤트, BIVE→아티스트, 회원 활동·시스템→공지) |

### 2-2. 특정 회원 그룹 — CSV 전용 + 업로드 명단

| 항목 | 내용 |
| --- | --- |
| 입력 방식 | 기존 "회원 검색·선택(다중) 또는 CSV 업로드" → **CSV 파일 첨부만** |
| 회원 매칭 | CSV **이메일 컬럼** 기준. 미존재·중복 이메일 제외, 탈퇴·휴면·차단 자동 제외 |
| 명단 표시 | 첨부 후 섹션 하단에 명단 — 컬럼 **번호·닉네임·이메일** |
| 페이지네이션 | **페이지당 20명** |
| 총 회원 수 | "총 {N}명" 표시 |

### 2-3. 자동 트리거 카테고리 통일 (수동 알림과 동일 4종)

자동 트리거 카테고리를 수동 알림과 **동일 4종**으로 일원화. 기존 5종을 다음과 같이 매핑한다.

| 기존 자동 트리거 (5종) | → 통일 (4종) |
| --- | --- |
| 래플 / 응원·퀘스트 | 이벤트 |
| BIVE | 아티스트 |
| 회원 활동 / 시스템 공지 | 공지 |
| (게임 트리거 신설 시) | 게임존 |

> 통일 후 BO 알림 리스트(수동·자동 탭)·작성 화면·회원 앱 알림함 카테고리가 모두 4종으로 동일하다.

## 4. 확인·결정 사항

- **카테고리 = 앱 알림함 분류·필터용 · 필수** (사용자 결정). NTF-510의 기존 4종과 일치
- **CSV = 이메일 식별 · 명단 컬럼 닉네임·이메일** (사용자 결정). 명단은 임의 생성이 아닌 **실제 회원 리스트 참조**
- 딥링크 "소스 타입"(자유 텍스트)은 유지 — 카테고리와 공존(대체 아님)
