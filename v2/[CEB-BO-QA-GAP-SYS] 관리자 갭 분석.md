## 1. 관리자 리스트 (sys-admins, /admins/list)
- **QA 정합**: 컬럼(계정상태·권한명·관리자명·이메일·등록일시·최근 로그인 일시)·[관리자 초대]·상태 필터·검색(관리자명)·[초기화] — TC_0004/0005 정합
- ⚪ **TC_0001**: h1 "관리자현황" (QA "관리자 리스트") — 정정
- ⏳ 상태 카드(전체/Active/Pending/Locked/Inactive)는 테스트 데이터 적어 '전체'만 노출 확인 / 권한 그룹 필터·관리자 상세(9)·초대 모달(2): 후속

## 2. 권한 그룹 리스트 (sys-permissions, /admins/permissions)
- **QA 정합**: 카드(전체 2·Active 2·Inactive 0)·컬럼(권한상태·권한명·관리자 수·관리자명)·유형 배지(수정불가·기본값·운영자 정의)·[권한 생성]·상태 필터·검색·[초기화] — TC_0003/0005 정확 일치
- ⚪ **TC_0001**: h1 "권한관리" (QA "권한 그룹 리스트") — 정정
- 실데이터: Super Admin(수정불가·8명)·Viewer(기본값·3명) / ⏳ 권한 그룹 상세(8, ?tab 동기화)·권한 생성 모달(2): 후속

> 관리자 영역 종합: 리스트 2화면 QA 정합 양호(h1 ⚪ 2건만). SUPER 전용 접근 제어·컬럼·배지·필터 정합. 잔여: 상세·모달·시스템 연동.

## 3. 권한 그룹 상세 (/admins/permissions → 행 클릭)
- **QA 정합**: 3탭(기본정보·권한설정·관리자(N명))·권한설정 = 영역별 R/W/D(읽기·쓰기·삭제) 매트릭스·관리자 매핑(Super Admin 8명) — TC_0010 정합. (BO 매트릭스 영역 행 ~14, QA "12영역" — 영역 수 근사, 회원·아티스트·앱·BIVE·게임존·팬퀘스트·관리자 등 포함)
- ⏳ 프리셋/기본값 수정·삭제 비활성·운영자 정의 R/W/D 변경·SYS 영역 부여 불가(TC_0011~0017): mutation/권한 의존

## 4. 관리자 상세 (/admins/{id})
- **QA 정합**: h1 "관리자 상세 ({이름})"·[비밀번호 재설정 메일발송][수정하기]·기본정보(관리자명·이메일·등록일시·최근 로그인·권한·계정 활성화 토글)·활동 로그 테이블 — TC_0011/0012/0017 정합 / ⚪ "비밀번호 재설정 메일발송"(QA "[비밀번호 재설정]")
- ⏳ SUPER 전용 액션(권한 변경·만료 연장·세션 종료·잠금/비활성화 — 사유 필수)·활동 로그 필터(TC_0013~0019): mutation/SUPER 의존
