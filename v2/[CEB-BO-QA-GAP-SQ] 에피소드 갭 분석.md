## 1. 에피소드 그룹 리스트 (/sq/groups/list)
- **QA 정합**: h1 "그룹 리스트"·카드(전체 4·임시저장 0·진행중 3·종료 1)·[새 그룹 생성]·필터(상태·아티스트) — TC_0002~0004 정합
- ⚪ **TC_0006**: BO 컬럼 = 상태·아티스트·타이틀·시작일·종료일·최근 수정자·관리. QA "에피소드 수" 컬럼이 BO 리스트에 미표시(아티스트 그룹 리스트의 팔로워 수와 유사 패턴). 마지막 관리 컬럼 존재.
- ⏳ 페이지당 20건(TC_0008, 그룹 4건이라 미검증)·빈 메시지: 후속

## 2. 에피소드 그룹 상세 (/sq/groups/{gid})
- **QA 정합**: 섹션(그룹 정보·관리 정보·메인 에피소드·반복 에피소드)·진행중=[수정하기][종료하기] — TC_0019~0023 정합 / ⚪ 액션 라벨 "수정하기·종료하기"(QA "[그룹 수정]·[종료 전환]")
- ⚠ **에피소드 목록 레이아웃**: BO는 **테이블**(순서·상태·이미지·에피소드·미션·참여 현황·관리) — QA TC_0024/0025는 "카드"(메인 이미지 3:4·타이틀·미션 수 N/10·진행/완료·검수 대기)로 묘사. 데이터 항목은 유사하나 표현이 카드↔테이블 상이 — 재확인 대상
- ⏳ 에피소드 상세·생성·수정·미션 추가/상세/수정: 후속

## 6. 에피소드 그룹 생성 폼 (/sq/groups/create, mutation 시도)
- **폼 구조 정합**: h1 "새 에피소드 그룹 생성"·아티스트 드롭다운(활성 그룹 14)·타이틀·시작/종료일시(달력 위젯+시간)·[취소][생성](비활성) — TC_0010/0011
- 🟠 **TC_0012**: 안내 "ACTIVE 상태는 아티스트당 1개만 허용됩니다." — 영문 enum **"ACTIVE"** 노출(기획자 언어 위반, QA '진행중') 정정
- ⚪ **TC_0011**: 시작/종료 "일시"(QA "일자")·생성 폼에 상태 선택 필드 없음(임시저장 기본 생성)
- ⚪ **TC_0018**: 취소 시 **네이티브 confirm** "저장하지 않은 변경사항이 있습니다. 이동할까요?" (QA "변경사항을 저장하지 않으시겠습니까?")
- ⚠ **mutation 미완료**: 종료일 달력 위젯이 자동화 클릭으로 구동 안 됨(매 클릭이 시작일에 할당) → 실제 생성→삭제 사이클 미완료. 폼 구조·검증은 확인. 실제 생성 검증은 수동 또는 다른 입력 방식 필요.
