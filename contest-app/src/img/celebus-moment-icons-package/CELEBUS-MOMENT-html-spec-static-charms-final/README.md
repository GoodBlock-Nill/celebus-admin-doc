# CELEBUS MOMENT — HTML Spec Static Charm Icons (Final)

This final package contains the seven static 3D charm icons explicitly specified in the attached icon specification HTML.

Included: `log-in`, `bell`, `image-off`, `clapperboard`, `upload`, `heart`, `trophy`.

Each icon is a 256×256 RGBA PNG with a transparent background and at least 12px alpha safe margin. The icons use the Hybrid 2.5D matte plastic/clay charm style with CELEBUS Violet primary color and restrained Coral accents.

The package does not include `share-2`, active/focused/pressed variants, notification-state variants, or the other line icons excluded by the HTML specification.

`manifest.json` includes measured alpha bounds, safe margins, hashes, and provenance. `contact-sheet-final-v2.png` is a preview only; its checkerboard is not embedded in the individual icon PNGs.
