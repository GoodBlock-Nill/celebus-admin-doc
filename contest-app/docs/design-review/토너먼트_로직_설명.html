모먼트 토너먼트 로직 설명

CELEBUS MOMENT의 토너먼트가 어떻게 작동하는지 — 유형, 플레이 방식, 집계, 수상, 진행 흐름을 한 문서로 정리했습니다. 기획·개발·운영·디자인 공통 참고용.

✦ 한눈에

형식

이상형 월드컵 — 아카이브의 공개 영상들이 자동 출전하고, 참여자는 1:1 대결을 이어가며 나의 우승작을 뽑습니다.

두 축

출처(팬영상 / 공식영상) × 보상(보상형 / 인기투표형) 두 축으로 구성됩니다.

집계

1순위 우승 비율, 2순위 1:1 승률. 무작위 대진으로 노출 기회를 통계적으로 공평하게.

수상

발표 시 팬인기상 · 아티스트인기상 · 최다업로드상 3종이 자동 계산됩니다.

1 축 ① 영상 출처 — 팬영상 / 공식영상

토너먼트는 어느 아카이브에서 여느냐로 겨루는 영상이 정해집니다. 그 아카이브의 공개 영상이 자동 출전합니다.

구분팬영상 토너먼트공식영상 토너먼트
배지 팬영상 공식영상 · (카테고리)
대상 팬 아카이브에 팬들이 올린 영상끼리 겨룸 V01D 공식 영상의 인기를 겨룸
대상 범위 해당 팬 아카이브 전체 전체 또는 특정 카테고리(V1DE0·AZIT·Shorts 등) 중 선택
최다업로드상 있음 (팬 업로더 대상) 없음 — 업로더가 공식(@v01d-ix) 단일이라 미부여
카테고리 스코프 — 공식영상 토너먼트는 "AZIT 인기 토너먼트", "Shorts 인기 토너먼트"처럼 카테고리 단위로 열어 같은 성격의 영상끼리 겨루게 할 수 있습니다. (전체로 열면 MV·무대·브이로그가 혼합)

2 축 ② 보상 유형 — 보상형 / 인기투표형

출처와 별개로, 우승 보상 유무에 따라 두 가지입니다. 플레이·집계·수상 방식은 동일합니다.

구분보상형인기투표형
배지 🎁 보상형 인기투표형
목적 우승작·업로더에게 실제 보상을 걸고 참여를 독려 보상 없이 순수하게 "이번 최고 영상"을 뽑는 재미
보상 관리자가 보상 내용을 기재 (예: 우승 업로더에게 V01D 응원봉 + 공식 SNS 소개). 앱에 표시, 지급은 운영이 수동 진행. 없음
두 축은 자유롭게 조합됩니다 — 예: 공식영상 · AZIT · 인기투표형, 팬영상 · 보상형.

3 플레이 방식 — 개인 랜덤 대진

참여자마다 서로 다른 무작위 대진표를 받아 1:1 대결을 진행합니다. "누구는 특정 영상을 못 봤다"는 편향을 줄이기 위한 설계입니다.

STEP 1
자동 출전
해당 아카이브의 공개 영상 전체가 자동으로 후보에 오릅니다. (나중에 올라온 영상도 소급 포함)
STEP 2
1:1 대결
무작위로 짝지어진 두 영상 중 더 좋은 쪽을 선택. 선택한 영상이 다음 라운드로.
STEP 3
나의 우승작
대결을 이어가 마지막에 남은 1개가 "나의 우승작"이 됩니다.
STEP 4
집계 반영
내 대진의 승/패·우승 결과가 전체 통계에 합산됩니다.
대진 크기는 2·4·8·16·32강(대결 수 1·3·7·15·31)만 유효합니다. 서버가 대진 구조와 "모든 후보가 이 아카이브 소속인지"를 검증해 조작을 차단합니다.

4 집계 로직 — 우승 비율 우선

순위는 두 지표로 정해집니다. 우승 비율이 1순위, 동률일 때 1:1 승률이 2순위입니다.

① 우승 비율 (1순위)

이 영상이 등장한 대진 중 몇 번 최종 우승했나. 등장 기회 대비 우승률이라 노출 편차에 공평.

우승 비율 = 최종 우승 수 ÷ 대진 등장 수
② 1:1 승률 (2순위)

개별 1:1 대결에서의 승리 비율. 우승 비율이 같을 때 순위를 가릅니다.

승률 = 1:1 승리 수 ÷ (승리 수 + 패배 수)
어뷰징 방지 — 집계에 반영되는 플레이는 신원당 이벤트별 최대 3회입니다. 초과 플레이는 허용되지만 통계에는 반영되지 않습니다.

5 3종 수상 (발표 시 자동 계산)

관리자가 발표하기를 누르면 서버가 아래 3종을 자동으로 계산해 확정합니다.

팬인기상

우승 비율 1위 영상. (동률 시 승률) 팬 참여 투표로 뽑힌 최고작.

아티스트인기상

V01D 멤버가 직접 픽한 영상 중 최다 득표작. 멤버 픽은 발표 전까지 비공개.

최다업로드상

해당 아카이브에 가장 많은 날 영상을 올린 참여자. (하루 1건 인정) ※ 공식영상 토너먼트는 제외

6 진행 흐름

진행중 (open)
참여자 플레이 가능. 멤버 픽·투표 집계 진행(비공개).
→
결과 발표 (announced)
3종 수상 자동 계산·공개. 멤버 픽 공개.
→
종료 (closed)
목록에서 비노출. 기록 보존.
보상형 마무리 — 발표 후 앱에 표시된 보상 내용을 기준으로 운영이 우승 대상에게 보상을 수동 지급합니다. (응원봉·굿즈 배송, 공식 SNS 소개 등)

7 관리자 운영 요약

  • 개최 — 아카이브를 선택하고 토너먼트명을 입력하면 그 아카이브의 공개 영상이 자동 출전합니다.
  • 유형 선택 — 생성 시 인기투표형 / 보상형 중 선택. 보상형이면 보상 내용을 텍스트로 기재합니다.
  • 발표 — [발표하기] 시 3종 수상이 자동 계산되어 앱에 공개됩니다.
  • 보상 지급 — 보상형은 발표 후 운영이 수동으로 보상을 전달합니다. (자동 지급 아님)
