CELEBUS MOMENT(V01D 전용 팬 영상 PWA)의 토너먼트 메뉴 전체 화면을 정리했습니다. 현재 구조·구성요소·개선 포인트를 검토하고, 브랜드 톤에 맞는 UI/UX 고도화 방향을 제안해 주세요. 문서 하단에 GPT 디자이너용 프롬프트가 포함돼 있습니다.

✦ 개요 · 화면 구조

토너먼트 메뉴는 하단 내비 [토너먼트] 탭으로 진입하며, 상단에서 [토너먼트][랭킹] 두 탭으로 나뉩니다.

토너먼트 메뉴 (/events) ├─ [토너먼트] 탭 ── 대회 목록 ── 대회 상세(인트로) ── 대결 플레이(1:1) ── 결과 │ └─ 랭킹 보기(standings) └─ [랭킹] 탭 ── ① 토너먼트별 랭킹 ② D10V 크리에이터 랭킹 ③ D10V Pick 토너먼트 = "이상형 월드컵": 참여자마다 무작위 1:1 대진 → 나의 우승작 선택 → 우승비율·승률 집계 두 축: 출처(팬영상/공식영상) × 보상(보상형/인기투표형)
검토 핵심 — 현재는 기능은 갖췄으나 정보 위계·대결의 손맛·랭킹의 시각적 매력·축하 연출이 약합니다. 팬덤(D10V)이 "재미있게 겨루고 자랑하고 싶은" 경험으로 끌어올리는 게 목표입니다.

1 토너먼트 탭 — 대회 목록

┌─────────────────────┐ │ [ 토너먼트 ][ 랭킹 ]│ ← 상단 탭 ├─────────────────────┤ │ 모먼트 토너먼트 🏆 │ │ 올라온 영상들로 겨루는│ │ │ │ ┌─────────────────┐ │ │ │🏆 AZIT 인기… 진행중│ │ │ │[공식영상·AZIT][인기]│ │ ← 배지 3~4개 │ │ 설명… │ │ │ └─────────────────┘ │ │ ┌─────────────────┐ │ │ │🏆 시즌2 진행중 │ │ │ │[팬영상][🎁보상형] │ │ │ │ ┌─보상 내용 박스─┐ │ │ │ └─────────────────┘ │ └─────────────────────┘

구성요소

  • 상단 탭 토너먼트 랭킹 — 활성=브랜드 그라데
  • 대회 카드: 제목 + 상태(진행중/결과 발표) + 배지 묶음
  • 배지: 출처 팬영상/공식영상·카테고리 · 보상 🎁 보상형/인기투표형
  • 보상형은 하단에 우승 보상 내용 박스(골드)

개선 포인트

위계카드 한 장에 배지가 3~4개 + 상태 + 설명 + 보상박스로 정보 과밀. 무엇을 먼저 보게 할지 위계 정리 필요(썸네일/대표 이미지 부재로 밋밋함).
매력대회 카드에 대표 비주얼(커버·참가 영상 썸네일 콜라주)이 없어 리스트가 단조로움. "이 대회 재밌겠다"는 유인 약함.
상태진행중/결과 발표 외에 마감 임박·참여 인원·내 참여 여부 같은 라이브 신호가 없음.

2 대회 상세 — 인트로(시작 전)

┌─────────────────────┐ │ ‹ 토너먼트 │ │ 🏆 시즌2 [🎁보상형]│ │ [팬영상] 부산 버스킹 │ │ ┌─🎁 우승 보상 ─────┐ │ │ │ V01D 응원봉 + SNS │ │ │ └───────────────────┘ │ │ 두 번째 대결! │ │ ┌───────────────────┐ │ │ │ ▶ 토너먼트 시작(2강)│ │ ← 메인 CTA │ └───────────────────┘ │ │ 이번 이벤트 투표 0/3 │ │ ┌───────────────────┐ │ │ │ 랭킹 보기 │ │ │ └───────────────────┘ │ └─────────────────────┘

구성요소

  • 헤더: 뒤로 · 트로피 참(3D) · 제목 · 유형 배지 · 출처/카테고리 · 스테이지명
  • 보상형: 우승 보상 박스(골드, Gift 아이콘)
  • 메인 CTA 토너먼트 시작 (N강) — N=참가 영상 수 기준 대진 크기
  • 잔여 투표 0/3 (집계 캡) · 랭킹 보기 보조 버튼

개선 포인트

기대감시작 화면이 정적임. 참가 영상 미리보기(썸네일 그리드)·참여자 수·상위권 미리보기 등으로 "지금 해보고 싶다"는 기대감 부여 여지.
설명"이상형 월드컵" 방식·규칙(1:1로 골라 우승작 뽑기, 3회 집계)을 처음 유저가 직관적으로 알기 어려움. 온보딩 힌트 필요.
보상보상형의 보상 매력을 더 강조(비주얼·"우승하면 받는 것") 가능.

3 대결 플레이 — 1:1 투표 핵심 화면

┌─────────────────────┐ │ [8강] 3 / 4 │ ← 라운드·진행 │ 둘 중 더 좋은 영상은? │ │ 영상 보고 골라주세요 │ │ ┌───────────────────┐ │ │ │ [ 영상 A 썸네일 ] │ │ │ │ ▶ │ │ │ │ 제목 A · @handle │ │ │ │ [ ✓ 이 영상 선택 ] │ │ │ └───────────────────┘ │ │ VS │ │ ┌───────────────────┐ │ │ │ [ 영상 B 썸네일 ] │ │ │ │ ▶ │ │ │ │ [ ✓ 이 영상 선택 ] │ │ │ └───────────────────┘ │ └─────────────────────┘

구성요소

  • 상단: 라운드 배지(8강) + 진행 3/4
  • 두 영상 세로 스택 + 가운데 VS
  • 각 타일: 썸네일→탭하면 재생(YouTube/TikTok), 제목·핸들, 이 영상 선택 버튼
  • 한 번에 하나만 재생(방금 동시재생 버그 수정 완료)

개선 포인트

손맛월드컵의 핵심인 "고르는 손맛"이 약함 — 선택 시 승자 확대/탈락 연출, 다음 대결 전환 애니메이션, 진행 게이지 등 게임적 피드백 부재.
비교세로 스택이라 동시 비교가 어려움. 나란히(좌우) 배치 or 상하 반화면 대결 구도 등 "맞대결" 구도 검토.
진행감몇 강 → 4강 → 결승까지의 여정 시각화(브래킷·진행 바)로 몰입 유도.
우승최종 "나의 우승작" 확정 순간의 축하 연출(컨페티·공유 유도) 강화.

4 랭킹 보기 — 대회별 순위(standings)

┌─────────────────────┐ │ 우승비율=우승 비율… │ │ ┌───────────────────┐ │ │ │1 [썸네일▶] 제목 │ │ │ │ 우승 67%·승률 67%│ │ │ └───────────────────┘ │ │ ┌───────────────────┐ │ │ │2 [썸네일▶] 제목 │ │ │ │ 우승 33%·멤버픽 1│ │ │ └───────────────────┘ │ │ (멤버는 아티스트 픽 │ │ 버튼 노출) │ └─────────────────────┘

구성요소

  • 순위 번호 + 썸네일(재생 오버레이, 클릭 시 영상) + 제목
  • 지표: 우승 비율(1순위) · 1:1 승률(2순위) · 멤버 픽 수
  • 멤버 로그인 시: 아티스트 픽 선택 버튼(비공개, 발표 시 공개)

개선 포인트

시각화순위가 텍스트 %뿐 — 1·2·3위 메달·포디움·바 차트 등 시각적 위계로 "탑랭커"를 돋보이게.
지표 이해"우승 비율 vs 승률" 두 지표의 의미가 유저에게 어려움. 시각적으로 직관화 필요.
공유내 우승작·상위권을 자랑/공유할 유인 없음.

5 결과 발표 — 3종 수상

┌─────────────────────┐ │ ┌─ 최종 결과 🏆 ────┐ │ │ │ 팬인기상 — 제목… │ │ │ │ 아티스트인기상 — … │ │ │ │ 최다업로드상 — @… │ │ │ └───────────────────┘ │ │ (그 아래 랭킹 목록) │ └─────────────────────┘

구성요소

  • 발표 시 자동 계산 3종 수상 배너 — 팬인기상·아티스트인기상·최다업로드상
  • 공식영상 토너먼트는 최다업로드상 제외

개선 포인트

연출수상이 텍스트 나열 배너뿐 — 시상식다운 수상작 카드·트로피·축하 모션으로 "발표의 순간" 강화.
수상자수상 영상/업로더를 썸네일·아바타로 보여주면 더 명확·매력적.

6 랭킹 탭 — 3개 랭킹

┌─────────────────────┐ │ [ 토너먼트 ][ 랭킹 ]│ │ 토너먼트별 랭킹 │ │ · 각 대회 → 순위 이동│ │ D10V 크리에이터 랭킹 │ │ 1 닉네임 3개 업로드│ ← 최다업로드(팬영상) │ 2 닉네임 2개 업로드│ │ D10V Pick │ │ 1 [썸네일] 제목 3회우승│ ← 최다우승(팬영상) │ 2 [썸네일] 제목 2회우승│ └─────────────────────┘

구성요소

  • 토너먼트별 랭킹 — 대회 리스트, 탭 시 그 대회 순위로
  • D10V 크리에이터 랭킹 — 팬영상 최다 업로드(닉네임 + 개수, 메달)
  • D10V Pick — 팬영상 최다 우승(썸네일 + 우승 횟수, 클릭 재생)

개선 포인트

아이덴티티크리에이터 랭킹에 아바타·프로필이 없어 밋밋. "누구인지" 각인 약함.
차별화3개 섹션이 비슷한 리스트 룩 — 각 랭킹의 성격(대회/사람/영상)이 시각적으로 구분되면 스캔성↑.
명예탑랭커를 위한 명예의 전당/뱃지/시즌 개념 등 확장 여지.

당신은 K-pop 팬 영상 플랫폼 "CELEBUS MOMENT"(밴드 V01D 전용, 모바일 세로 PWA)의 프로덕트 디자이너입니다.
아래 "토너먼트 메뉴"의 현재 화면 구조와 개선 포인트를 검토하고, 브랜드 톤에 맞는 UI/UX 고도화안을 제안해 주세요.

[제품 맥락]
- 토너먼트 = 이상형 월드컵: 참여자마다 무작위 1:1 대진으로 "나의 우승작"을 뽑고, 우승 비율·승률로 집계.
- 두 축: 출처(팬영상/공식영상) × 보상(보상형/인기투표형). 팬덤명은 D10V.
- 메뉴 구조: 상단 [토너먼트][랭킹] 탭.
  · 토너먼트 탭: 대회 목록 → 대회 상세(인트로) → 대결 플레이(1:1) → 결과 발표 / 랭킹 보기
  · 랭킹 탭: ① 토너먼트별 랭킹 ② D10V 크리에이터 랭킹(팬영상 최다업로드) ③ D10V Pick(팬영상 최다우승)

[핵심 개선 목표]
기능은 있으나 "정보 위계 · 대결의 손맛 · 랭킹의 시각적 매력 · 축하 연출"이 약합니다.
팬덤이 "재미있게 겨루고, 자랑하고 싶은" 경험으로 끌어올리는 것이 목표입니다.

[화면별 중점 검토 요청]
1. 대회 목록 — 배지 과밀(출처·유형·상태·보상) 정보 위계 정리, 대표 비주얼 부재로 단조로움 개선.
2. 대회 상세(인트로) — 시작 전 기대감(참가 영상 미리보기·참여자 수), 규칙 온보딩.
3. 대결 플레이(★핵심) — "고르는 손맛"(선택 연출·전환 애니메이션·진행 게이지·브래킷 여정), 1:1 맞대결 구도(세로 스택 vs 좌우 비교), 우승 확정 축하.
4. 랭킹 보기 — 1·2·3위 메달/포디움/차트 시각화, 두 지표(우승비율·승률) 직관화, 공유 유인.
5. 결과 발표 — 시상식다운 수상작 카드·트로피·축하 모션.
6. 랭킹 탭 — 크리에이터 아바타/프로필, 3개 섹션의 성격별 시각 차별화, 명예의 전당·시즌·뱃지 확장.

[브랜드/제약]
- 컬러: Violet #6C4DE6(주)/#4E2FC0/#F1EBFF, 그라데 #A855E8→#6C4DE6, Coral #FF7A6A(포인트).
- 시맨틱: 팬영상=그린, 보상=골드, 공식=바이올렛. 폰트 Pretendard.
- 모바일 세로, 하단 내비 고정, 3D 참(charm) 아이콘 사용 중. reduced-motion·다크 대비 고려.

[산출물 요청]
- 화면별 개선 방향(레이아웃·정보 위계·인터랙션·모션) 제안.
- 특히 "대결 플레이"의 게임적 손맛 강화안을 우선순위로.
- 가능하면 와이어프레임/시안 또는 구체적 컴포넌트 스펙으로.
- 추가로 필요한 데이터/이미지(대표 커버, 아바타 등)가 있으면 명시.
