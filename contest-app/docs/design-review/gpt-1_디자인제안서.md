# 팬스테이지(FanStage) 디자인 개선 제안서

> 버전 1.0 · Mobile-first PWA · 390–430px 기준

## 0. 이해한 내용

팬스테이지는 일반적인 팬 영상 SNS가 아니라, **공연별로 관리되는 스테이지 아카이브 안에서 팬 영상을 공유하고 멤버의 실제 반응을 받는 서비스**다.

- 홈은 새로운 콘텐츠를 발견하는 곳
- 스테이지는 공연별 아카이브를 찾는 곳
- 영상 상세는 외부 영상과 멤버 반응에 집중하는 곳
- 올리기는 기존 YouTube/TikTok/Instagram 링크를 해당 스테이지에 등록하는 곳
- 핵심 감정은 “내 영상을 멤버가 봐줬다”는 자부심

표현 방향은 **밝은 라이트 클린 콘텐츠 앱 + 절제된 일렉트릭 인디고 포인트**다. 다크 배경, 네온 글로우, 과한 그라데이션, 극장·무대 은유는 사용하지 않는다.

## 가정

- 스테이지는 관리자만 생성한다.
- 멤버 계정은 검증된 계정이며 일반 팬 계정과 구분된다.
- 외부 플랫폼에서 썸네일·제목·플랫폼 정보를 가져올 수 있다.
- 로그인 없이 열람 가능하고, 하트·댓글·업로드·마이페이지만 로그인 후 사용한다.

# A. 정보구조(IA)

## A-1. 대안 비교

| 대안 | 구조 | 장점 | 단점 |
|---|---|---|---|
| 1. 스테이지 우선형 | 홈 → 스테이지 목록 → 스테이지 상세 → 영상 | 공연별 아카이브가 가장 명확하고 업로드 위치를 이해하기 쉽다 | 빠른 영상 소비에는 단계가 많다 |
| 2. 통합 피드 + 공연 렌즈 | 홈 통합 피드 → 공연 필터 또는 렌즈 | SNS처럼 빠르게 소비 가능하다 | 스테이지가 단순 필터처럼 보이고 필터 난립 문제가 반복된다 |
| 3. 하이브리드형 **권장** | 홈은 발견, 스테이지는 아카이브, 영상은 몰입 | 사용성·정보구조·콘텐츠 소비를 균형 있게 해결한다 | 홈과 스테이지의 역할 차이를 디자인으로 명확히 해야 한다 |

## A-2. 권장 하이브리드 구조

```text
홈
├─ 멤버가 봤어요
├─ 진행 중인 스테이지
├─ 최근 올라온 영상
├─ 월드컵 이벤트
└─ 명예의 전당 미리보기

스테이지
├─ 진행 중
├─ 보관됨
└─ 스테이지 상세
   ├─ 전체 영상
   ├─ 직캠
   ├─ 커버
   ├─ 편집
   └─ 기타

영상 상세 / 몰입 재생
├─ 외부 영상 임베드
├─ 멤버 반응
├─ 팬 하트
├─ 댓글
└─ 자랑 카드

월드컵
├─ 이벤트 목록
├─ 대결
├─ 나의 우승작
└─ 랭킹

명예의 전당
└─ 멤버 하트를 많이 받은 영상

마이
├─ 내 영상
├─ 멤버가 봐준 영상
└─ 내 댓글
```

## A-3. 현재 탐색 범위 유지

스테이지 상세에서 영상을 선택하면 영상 상세에서도 다음 범위를 유지한다.

```text
현재 범위
2026 여름 부산 버스킹 · 전체 · 최신순
```

규칙:

- 다른 공연 영상으로 갑자기 이동하지 않는다.
- 뒤로 가면 기존 스테이지와 스크롤 위치를 유지한다.
- 카테고리 변경은 현재 스테이지 안에서만 적용한다.
- 홈에서 영상을 누르면 해당 영상의 스테이지를 맥락으로 연결한다.

# B. 내비게이션·필터 최소화

## B-1. 하단 탭

```text
┌────────┬────────┬────────┬────────┬────────┐
│  홈    │ 스테이지 │  ＋   │ 월드컵  │  마이  │
└────────┴────────┴────────┴────────┴────────┘
```

| 탭 | 역할 |
|---|---|
| 홈 | 새로운 스테이지, 멤버 반응, 추천 콘텐츠 발견 |
| 스테이지 | 공연별 아카이브 탐색 |
| ＋ 올리기 | 스테이지·카테고리를 선택해 링크 등록 |
| 월드컵 | 진행 중 이벤트와 나의 결과 |
| 마이 | 내 영상, 멤버 반응, 내 댓글 |

명예의 전당은 홈의 주요 섹션과 바로가기로 제공하고, 알림은 상단 우측 아이콘으로 둔다. 별도 하단 탭을 늘리지 않는다.

## B-2. 필터 원칙

전역에 다음과 같은 복합 필터 바를 만들지 않는다.

```text
공연 ▼  카테고리 ▼  인기 ▼  멤버 ▼  기간 ▼
```

대신 화면의 범위를 좁힌다.

- 스테이지 목록: `[진행 중] [보관됨]` + 필요할 때 검색
- 스테이지 상세: `[전체] [직캠] [커버] [편집] [기타]` + `최신순⌄`
- 명예의 전당: `[전체] [그랜드슬램]`

인기순·최신순·멤버 하트순은 필터가 아니라 정렬 메뉴로 처리한다.

## B-3. 정렬 바텀 시트

```text
정렬

○ 최신순
○ 팬 하트순
○ 멤버 하트순
○ 댓글순

                         [적용]
```

# C. 화면별 설계

## C-1. 홈

홈은 모든 영상을 섞어 보여주는 피드가 아니라 **다음 행동을 찾는 발견 화면**이다.

```text
┌──────────────────────────┐
│ 팬스테이지             ♡  │
│ 멤버가 봤어요             │
│ [영상 썸네일]             │
│ 주연 님이 봤어요          │
│ 2026 여름 부산 버스킹     │
│                          │
│ 진행 중인 스테이지     더보기 │
│ [부산 카드] [홍대 카드]    │
│                          │
│ 지금 진행 중인 월드컵      │
│ [부산 버스킹 베스트컷]     │
│                          │
│ 명예의 전당           더보기 │
│ [가로 영상 리스트]         │
└──────────────────────────┘
```

콘텐츠 우선순위:

- 로그인 사용자: 최근 멤버 반응 → 내가 참여한 스테이지 → 이벤트 → 최근 업로드 → 명예의 전당
- 비로그인 사용자: 진행 중 스테이지 → 인기 영상 → 이벤트 → 명예의 전당 → 로그인 유도

멤버 반응이 없는 사용자는 빈 상태만 보여주지 않고 탐색 가능한 콘텐츠를 제공한다.

## C-2. 스테이지 목록

```text
스테이지
공연별 영상 모아보기
[진행 중] [보관됨]

[대표 썸네일]
2026 여름 부산 버스킹
2026.07.20 · 영상 42개 · 업로드 가능

[대표 썸네일]
홍대 라이브 클럽 0628
2026.06.28 · 영상 18개 · 업로드 가능
```

스테이지 카드에는 대표 이미지 또는 썸네일 콜라주, 스테이지명, 날짜, 영상 수, 진행 상태, 업로드 가능 여부를 포함한다.

## C-3. 스테이지 상세

```text
‹ 스테이지
[대표 이미지]
2026 여름 부산 버스킹
2026.07.20 · 영상 42개
                         [영상 올리기]
[전체] [직캠] [커버] [편집] [기타]
최신순⌄

[영상 썸네일] [영상 썸네일]
♡ 24          ● 주연 님이 봤어요
```

- 기본은 2열 썸네일 그리드
- 영상 선택 시 몰입 재생으로 이동
- 필요하면 보기 방식 전환을 지원하되, 이것은 필터로 취급하지 않는다.
- 반응이 있는 카드만 메타 영역을 확장한다.

영상 카드:

```text
┌──────────────┐
│   썸네일       │
│       0:42    │
├──────────────┤
│ 제목 또는 팬명 │
│ ♡ 24  댓글 6  │
│ ● 주연 님이 봤어요 │
└──────────────┘
```

## C-4. 영상 몰입 재생

외부 임베드이므로 자체 플레이어처럼 과장하지 않고, 영상·반응·댓글에 집중한다.

```text
‹ 부산 버스킹 · 전체
[외부 영상 임베드]
팬명 또는 제목
@sora · 직캠

[주연 아바타] 주연 님이 봤어요
[민서 아바타] 민서 님이 봤어요

♡ 24       댓글 6       [자랑 카드 만들기]
멤버 댓글
[멤버 아바타] 주연 · 이 장면 정말 좋았어요
```

외부 임베드 기준:

- 원래 비율을 보존한다.
- YouTube 가로 영상은 16:9, TikTok·릴스는 9:16을 우선한다.
- 비율을 알 수 없으면 16:9 안에 레터박스를 둔다.
- 로딩 전에는 썸네일과 재생 버튼을 보여준다.
- 임베드 오류 시 `원본에서 보기`를 제공한다.

## C-5. 올리기

스테이지 상세의 영상 올리기에서 들어오면 스테이지를 자동 선택한다.

### 링크 입력

```text
영상 올리기
스테이지 [2026 여름 부산 버스킹 ›]
영상 링크
[YouTube, TikTok, Instagram 링크 붙여넣기]
[미리보기 불러오기]
```

### 정보 확인

```text
[영상 미리보기]
가져온 영상 제목
카테고리 [직캠] [커버] [편집] [기타]
표시 이름 [팬명]
□ 커뮤니티 가이드 확인
[등록하기]
```

검증 항목:

- 지원 플랫폼 여부
- 공개 링크 여부
- 중복 링크 여부
- 스테이지가 보관 상태인지 여부
- 카테고리 선택 여부

비로그인 상태로 올리기를 누르면 로그인 후 원래 선택한 스테이지로 복귀한다.

## C-6. 마이페이지

```text
마이페이지
[아바타] 팬명
가입일 · 참여 영상 12개
[내 영상] [멤버가 봐준 영상] [내 댓글]

[썸네일]
2026 여름 부산 버스킹
● 주연 님이 봤어요
멤버 하트 2 · 팬 하트 24
```

상단에는 큰 통계 대시보드보다 멤버 반응 여부를 우선한다.

## C-7. 명예의 전당

```text
명예의 전당
멤버 하트로 사랑받은 영상
[전체] [그랜드슬램]

1  [큰 썸네일]
   2026 여름 부산 버스킹
   멤버 하트 5개
   멤버 전원 하트
```

금색 왕관·글로우·과한 랭킹 효과는 사용하지 않는다. 그랜드슬램은 명확한 문구와 멤버 아바타 묶음으로 전달한다.

## C-8. 월드컵

이벤트 목록:

```text
월드컵
팬들이 직접 뽑는 이번 공연 베스트
[부산 버스킹 베스트컷]
16강 진행 중 · 참여 1,248명
```

대결:

```text
3 / 8 라운드
[영상 A 썸네일]   A 선택
         VS
[영상 B 썸네일]   B 선택
```

- 두 외부 영상을 동시에 자동 재생하지 않는다.
- 기본은 썸네일 비교다.
- 누른 카드만 외부 플랫폼에서 재생한다.
- 선택 완료 후 다음 대진으로 이동한다.

# D. 멤버 반응의 절제된 표현

## D-1. 반응 종류

| 반응 | 표현 |
|---|---|
| 팬 하트 | 하트 아이콘 + 숫자 |
| 멤버 하트 | 멤버 아바타 + `멤버 하트` |
| 멤버 댓글 | 멤버 아바타 + 검증 표시 + 상단 고정 |
| 그랜드슬램 | 멤버 아바타 묶음 + `멤버 전원 하트` |

## D-2. 피드 배지

```text
● 주연 님이 봤어요
```

또는:

```text
[주연 아바타] 주연 님 · 멤버 하트
```

권장 규격:

- 높이 24px
- 아바타 16px
- 배경 `#EEF0FF`
- 텍스트 `#3F40A8`
- 테두리와 그림자 최소화
- 카드당 대표 배지 1개 우선 노출

복수 멤버:

```text
[아바타 3개] 멤버 3명이 봤어요
[아바타 5개] 멤버 전원 하트
```

## D-3. 상세·알림

영상 상세에서 멤버 반응은 일반 좋아요보다 위에 둔다. 알림은 다음과 같이 단순하게 제공한다.

```text
[주연 아바타]
주연 님이 회원님의 영상을 봤어요
2026 여름 부산 버스킹 · 12분 전
```

새 반응은 작은 인디고 점으로만 표시한다. 클릭 순간의 짧은 하트 모션은 허용하지만 컨페티·전체 화면 글로우·폭발 효과는 사용하지 않는다.

# F. 근거와 기대 효과

## 1. 공연 단위 기억 구조

팬은 인기 영상 하나만 보는 것이 아니라 그날 공연에서 찍힌 영상들을 함께 찾아본다. 스테이지를 1급 객체로 유지하면 공연별 아카이브라는 차별점이 살아난다.

## 2. 범위를 먼저, 필터는 나중에

사용자가 지금 어떤 콘텐츠 범위를 보고 있는지 명확히 보여주면 선택 부담이 줄어든다. 스테이지 상세에서는 카테고리만 조작하고 정렬은 하나의 메뉴로 묶는다.

## 3. 모바일 콘텐츠 밀도

2열 썸네일, 영상 수, 카테고리, 멤버 반응을 함께 사용하면 한 화면에서 더 많은 영상을 비교할 수 있다. 빈 카드와 큰 여백을 줄인다.

## 4. 멤버 반응은 신뢰 정보

멤버 하트는 단순 인기 지표가 아니라 실제 멤버가 봤다는 인증 정보다. 큰 애니메이션보다 실제 멤버 아바타, 이름, 반응 종류가 더 강력하다.

## 5. 비로그인 열람은 성장 장치

공유 링크를 통해 방문한 팬이 즉시 스테이지와 영상을 볼 수 있어야 한다. 로그인은 하트·댓글·업로드·마이에 접근하는 순간 요청한다.

## 6. 외부 임베드의 제약 보완

자체 플레이어가 아니므로 재생 제어에는 한계가 있다. 대신 스테이지명, 카테고리, 팬명, 멤버 반응, 댓글을 안정적으로 제공해 서비스 맥락을 강화한다.
