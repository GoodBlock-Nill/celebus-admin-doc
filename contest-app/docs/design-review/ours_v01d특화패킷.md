## 3. V01D 특화 기회 영역 (검토·제안 요청)

아직 범용이라 V01D화할 여지가 있는 영역:

### 3.1 멤버 개별성
- 현재: 멤버는 아바타+이름으로만 구분. **멤버별 시그니처 컬러·프로필·필터 없음.**
- 검토: 멤버 5인의 **시그니처 컬러 체계**, **멤버 프로필/소개**, **"이 멤버가 반응한 영상"** 필터·모아보기가 필요한가? 밴드라 **파트(드럼·보컬·키보드·기타·베이스)** 를 활용할 여지?
- 참고(제안·공식 확인 필요): 목업에서 임시 배정한 컬러 — 유찬 #6C4DE6 / 주연 #F0407F / 케빈 #2F7BEF / 지섭 #E8A32B / 노스케 #12A89A. **공식 멤버 컬러가 있으면 그걸로 교체.**

### 3.2 팬덤 정체성 (디오브 / D10V)
- 현재: 팬은 CELEBUS 닉네임으로만 표시. **팬덤(디오브) 정체성 요소 없음.**
- 검토: 팬을 "디오브"로 부르는 카피, 팬 레벨/뱃지, D10V 슬로건("Dream In Our V01D") 활용?

### 3.3 콘텐츠 구조
- 현재: 공연(스테이지) → 영상 → 카테고리(직캠/커버/편집/기타).
- 검토: **멤버별**·**곡별**·**공연 유형(버스킹/라이브/단독)** 축을 추가할지? 밴드 특성상 "연주 파트별" 직캠 수요?

### 3.4 멤버 반응의 특별화
- 현재: "OO 님이 하트를 보냈어요" + 아바타(절제).
- 검토: V01D 멤버 반응을 더 특별하게(멤버 시그니처 컬러 적용, 멤버 친필/스탬프 느낌) 하되 **과하지 않게**. "V01D가 봤다"의 감정을 어떻게 절제되게 강화?

### 3.5 비주얼 정체성 (밴드 미학)
- 현재: 라이트·뉴트럴 + 바이올렛 포인트(범용적으로 깔끔).
- 검토: **밴드/라이브** 정체성(악기·무대·앰프·아날로그 질감 등)을 **절제된 수준**으로 가미할지, 아니면 지금처럼 콘텐츠(영상 썸네일)가 색을 내는 중립 유지가 맞는지?

### 3.6 보상·리텐션 (ix 연계)
- 검토: **V01D Pick 상위 영상**에 멤버 **싸인 포카/폴라로이드** 보상? 멤버 **시드 영상**(공식 제공)을 아카이브 시작점으로?

## 4. 검토 요청 (우선순위 매겨주시면 좋습니다)

1. **V01D 특화의 적정 강도** — 범용 유지 vs 강한 아티스트 테마. 어디까지가 "특화"이고 어디부터 "과함"인가?
2. **멤버 개별성** — 시그니처 컬러·프로필·멤버별 필터가 이 서비스에 필요한가? 밴드 파트를 어떻게 활용?
3. **팬덤(디오브) 정체성** — 넣는다면 어디에 어느 정도로?
4. **멤버 반응 표현** — V01D답게 특별화하되 절제 유지하는 방법
5. **비주얼** — 밴드 미학 가미 vs 중립 유지
6. **지금 가장 먼저 할 3가지** — V01D 특화 착수 우선순위

## 5. 유지해야 할 것 (디자인 시스템 — 이미 확정)

- 한/영/일 다국어, 모바일 390–430px 우선
