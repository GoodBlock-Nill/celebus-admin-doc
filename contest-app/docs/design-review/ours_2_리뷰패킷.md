# CELEBUS MOMENT — 디자인 검토 패킷 (GPT 디자이너용)

> 시각 자료(HTML 디자인 리뷰 덱)와 **함께** 전달하는 구조화 문서.
> 컨셉·데이터모델·화면별 상세·로직·오픈 이슈를 정리했습니다. 검토는 **디자인·플로우·컨셉** 중심으로 부탁드립니다.
> (보안/운영/배포 항목은 배포·SSO 연동 단계로 별도 보류 중)

---

## 0. 한 줄 요약

**CELEBUS MOMENT** — "Your moment. Their response."
팬이 찍은 순간(직캠·커버·편집)을 관리자가 만든 **공연별 스테이지**에 올리면, **아티스트 멤버가 실제로 보고 하트·댓글로 반응**하는 K-pop 팬 콘텐츠 플랫폼(모바일 PWA).

- 스택: Next.js 16 · React 19 · Tailwind v4 · Supabase · 한/영/일
- 현재 상태: 리디자인(라이트 전환 + CELEBUS 브랜드색) **배포·SSO 전 단계까지 완료**

---

## 1. 서비스 컨셉

- 핵심 감정: **"내 영상을 멤버가 봐줬다"**. 멤버의 시선이 곧 보상.
- '무대/극장' 은유는 **폐기**(초기 방향에서 전환). 소셜 콘텐츠 감각(유튜브/인스타/틱톡 친숙).
- 멤버 반응은 **절제**(검증배지 스타일). 글로우·컨페티 없음.

### 핵심 루프
```
관리자: 스테이지(공연 아카이브) 개설
  → 팬: 링크 붙여넣기로 영상 업로드
  → 팬들: 둘러보고 좋아요·댓글
  → 멤버: 하트·댓글로 실제 반응
  → 알림: "주연 님이 회원님의 영상을 봤어요"
  → 명예의 전당 / 월드컵 인기투표 + 시상
```

## 3. 디자인 시스템 (토큰)

Tailwind v4 `@theme`. 컴포넌트는 시맨틱 토큰만 참조 → 토큰 교체로 전면 반영.

| 토큰 | 값 | 용도 |
|------|-----|------|
| `bg` | `#F7F7FA` | 페이지 배경 |
| `card` | `#FFFFFF` | 카드·시트 |
| `fg` / `muted` / `subtle` | `#17171C` / `#686A76` / `#A6A7B2` | 본문·보조·희미 |
| `border` | `#E6E6ED` | 카드·구분선(큰 그림자 대신 1px + shadow-sm) |
| `primary` / `primary-strong` | `#6C4DE6` / `#4E2FC0` | CTA·활성·강조 텍스트 |
| `primary-soft` | `#F1EBFF` | 멤버 반응 배지·선택 칩 |

- 타이포: **Pretendard** — Display 24 / Title 19 / Subtitle 15 / Body 13–14 / Caption 11–12
- Radius: sm12 · md16 · lg22 · pill100 / Spacing 4단위 / 화면 좌우 16–18
- 모션: fade-up·sheet-up, reduced-motion 존중

---

## 4. 컴포넌트

- **버튼**: Primary(인디고 솔리드) / 그라데(올리기·워드마크 전용) / Secondary(뉴트럴)
- **세그먼트·필터 칩**: 활성=ink(검정), 비활성=흰 카드. 정렬은 칩이 아니라 **바텀시트**로 분리
- **멤버 반응 배지**: 작은 아바타 스택 + `primary-soft` 배경 + `primary-strong` 텍스트, 검증(✓) 마크
- **카드**: 흰 카드 + border + shadow-sm. 썸네일 위 배지만 다크 오버레이 허용
- **헤더**: 홈=2줄(윗줄 `‹CELEBUS`+언어 / 아랫줄 로고+알림), 비홈=로고+알림 한 줄
- **하단 탭**: 홈·스테이지·＋·이벤트·마이 (라우트 기반, 중앙 ＋=그라데)

---

## 5. 화면별 상세

각 화면은 **Loading·Empty·Error+재시도·NotFound·Auth(로그인 유도)** 상태를 모두 구현.

### ① 홈 (디스커버리) — `/`
- 태그라인 → **콘텐츠 히어로**(멤버 하트 최다 영상, 실제 썸네일 + "멤버 전원이 봤어요" 필) → **멤버가 봤어요**(최근 반응) → **진행 중인 스테이지** 레일 → **월드컵** 진입 → **명예의 전당** 미리보기
- 각 섹션은 데이터 없으면 자동 숨김. 전체 비면 통합 빈 상태.

### ② 스테이지 목록 — `/stages`
- 진행중/보관 세그먼트. 큰 카드(커버·제목·날짜·영상수·상태칩·"열어보기")
- 스테이지 = 관리자가 만든 공연별 아카이브임을 안내

### ③ 스테이지 상세 — `/stage/[id]`
- 제목·날짜·영상수 + "영상 올리기" · 카테고리 칩(전체/직캠/커버/편집/기타)
- **범위 표시**("스테이지명 · 전체") + 정렬(최신순) · 2열 그리드
- 영상 카드: 썸네일·카테고리·재생글리프·제목·핸들·좋아요 + **멤버 반응 라인**

### ④ 영상 상세 (몰입) — 모달
- 외부 임베드(YouTube/틱톡/인스타, 비율 보존) + 그랜드슬램 칩 + **멤버 하트 라인**
- 좋아요 · **자랑 카드**(공유 이미지) · 원본 보기 · 신고
- **댓글**: 멤버 댓글 하이라이트+상단고정+멤버 배지, 200자·1단 대댓글

### ⑤ 올리기 시트
- 스테이지 선택 → 링크 붙여넣기 → 미리보기(썸네일·플랫폼·제목) → 카테고리 → 게시
- "링크만 붙여넣으면 끝 · 멤버들이 봐요"

### ⑥ 이벤트 / 월드컵 — `/events`
- 진행 중 월드컵 + 명예의 전당(항상 채워진 탭)
- 월드컵: 이상형월드컵(1:1 대결 → "나의 우승작") · 우승비율·1:1승률 랭킹 · **3종 시상**(팬인기상·아티스트인기상·최다업로드상, 발표 시 자동 계산)

### ⑦ 명예의 전당 — `/hearts`
- 멤버 하트 받은 영상 2열 그리드(스테이지 상세와 동일 카드)

### ⑧ 마이페이지 — `/my`
- 프로필 · 통계(내 영상/멤버가 봤어요/멤버 전원) · 탭(내 영상·봐준 영상·내 댓글)
- 미로그인 시 로그인 유도, 빈 탭은 업로드 유도

## 6. 유저 플로우 & 접근 정책

- **열람은 로그인 없이 자유** (스테이지·영상·전당·이벤트). 공유 유입 루프 유지.
- **상호작용만 로그인 필요** (하트·댓글·업로드·월드컵 투표·마이) → 미로그인 시 **로그인 유도 모달**.
- 최종 운영에서 신원 쿠키는 CELEBUS SSO 로그인으로만 발급(익명 발급 폐지, W4 예정).

---

## 7. 로직 · 규칙 (요약)

- **데이터 2단계**: 스테이지(관리자) → 영상(팬, 항상 1스테이지 소속) → 카테고리
- **멤버 하트**: 멤버 계정만 가능(대행 없음). 전원 = 그랜드슬램
- **월드컵**: 스테이지 단위 이상형월드컵, 대진 구조 검증, **신원당 3회 집계 캡**
- **모더레이션**: 신고 누적 자동 숨김 (운영 큐는 배포 전 보완 예정)

## 8. 검토 요청 (우선순위 매겨주시면 좋습니다)

1. **디자인 시스템** — 토큰 위계·컬러 사용(보라 집중)·타이포·컴포넌트 일관성. 라이트 톤이 K-pop 팬덤에 적합한지
2. **브랜딩** — 로고락업·그라데 사용처·태그라인·보이스
3. **정보구조 & 플로우** — 스테이지 1급 객체·하단 탭·업로드/반응 루프
4. **멤버 반응 표현** — "봐줬어요" 절제 표현이 감정 페이오프로 충분한지/과한지
5. **화면별 디테일** — 밀도·여백·위계·빈/에러 카피
6. **개선 우선순위** — 지금 먼저 손봐야 할 3가지

### 우리가 아는 미해결/논의 필요 (미리 공유)
- '무대' 카피 잔존: `stage_heading("멤버에게 자랑하는 무대")`, `stage_submit("무대에 올리기")` 등 — '스테이지' 용어 유지 vs 컨셉 카피 교체 **미정**
- 콘텐츠 히어로/썸네일은 정적 목업에서 그라데 placeholder지만 **실앱은 실제 영상 썸네일** 렌더
- 레거시 콘테스트 화면은 W4 초기화 시 제거 예정(현재 다크, 미링크)
