## Q1. 콜드스타트 — 배포 시 콘텐츠가 0일 때

### 현재 동작 (검증)
- **완전 빈 상태**: "아직 열린 공연이 없어요. / 곧 만나요!" — CTA 없는 막다른 문구
- **공연 O, 영상 0**: 히어로·멤버 반응·V01D Pick 전부 숨김 → 빈 아카이브 레일만 노출. "첫 업로더" 유도 장치 없음
- 온보딩/how-it-works 미배선

### 페인포인트
- 텅 빈 피드 → 거부감("dead mall" 문제: 아무도 없는 가게엔 안 들어감)
- 첫 업로더의 심리적 부담: "아무도 없는데 내가 왜 먼저?"

### 성공한 앱들의 처리
1. **선(先) 씨딩**: 운영이 먼저 채워 "살아있는" 느낌을 만든다. TikTok 초기엔 크리에이터를 직접 섭외·업로드시켰고, Reddit은 운영진이 더미 활동으로 마중물을 부었다.
   - **CELEBUS 강점**: ix 미팅에서 멤버가 고화질 영상·직접 업로드 협조를 약속 → **멤버/공식 콘텐츠로 아카이브를 미리 채우면** 팬은 "이미 멤버가 있는 공간"에 참여하는 그림이 된다.
2. **빈 상태를 온보딩으로**: 빈 화면 = 가이드 + 첫 액션. "첫 주인공이 되어보세요" + 원탭 업로드(예시 링크 프리필).
3. **시작 미끼(시드 미션)**: "이번 주 첫 직캠 올리면 응모권 2배" 같은 초기 인센티브.
4. **협력 목표**: "팬덤 목표 N개 달성 → 멤버 스페셜 해금" — 경쟁 대신 협력 프레임(소규모 팬덤 친화).
5. **소셜프루프 공백을 서사로**: 좋아요 0이어도 "멤버가 곧 봐요" 기대감 카피로 공백을 스토리로 전환.

### 권장 (우선순위)
- **P0** 배포 전 **멤버·운영 시드 콘텐츠 10~20개** 확보(아카이브가 비지 않게)
- **P0** 홈/공연 **빈 상태를 "첫 업로더 유도형"**으로 교체(원탭 업로드 + 예시)
- **P1** **시작 챌린지**(첫 업로드 보상) — Q4와 연결
- **P1** 신규 한정 **how-it-works 3스텝** 홈 상단 배선(코드 자산 이미 존재)

## Q2. 컨셉 전달력 & 업로드 욕구

### 현재 (검증)
- 컨셉 전달 수단 = 태그라인 "Your moment. Their response." + 히어로 배지 "멤버 전원 하트"가 사실상 전부
- how-it-works 미배선 → **"올리면 멤버가 실제로 본다"는 핵심 훅이 암시적**
- 업로드 진입 = 하단 ＋(상시). 홈 상단 상시 CTA·가치제안 없음

### 평가
- 👍 태그라인·브랜드·라이트 UI는 명확하고 세련됨
- 👎 신규가 "이게 뭐 하는 앱?"을 3초에 못 잡을 수 있음. **차별점(멤버가 진짜 반응)**이 전면에 안 뜸
- 👎 "왜 올려야 하지?"의 보상(멤버 반응·공식 피처링·응모권)이 약하게 노출

### 권장
- 히어로 아래 **가치제안 1줄**: "내가 올린 영상, V01D 멤버가 직접 보고 하트를 남겨요"
- 신규 1회 **3스텝 온보딩**: 올리기 → 멤버가 봐줌 → 명예/보상
- **업로드 보상 명시**: 멤버 반응 알림 + **공식 채널 피처링 가능성**(ix 협의 자산) + 응모권

## Q3. 영상 브라우징이 Shorts/Reels처럼 간편한가

### 현재 (검증)
- 카드 그리드 → 탭 → **`/video/[id]` 단일 임베드 페이지** → 뒤로가기. **세로 스와이프 연속 피드 없음**
- 임베드 = YouTube/TikTok/IG **원본 플랫폼 iframe** → 인앱 자동재생·프리로드·제스처가 원본에 종속

### 평가
- Shorts/Reels식 "몰입형 세로 연속 스와이프"는 **아님**. 클릭-백-클릭 구조 → 체류↓ 이탈↑
- 임베드 모델의 구조적 한계(iframe autoplay/제스처 제약)

### 선택지
- **A. 몰입 피드 모드 신설(권장·경량판)**: 세로 풀스크린, 한 화면 1영상, 위/아래 스와이프로 다음·이전, 우측 액션 레일(하트·댓글·자랑). 원본 임베드는 API 파라미터로 무음 자동재생 등 최대한 활용.
- **B. 경량 개선**: 카드 인라인/호버 프리뷰, 상세에서 "다음 영상 추천"으로 꼬리물기.
- **C. 자체 호스팅 숏폼**: 완전한 Reels UX 가능하나 저장·저작권·비용 부담(파일럿 범위 밖).
- 결론: 파일럿은 **A의 경량판(세로 스와이프 피드 + 원본 임베드)** 우선 검토.

## Q4. 월드컵 컨셉은 적절한가 + 대안

### 현재 (검증)
- 이상형 월드컵(브래킷): 무작위 대진 → 1:1 → 나의 우승작 → 집계(신원당 3회) → 결과=우승비율/승률 + 멤버 픽 발표

### 평가
- 👍 K-pop 팬덤 친숙(스타 이상형 월드컵 문화), 단순 투표보다 재미·체류↑, 1:1이 선택 부담↓
- 👎 **콘텐츠 밀도 의존**(재미는 8~16강 필요) → 콜드스타트/소규모에서 빈약
- 👎 **집계 의미 약함**(신원당 3회 캡 → 가벼운 참여, 반복 동기 약함)
- 👎 **업로더 보상 연결 약함**(우승이 무엇을 주는지 흐림)
- 👎 앱 코어(멤버가 봐준다)와 **분리된 미니게임**처럼 존재

### 더 나은 방향 (핵심 원칙: 이벤트는 코어 루프를 강화해야 함)
1. **멤버 픽 위크(리추얼화)**: 매주 멤버가 그 주 베스트 팬영상을 직접 고르고 **공개 발표**. 팬은 후보 추천/응원. → 앱 코어(멤버 반응)와 직결, 밀도 낮아도 성립.
2. **베스트 모먼트 토너먼트(시즌제)**: 월드컵을 유지하되 **스테이크를 명확화** — 우승작을 **V01D 공식 채널·CELEBUS X에 피처링**(ix 협의 자산). "우승하면 멤버가 본다/공식에 걸린다" = 강력 동기.
3. **챌린지/미션 기반**: "이번 주 직캠 챌린지" 테마 → 제출 → 반응 → 상위 피처링. **콜드스타트(Q1)를 동시 해결**(빈 캔버스 완화 + 코호트 형성).
4. **협력 목표(콜렉티브)**: 팬덤 전체 하트 N개 → 멤버 스페셜 해금. 경쟁 대신 협력(소규모 팬덤 친화).
5. ~~예측/베팅형~~: 게임존과 컨셉 중복 위험 → 비추천.

### 권장 결론
- 월드컵은 **폐기보다 재프레이밍**. **챌린지(입구) → 토너먼트(경쟁·피처링 스테이크) → 멤버 픽(피처링 보상)** 3단 파이프라인으로 코어 루프에 정렬.
- 이 구조는 Q1(콜드스타트)·Q2(업로드 동기)·Q4(이벤트 재미)를 **한 번에** 끌어올린다.
