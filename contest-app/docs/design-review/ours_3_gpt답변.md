- **왜 ③ 제외**: GPT는 우리 실제 리포가 없고 문서(스크린샷·목업)만 가짐. "직접 수정"하면 실제 앱과 분리된 별도 HTML만 나와 결국 재구현 필요. → GPT는 **명세**까지만, 구현은 코드베이스 접근 가능한 에이전트(Claude Code)가.

- **단계적 대안**: 범위가 크면 GPT에게 ①·②만 먼저(가벼운 분석) 요청 → 범위 확정 후 ④명세 받기.
