# 참고 자료 패킷 — 팬스테이지(FanStage)

> `fanstage-design-brief.md`(의뢰서)와 **함께** 전달하는 배경 자료입니다.
> 디자이너가 서비스 맥락 · 정보구조 · 용어 · 현재 상태를 빠르게 파악하도록 정리했습니다.

---

## 1. 서비스 맥락 (한 장 요약)

- 팬스테이지는 K-pop 아티스트의 팬 콘텐츠 앱입니다. 팬이 직접 찍거나 편집한 아티스트 영상을 올려
  **최애 멤버에게 자랑**하고, **멤버가 실제로 그 영상을 보고 하트·댓글로 반응**하는 것이 핵심 루프입니다.
- 감정의 정점은 **"내 영상을 멤버가 봐줬다"**. 이 순간을 어떻게 자연스럽고 절제되게 전달하느냐가 디자인의 승부처.
- 팬은 영상을 **직접 업로드하지 않고**, 이미 유튜브/틱톡/인스타에 있는 **링크를 붙여넣어** 등록합니다.

### 핵심 사용 루프
```
① 관리자가 "스테이지"(공연) 생성
      ↓
② 팬이 그 공연의 자기 영상 링크를 해당 스테이지에 올림 (자랑)
      ↓
③ 다른 팬들이 둘러보고 좋아요·댓글로 평가
      ↓
④ 멤버가 영상을 보고 "멤버 하트" → 팬에게 알림 ("주연 님이 봤어요")
      ↓
⑤ 하트 많은 영상 = 명예의 전당 / 이벤트 기간엔 월드컵 인기투표 + 시상
```

---

## 2. 정보구조 & 데이터 모델

### 2-1. 2단계 계층 (가장 중요)
```
스테이지(공연 아카이브)           ← 관리자가 생성. 예: "2026 여름 부산 버스킹"
   └─ 영상(팬 업로드)             ← 항상 한 스테이지에 소속
         └─ 카테고리: 직캠 / 커버 / 편집 / 기타
```
- 스테이지는 **상시(진행중)** 상태로 열려 있고 업로드를 받습니다. 관리자가 **보관** 전환하면 열람만 가능(아카이브).
- ⚠️ 디자인 난제: 이 "공연별 아카이브" 구조를 살리면서도, 필터 난립 없이 둘러보기 편하게 만드는 것.

### 2-2. 반응 · 평가
| 요소 | 의미 |
|------|------|
| 좋아요(팬 하트) | 일반 팬의 반응. 계정당 1회 토글 |
| **멤버 하트** | **멤버 계정이 직접** 남기는 반응. 서비스의 핵심 가치. 대행 입력 없음 |
| 그랜드슬램 | 멤버 **전원**이 하트를 남긴 영상(최고 훈장) |
| 댓글 | 1단 대댓글. **멤버 댓글은 하이라이트 + 상단 고정** |
| 신고 | 누적 시 자동 숨김(운영 모더레이션) |

### 2-3. 이벤트 · 랭킹
- **월드컵 이벤트**: 한 스테이지의 영상들로 겨루는 **이상형 월드컵(1:1 대결 토너먼트)**. 각자 무작위 대진을 플레이하고 "나의 우승작"을 뽑음. 집계는 우승 비율·1:1 승률.
- **3종 시상**: 팬인기상(우승 비율) · 아티스트인기상(멤버 픽) · 최다업로드상(유효 업로드 일수).
- **명예의 전당**: 멤버 하트를 많이 받은 영상 모음.

### 2-4. 신원 · 접근
- **열람은 로그인 없이 자유**. 상호작용(하트·댓글·업로드·마이페이지)만 로그인 필요 → 미로그인 시 로그인 유도.
- 다국어(한/영/일).

---

## 3. 용어 사전 (화면 문구 기준)

| 용어 | 뜻 | 비고 |
|------|-----|------|
| 스테이지 | 관리자가 만든 공연별 영상 아카이브 | 앱 타이틀과 별개 개념 |
| 멤버 하트 | 멤버가 영상을 봤다는 반응 | "OO 님이 봤어요" / "봐줬어요" |
| 그랜드슬램 | 멤버 전원 하트 | |
| 자랑 카드 | 멤버 하트받은 영상을 외부 공유용 이미지로 | 바이럴 요소 |
| 명예의 전당 | 하트 많은 영상 모음 | |
| 월드컵 | 영상 인기투표 토너먼트 | 이상형 월드컵 형식 |

---

## 4. 현재 화면 인벤토리 (이미 구현된 기능)

- 홈(스테이지 목록 / 이벤트 탭)
- 스테이지 상세(공연별 영상 피드 + 카테고리 필터 + 업로드)
- 영상 상세(임베드 재생 + 멤버 하트 라인 + 좋아요 + 댓글 + 신고 + 자랑 카드)
- 올리기(링크 붙여넣기 → 미리보기 → 카테고리 → 게시)
- 월드컵 이벤트(대결 카드 → 나의 우승작 → 랭킹) / 명예의 전당
- 알림 / (마이페이지는 미구현 — 신규 설계 필요)
- 관리자: 스테이지·멤버·이벤트 관리(별도)

## 5. 디자인 방향 요약 (확정 / 폐기)

### ✅ 확정
- **밝은 라이트 클린 콘텐츠 앱** 톤. 유튜브/인스타처럼 훑기 좋고, 틱톡처럼 몰입 재생.
- 포인트 컬러 1색: **일렉트릭 인디고**(브랜드 보라 계승). 나머지는 뉴트럴.
- 멤버 반응은 **검증배지처럼 절제**된 표현(작은 아바타 + "멤버가 봤어요").
- 하단 탭 내비게이션. 올리기는 하단 중앙 ＋로 초간편.

### ❌ 폐기 (반복 금지)
- 다크 + 네온 글로우 + 보라→핑크→골드 그라데(= 흔한 AI 디자인).
- '무대/극장/스포트라이트' 은유를 앱 전체에 씌우는 것.
- 하나의 피드에 모든 영상 + 필터 난립.

### 참고 시안 (현재 진행 중인 라이트 방향 목업)
- 클린 라이트 v2 목업(권장 톤): *아트팩트 링크를 함께 첨부* — "이 톤은 유지하되 스테이지(공연) 구조와 필터를 개선해달라"고 요청.
- (폐기된) 다크 무대 컨셉 목업: 참고용. "이렇게 가지 말 것"의 예시.

## 6. 기술 제약 (디자인이 지켜야 할 선)

- 모바일 우선(뷰포트 약 390~430px), PWA.
- 영상은 **외부 링크 임베드**(유튜브/틱톡/인스타). 자체 업로드·자체 플레이어 아님.
- 링크 붙여넣기 기반 등록(수기 입력 최소화).
- 로그인 없이 열람 / 상호작용만 로그인.
- 다국어(한·영·일) 레이아웃 견고성(긴 텍스트 대응).

---

## 7. (선택) 아티스트 · 팬덤 컨텍스트

> 디자인 그라운딩용. 외부 공유가 꺼려지면 이 섹션은 빼고 전달해도 됩니다.

- 아티스트: **5인조 밴드**. 멤버가 악기·보컬 역할로 구성(드럼·리더 / 보컬 / 키보드 / 기타 / 베이스).
- 팬덤: 고유 팬덤명 보유. 멤버별 시그니처 컬러를 아바타·배지에 활용 가능.
- 톤앤매너: 밴드/라이브 공연 중심이라 "직캠·버스킹·라이브"가 주요 콘텐츠 소재.
