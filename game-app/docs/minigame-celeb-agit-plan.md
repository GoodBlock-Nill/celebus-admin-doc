## 1. 컨셉

**"V01D 멤버들이 놀러오는 나만의 아지트를 꾸미고, 매일 들러 멤버와 교류하는 코지 공간."**

- 동물의 숲의 본질은 4가지다: ① **매일 조금씩 변하는 일상 리듬** ② **꾸미기(자기표현)** ③ **수집(도감)** ④ **주민과의 정서적 교류**. 이 4개는 오픈월드 없이도 성립한다 — 본 기획은 이 4개만 정확히 이식하고 나머지(섬 전체·지형·낚시터 등)는 버린다.
- 주민 = **V01D 멤버 5인 NPC**. "최애가 내 방에 놀러와서 말을 건다"는 팬덤 게임만이 가진 대체 불가 훅으로, 원작의 '주민 애착'을 그대로 치환한다.
- 레이싱이 "실력·경쟁" 축이라면 아지트는 **"애정·표현·저리듬"** 축 — 경쟁 없는 안식처. 두 신작이 서로 다른 유저층을 커버한다.

### 주의: 메인 앱과의 영역 충돌 회피
- CELEBUS 메인 앱에 도감·기억저장소(아카이브)가 존재/예정이므로, 아지트의 수집은 **"가구·인테리어 도감"으로 한정**한다. 멤버 사진·영상·포카류 수집은 절대 다루지 않는다 (포카 컬렉션 기폐기 결정과 동일한 사유 — 메인 앱과 겹침).

## 2. 확정 전제 (현실성 검증)

| # | 판단 | 근거 |
|---|------|------|
| 1 | **2D 아이소메트릭(쿼터뷰) 채택, 3D 불필요** | 꾸미기 게임의 핵심은 렌더링이 아니라 배치 UX와 가구 아트 품질. 웹 2D는 저사양 폰까지 완벽 호환·오프라인 캐시 부담 최소. 포켓캠프조차 공간을 "캠핑장 한 판"으로 축소했다 — 웹은 더 축소가 정답 |
| 2 | **아트 물량이 최대 비용 변수** | 가구 스프라이트가 콘텐츠 그 자체. 런칭 볼륨을 명시적으로 캡(§6)하고, 이후 관리자 카탈로그로 점진 추가(기존 상점 카탈로그 운영 패턴 재사용) |
| 3 | **실시간 요소 불필요** | 원작 감성의 핵심인 '시간의 흐름'은 KST 일일 리셋·요일 이벤트로 충분히 재현(기존 데일리 체크인·미션 인프라 재사용). 실시간 동시 방문은 제외 |
| 4 | **경제·인벤토리는 서버 권위 기존 패턴 재사용** | 점수 게임이 아니라 조작(치팅) 표면이 작음. 구매·보유·배치 저장만 서버 검증하면 됨 — 기존 지갑·인벤토리 RPC 패턴과 동일 구조 |

## 3. 코어 루프

### 일일 루프 (5~10분, 하루 2~3회 접속 유도)
```
[아지트 입장]
 → ① 관리 3액션: 화분 물주기 · 우편함 열기 · 벼룩시장(오늘의 가구 3종) 확인
 → ② 멤버 방문 이벤트: 오늘의 방문 멤버(1명)와 대화 → 선물 or 부탁 들어주기 → 친밀도 상승
 → ③ (재화가 모이면) 가구 구매·배치 변경
 → 완료 보상 수령 → 퇴장 (또는 다른 게임으로)
```

### 중기 루프 (주 단위)
```
친밀도 레벨업 → 멤버 전용 가구·인테리어 테마 해금
 → 테마로 방 완성 → 방 자랑 카드 공유 (기존 공유카드 인프라)
 → 도감 수집률 상승 → 다음 테마 목표 설정
```

- **에너지·스태미나 없음.** 못 하게 막는 장치가 아니라 "내일 또 올 이유"(일일 리셋 콘텐츠)로 리텐션을 만든다. 원작 철학과 동일.

## 4. 핵심 시스템

### 4.1 아지트 (공간)
- 시작: **1룸(8×8 그리드)**. 확장: 친밀도·수집 마일스톤으로 **최대 2룸 + 야외 테라스**(런칭 범위).
- 배치 요소: 바닥재/벽지, 가구(그리드 스냅), 벽걸이, 소품(가구 위 스택 1단).
- 편집 모드: 탭해서 집기 → 드래그 배치 → 회전(4방향) — 모바일 터치 최우선 UX. 배치 저장은 서버.

### 4.2 멤버 NPC 교류
- 매일 KST 리셋으로 **오늘의 방문 멤버 1명** 결정(결정론 로테이션 + 친밀도 가중).
- 상호작용: 인사 대화(2~3문장) → 선택지 1회 → 선물하기(보유 가구·소품 중 1일 1회) or 부탁(간단 과제: "화분에 물 줘줘" 수준).
- **친밀도 5단계/멤버**: 단계별 해금 — 새 대화 풀, 전용 가구, 멤버 룸 테마(최종 단계).
- 대사는 멤버별 말투 컨셉을 잡아 작성하되, **실존 인물 발언 창작 리스크 관리**: 사전에 소속사(ix) 확인 필수 안건으로 등록. 1차는 안전한 일상·응원 톤으로 한정, 한국어 우선 작성 후 영/일 번역.

### 4.3 수집 (가구 도감)
- 도감 = 카테고리(가구/벽지·바닥/소품/멤버 전용) × 수집률 표시.
- 획득 경로: 벼룩시장(CP 구매, 일일 3종 로테이션) · 친밀도 해금 · 요일 이벤트 보상 · 미션 보상.
- 희귀도 3단(일반/레어/멤버 전용). **뽑기(가챠) 없음** — 팬덤 대상 확률형은 리스크 대비 이득 없음. 전부 명시 가격 또는 명시 조건 해금.

### 4.4 소셜 (비실시간 — 전략적 선택)
- **방 자랑 카드**: 현재 방 스냅샷 + 수집률 + 친밀도 뱃지 → 이미지 공유(기존 공유카드 파이프라인).
- **방 구경(2차)**: 링크로 타인 방 읽기 전용 방문 + 반응 남기기 — 반응은 **정형 스티커만**(하트·박수·"아늑해요" 등). 자유 텍스트 방명록은 모더레이션 표면을 만들므로 배제(스케치의 '텍스트 없는 시스템' 원칙과 동일).
- **실시간 동시 방문은 의도적으로 도입하지 않는다** (공통 전략 문서의 게임별 매트릭스 참조): 이 장르의 재미는 "내 공간을 보여주는 것"이지 "같은 순간에 함께 있는 것"이 아니다. 동물의 숲조차 방문의 핵심 가치는 구경·반응이며, 동시 존재는 비용 대비 기여가 낮다. 허브 내 실시간 수요는 스케치 파티룸·마블 룸·러시 라이브 고스트가 담당한다.
- **시즌 전시 이벤트(운영, 2차)**: "이달의 아지트" — 기간 내 방 스냅샷 출품 → 스티커 투표 → 우수작 홈 허브 전시. 동시 접속 없이 커뮤니티 이벤트가 성립하는 이 장르의 정답.

## 5. 하루 콘텐츠 리듬 (원작의 '시간' 이식)

| 리듬 | 내용 |
|------|------|
| 매일 | 방문 멤버 교체 · 벼룩시장 3종 교체 · 관리 액션 리셋 |
| 요일 | 주말 한정 가구 입고, 수요일 "멤버 단체 방문"(2명) 등 요일 시그니처 1~2개 |
| 시즌(운영) | 관리자 카탈로그로 시즌 가구 팩 투입(발렌타인·데뷔 기념일 등) — 별도 배포 없이 운영 가능하게 설계 |

## 6. 콘텐츠 볼륨 (런칭 최소 — 아트 물량 캡)

| 항목 | 수량 | 비고 |
|------|------|------|
| 가구·소품 | **60종** | 일반 40 / 레어 10 / 멤버 전용 10(멤버당 2) |
| 벽지·바닥 | 각 8종 | 조합 64가지 확보 |
| 멤버 NPC | 5명 | 스프라이트 2~3포즈 + 표정 차분(치비 스타일 — 실사 아님) |
| 대사 | 멤버당 30문장 | 친밀도 단계별 풀. 한국어 우선 |
| 공간 | 1룸 → 2룸+테라스 | 확장은 진행 보상 |

- 60종은 "부족해 보이기 직전"의 의도적 캡이다. 꾸미기 게임은 초기 볼륨보다 **주간 신규 입고의 지속성**이 생명 — 런칭 후 주 3~5종 추가를 운영 루틴으로 잡는 것이 60→120종 런칭보다 리텐션에 유리하다.

## 7. 경제 (기존 CP 통합)

| 획득 | 소비 |
|------|------|
| 일일 관리 액션 완료 보상(소액) | 벼룩시장 가구 구매 (일반 30~80 CP / 레어 150~300 CP) |
| 데일리 미션 풀에 아지트 미션 편입 | 벽지·바닥 |
| 요일 이벤트 보상 | (멤버 전용은 비매품 — 친밀도 해금) |

- **다른 게임과 지갑 공유가 핵심 시너지**: 퍼즐·레이싱에서 번 CP의 안정적 소비처가 아지트 가구가 된다. 현재 CP 경제의 가장 큰 약점(소비처 부족)을 해결하는 포지션.
- 판매(가구 되팔기)는 1차 제외 — 경제 역류 통로는 최소화.

## 8. 기술 검토

- **렌더링**: 2D 아이소메트릭, 일반 웹 렌더(캔버스 불필요한 수준). 가구 = 스프라이트 + 그리드 좌표. WebGL 미사용 → 최저사양 폰·저전력에서도 완벽.
- **저장 구조**: 방 상태 = 배치 배열(가구ID·좌표·회전) 서버 저장. 인벤토리·지갑·친밀도 전부 서버 권위(기존 RPC 패턴).
- **결정론 요소**: 방문 멤버·벼룩시장 로테이션은 KST 날짜 시드 결정론(기존 데일리 시드·미션 로테이션과 동일 기법) — 서버·클라 불일치 없음.
- **오프라인**: PWA 캐시로 방 열람은 오프라인 허용, 상호작용은 온라인 필수(서버 권위).
- **관리자 콘솔 확장**: 가구 카탈로그(추가/가격/노출 기간), 멤버 대사 관리, 벼룩시장 로테이션 확인 — 기존 관리자 페이지에 탭 추가.
- **무결성**: 점수 없음 → 리플레이 불필요. 구매·해금 조건만 서버 검증(이미 표준 패턴).

## 9. 아트 방향

- CELEB MATCH 톤(글로시 캔디·바이올렛 네온)을 **실내 코지 톤으로 번안**: 채도를 한 단계 낮춘 웜 파스텔 + 포인트 네온(아지트가 "밴드의 아지트"임을 네온 사인·앰프·포스터 소품으로 표현).
- 멤버 NPC는 **치비(2.5등신) 스타일** — 실사·정밀 캐리커처는 초상권·품질 리스크가 크고, 치비는 기존 별 마스코트와 톤 호환.
- 최대 물량인 가구 60종은 **스타일 가이드(팔레트·라인 두께·그림자 각도) 먼저 확정 → 배치 프리뷰용 목업 10종으로 승인 → 양산** 순서로 제작(양산 후 톤 불일치 재작업이 최악의 낭비).

## 10. 제외 범위와 사유 (정직한 스코프)

| 제외 | 사유 |
|------|------|
| 오픈 맵·섬 탐험·지형 편집 | 웹 성능·제작량 비현실적. 아지트 공간 집중이 원작 감성 재현에 더 유리 |
| 낚시·곤충채집 등 필드 미니게임 | 별도 게임 수준의 공수. '부탁 들어주기'로 상호작용 욕구만 이식 |
| 실시간 동시 방문·채팅 | 실시간 서버 + 모더레이션 부담. 비실시간 방문+하트로 대체(2차) |
| 확률형 뽑기 | 팬덤 대상 리스크. 전 아이템 명시 가격/조건 |
| 멤버 음성·실사 이미지 | 권리 확인 전 미사용. 치비+텍스트 대화로 시작, ix 협의 후 확장 |

## 11. 마일스톤

| 단계 | 산출물 | 게이트 |
|------|--------|--------|

## 12. 리스크와 완화

## 13. KPI (베타 기준)

- 일일 관리 루프 완료율 ≥ 60%
- 방 편집 세션당 배치 변경 ≥ 5회 (꾸미기 재미 지표)
- 친밀도 1단계 도달률(가입 7일 내) ≥ 50%
- 방 자랑 카드 공유율 ≥ 8%
- D7 리텐션 ≥ 25% (코지 장르는 D1보다 D7이 본질 지표)

## 14. 오픈 이슈 (사용자 결정 필요)
