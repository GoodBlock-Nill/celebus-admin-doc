## 1. 품의 제목

**CELEB 게임 서비스 데이터베이스(Supabase) Pro 요금제 전환 승인의 건**

## 2. 기존 사용 요금제

- **Free 플랜 (무료)**
- 주요 한도: DB 500MB · 실시간 동시접속 200 · **백업 미제공** · 로그 보존 1일

## 3. 변경할 요금제

- **Pro 플랜 — 월 $25 (약 3.5만 원)**
- 주요 제공: DB 8GB · 실시간 동시접속 500 · **일일 자동 백업 7일 보관** · 로그 보존 7일 · 컴퓨트 크레딧 $10/월 포함
- 예상 외 과금 방지를 위해 **지출 상한(Spend Cap) 설정** 적용 예정 → 월 고정 $25 초과 없음

## 4. 상세 사유 및 활용 계획

### 사유

1. **백업 부재 해소 (핵심 사유)**
   현재 CELEB MATCH는 실사용자가 이용 중인 라이브 서비스로, 유저 포인트(CP)·게임 기록 등 자산 데이터가 **백업 없이** 운영되고 있음. 장애·작업 실수 발생 시 복구 수단이 없어, 일일 자동 백업 확보가 시급함.

2. **데이터 증가 대비**
   부정행위 방어용 게임 기록(리플레이 로그)이 상시 누적되는 구조로, 신규 미니게임 출시 시 무료 한도(500MB) 초과가 예상됨.

3. **신규 미니게임 멀티플레이 기반 확보**
   신작 4종(CELEB 스케치·마블·러시·아지트)의 멀티플레이(초대 방·정기 이벤트)가 Supabase 실시간 기능을 전제로 설계됨. 이벤트 시간대 동시접속 집중에 대비한 여유 확보 필요.

### 활용 계획

- 운영(프로덕션) 프로젝트를 Pro로 전환하고 일일 백업 즉시 활성화
- 무료 프로젝트 1개를 **개발·테스트 전용으로 분리** 운영 → 운영 DB에 직접 실험하던 구조를 개선해 장애 원인 자체를 차단 (추가 비용 없음)
- 신규 미니게임 개발 시 실시간 기능(초대 방 멀티플레이)을 Pro 기반으로 구축
