# CELEB MATCH · 스페셜 블록 디자인 의뢰서 (GPT 이미지 생성용)

새로 추가된 **스페셜 블록 2종**(가로 스트라이프 / 세로 스트라이프)의 아트를 GPT(이미지 생성)로 제작하기 위한 의뢰서입니다.
기존 스페셜 블록(`sp-area`, `sp-color`)과 톤·질감을 통일하는 것이 핵심입니다.

---

## 무엇을 만드나

기존 4매치는 십자(가로+세로) 스페셜 하나였는데, **방향 구분(가로줄/세로줄)** 으로 나뉘면서 두 블록이 새로 필요합니다.

| 블록 | 생성 조건 | 발동 효과 | 파일명 |
|------|-----------|-----------|--------|
| **가로 스트라이프 (lineH)** | 블록 4개 **가로 일렬** | 그 **행(가로 한 줄)** 전체 제거 | `sp-lineH.png` |
| **세로 스트라이프 (lineV)** | 블록 4개 **세로 일렬** | 그 **열(세로 한 줄)** 전체 제거 | `sp-lineV.png` |

---

## 사용법

1. ChatGPT(이미지 생성)에 **기존 아트를 참고 이미지로 첨부**한다.
   - `game-app/public/tiles/sp-area.png`
   - `game-app/public/tiles/sp-color.png`
   - (선택) 스타일 시트 한 장: 팀 참고용 스타일 시트 아티팩트
2. 아래 **[공통 스타일]** + **[블록 ①]** 을 함께 붙여넣어 1장 생성.
3. 이어서 **[공통 스타일]** + **[블록 ②]** 로 1장 더 생성(페어).
4. 두 장이 방향만 다르고 나머지는 동일해야 함 → 어긋나면 한 장 기준으로 "이것과 방향만 바꿔서" 재요청.

---

## [공통 스타일] — 두 블록 공통 지침

```
K-pop 감성 캐주얼 매치3 퍼즐 게임의 "스페셜 블록" 아이콘을 만들어줘.
첨부한 두 이미지(sp-area, sp-color)와 완전히 동일한 아트 스타일·톤을 유지해야 해:

- 형태: 모서리가 둥근 정사각형(rounded square) 블록 하나가 프레임을 꽉 채움.
  블록 바깥(둥근 모서리 밖)은 투명 배경.
- 배경: 부드러운 라일락/연보라 그라데이션에 유리처럼 반짝이는 베벨 테두리(밝은 하이라이트 림).
- 재질: 광택 있는 3D 젤리/캔디 질감, 말랑하고 프리미엄한 느낌.
- 글로우: 네온 라이트 글로우 액센트(오렌지·골드·화이트).
- 방향 표현: 흰색 점선 화살표로 "터지는 방향"을 직관적으로 표시
  (참고: sp-color는 안쪽으로 모이는 화살표).
- 정중앙 배치, 텍스트·글자·워터마크 없음, 카메라 정면 top-down 뷰.
- 배경 투명(PNG), 정사각 1:1.
```

## [블록 ①] 가로 스트라이프 · lineH (행 제거)

```
효과: "가로줄(행) 전체를 터뜨리는" 블록.

- 중앙에 광택 캔디(연보라 별/꽃 모양) 위로 선명한 가로 방향 줄무늬(스트라이프)를 넣어줘.
- 캔디를 관통하는 밝은 가로 네온 광선 빔(왼 → 오른쪽)이 좌우로 뻗어나가는 연출.
- 좌우 양옆을 향한 흰색 점선 화살표 2개(← →)로 "가로로 터진다"를 표시.
- 세로 요소는 넣지 말 것(세로 버전과 확실히 구분되게 가로 방향만 강조).
```

---

## [블록 ②] 세로 스트라이프 · lineV (열 제거)

```
효과: "세로줄(열) 전체를 터뜨리는" 블록. ①과 한 세트로 보이되 방향만 다르게.

- 중앙 캔디 위로 선명한 세로 방향 줄무늬(스트라이프).
- 캔디를 관통하는 밝은 세로 네온 광선 빔(위 ↕ 아래)이 상하로 뻗어나가는 연출.
- 위아래를 향한 흰색 점선 화살표 2개(↑ ↓)로 "세로로 터진다"를 표시.
- 가로 요소는 넣지 말 것. ①과 배경·캔디·글로우 톤은 동일, 방향만 90° 다르게.
```

## 기술 규격 / 후처리

- **최종 파일**: 투명 배경 PNG, 정사각.
  GPT가 1024로 생성하면 → **256×256으로 축소** 저장(기존 스페셜 아트가 256×256).
- **파일명**: `sp-lineH.png`(가로), `sp-lineV.png`(세로).
- **페어 일관성 필수**: 두 장이 배경·캔디·질감은 똑같고 **방향(가로/세로)만 다르게** 보여야 함.

## 완성 후 연결

1. 완성 파일을 아래 경로에 넣는다.
   - `game-app/public/tiles/sp-lineH.png`
   - `game-app/public/tiles/sp-lineV.png`
2. 코드 슬롯 `specials.lineH` / `specials.lineV` 에 경로를 연결하면 자동 반영(현재는 비어 있어 임시 CSS 오버레이 표시).
   ⚠️ 파일이 없는 상태로 먼저 연결하면 깨진 이미지가 뜨므로, **아트 완료 후 연결**.
