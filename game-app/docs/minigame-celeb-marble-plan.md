## 1. 컨셉

**"V01D의 월드투어를 따라 도시를 돌며 공연장을 세우고, 최고의 투어 프로듀서가 되는 8~12분 보드게임."**

- 부루마블의 "세계여행" 테마는 K-pop 밴드의 **월드투어**와 1:1로 치환된다. 장르 문법을 억지로 비트는 게 아니라 자연스럽게 겹치는 드문 케이스:
  - 도시 매입 → **투어 도시 개척** (서울·도쿄·방콕·파리·런던·뉴욕·LA…)
  - 건물 업그레이드 → **공연장 업그레이드**: 버스킹 → 라이브클럽 → 아레나 → 스타디움
  - 통행료 → **티켓 매출** (상대가 내 공연 도시에 멈추면 관람료 지불)
  - 황금열쇠 → **스타 카드** (투어 이벤트: 앵콜 요청, 장비 고장, 팬미팅 대박…)
- 허브 내 포지션: 퍼즐(두뇌)·레이싱(반사신경)·아지트(애정)에 이어 **"운+전략, 한 판의 드라마"** 축. 역전과 파산의 서사가 있는 유일한 게임.

### 명칭·표현 주의 (법적 리스크 선제 차단)
- 게임명 **CELEB 마블** 확정 (CELEB 시리즈 패밀리 네이밍). "부루마블"(씨앗사)·"모두의마블"(넷마블)은 **상표** — 마케팅 문구에서도 사용 금지. "마블" 단독은 장르 통용어이나 결합상표 등록 가능성 확인을 위해 **출시 전 KIPRIS 상표 검색 필수**(오픈 이슈).
- 게임 **룰(메커니즘) 자체는 저작권 보호 대상이 아니지만**, 보드 디자인·칸 명칭·카드 문구 등 **표현 요소는 전부 자체 제작**한다(황금열쇠→스타 카드 등 명칭도 전부 치환).

## 2. 확정 전제 (리서치·실측 근거)

| # | 확인된 사실 | 기획 반영 |
|---|------------|-----------|
| 1 | **모두의마블은 12턴·20분 제한 + 종반 6턴부터 통행료 1.5배 가속**으로 수렴. 원래 30턴이었으나 장기전 문제로 압축 ([모두의마블 규칙](https://namu.wiki/w/%EB%AA%A8%EB%91%90%EC%9D%98%EB%A7%88%EB%B8%94%20for%20kakao/%EA%B7%9C%EC%B9%99)) | 이 장르의 모바일 정답은 "턴 캡 + 종반 가속". 본 게임은 더 짧게 **10턴 + 종반 3턴 티켓 1.5배** (목표 8~12분) |
| 2 | **실시간 랜덤 매칭은 현재 유저 풀에서 성립 불가** — 실측 일 방문 ~63명·활성 ~41명(관리자 대시보드). 4인 매칭은 동시접속 수백 명 이상에서만 대기열이 돈다 | 런칭은 **멤버 AI 3인과의 싱글 대전**. 빈 로비(매칭 실패)는 게임이 죽어 보이는 최악의 첫인상 — 유저 풀 확보 전 랜덤 매칭 금지 |
| 3 | 턴제 게임은 **결정론 검증이 구조적으로 쉬움** — 주사위 시드+턴 로그만 있으면 서버 재현 가능 | 기존 CELEB MATCH 리플레이 무결성 패턴을 가장 저렴하게 이식할 수 있는 장르 |
| 4 | 2D 세로 보드는 웹 표준 기술로 충분(WebGL 불필요) | 저사양 완벽 호환. 렌더링 리스크 없음 |
| 5 | 턴제+룰 기반 = **자동 시뮬레이션으로 밸런스 검증 가능** | 출시 전 AI끼리 수천 판 자동 대국 → 파산율·역전율·평균 판 길이를 데이터로 튜닝 (감이 아닌 수치 밸런싱) |

## 3. 코어 루프

```
[홈 허브] → 대국 시작 (나 + 멤버 AI 3인)
 → 턴 진행: 주사위 → 이동 → 칸 이벤트 (매입/업그레이드/티켓 지불/스타 카드)
 → 10턴 종료 or 파산 or 독점 달성 → 정산 (총 자산 순위)
 → 결과: 승점·미션 진행·주간 랭킹 반영 → 재대국 or 홈
```

- **한 판 8~12분** — 허브에서 가장 긴 게임임을 인정하고, "점심시간 한 판" 포지션으로 명시. 60초 게임과 리듬이 다른 것이 오히려 라인업 다양성.
- 재도전 동기 = 주사위 운과 전략이 매판 다른 드라마를 만드는 장르 본연의 리플레이성 + 주간 승수 랭킹.

## 4. 룰 상세 (모바일 압축 설계)

### 4.1 보드 — 24칸 (원작 40칸 대비 압축)
| 구성 | 수량 | 내용 |
|------|------|------|
| 투어 도시 | 16칸 | 4개 대륙 라인 × 4도시 (라인 독점 시 티켓 2배) |
| 출발 | 1칸 | 통과 시 출연료 수령 |
| 스타 카드 | 3칸 | 이벤트 카드 드로우 |
| 휴가 | 1칸 | 1턴 휴식 (원작 무인도 치환, 3턴→1턴 압축) |
| 전세기 | 1칸 | 다음 턴 원하는 칸으로 이동 (원작 세계여행 치환) |
| 페스티벌 | 1칸 | 도시 하나를 골라 그 턴 티켓 2배 부스트 |
| 세금 | 1칸 | 보유 자산 비례 소액 납부 (자산 격차 완화 장치) |

### 4.2 진행 룰
- 주사위 2개, 더블 시 1회 추가 턴 (연속 더블 3회 = 휴가행 — 원작 유지).
- 공연장 업그레이드 4단계(버스킹→클럽→아레나→스타디움), 단계별 티켓 상승. 스타디움은 도시당 1개·비용 큼(하이리스크 하이리턴).
- **종반 가속**: 8~10턴차 티켓 1.5배 (모두의마블 검증 룰 이식 — 후반 긴장 유지·장기전 차단).
- 파산 = 즉시 탈락. **인수(상대 도시 빼앗기) 룰은 1차 제외** — 룰 복잡도를 낮추고 캐주얼 팬 이해선을 지킨다(오픈 이슈).

### 4.3 승리 조건 (3중)
1. 나 외 전원 파산
2. 한 대륙 라인 독점 + 전 도시 아레나 이상 (독점 승리 — 짜릿한 조기 종료)
3. 10턴 종료 시 총 자산 1위 (기본 종료)

### 4.4 스타 카드 — 30장 (런칭)
- 구성: 이득 12 / 손해 8 / 이동 6 / 상호작용 4 (상대 지정 이벤트).
- 문구는 전부 투어 세계관("앵콜 3곡! 다음 티켓 수령 시 +50%", "장비 파손… 수리비 지불").
- 카드 밸런스는 관리자 콘솔에서 수치 조정 가능하게 설계(기존 원격 설정 패턴).

## 5. 상대 — 멤버 AI 3인

- 매판 V01D 멤버 5인 중 3인이 상대로 등장(로테이션). **AI 전략 아키타입 3종**을 만들고 멤버에 배정:
  - 안정형(현금 보유·저위험) / 공격형(적극 매입·업그레이드) / 기회형(카드·전세기 활용 극대화)
- 멤버↔아키타입 매핑과 대사 톤은 **실존 인물 성격 규정 리스크**가 있으므로 ix 확인 안건(§13). 1차는 게임 행동만 차등, 성격 서사는 넣지 않는다.
- AI 품질 기준: "이길 만하지만 만만하지 않게" — 자동 시뮬레이션에서 **플레이어 기대 승률 35~45%** (4인전 균등 25%보다 유리하게 튜닝: 팬게임은 이기는 재미가 우선, 단 항상 이기면 지루).

### 6.1 프라이빗 룸 상세 (2차 — 설계 선반영)

이 장르는 원형이 멀티 게임이므로, 2차의 본 모드가 **게임의 완성형**이다. 1차 AI전 설계 시점부터 아래를 전제로 구조를 잡는다(후행 개조 방지).

| 항목 | 설계 |
|------|------|
| 인원 | 2~4인. 빈 자리는 멤버 AI가 채움(3인 초대 실패 시에도 4인 대국 성립 — 초대 부담 완화) |
| 동기화 | Supabase Realtime 턴 상태 브로드캐스트(턴당 수 회 — 턴제라 저빈도로 충분). 주사위·정산 확정은 서버 권위(중계와 권위 분리) |
| 이탈·AFK | 공통 표준: 턴 타이머 30초 → 자동 행동, 2연속 시 **AI 대체**(대국은 계속됨), 방 유지 시간 내 재입장 복귀 |
| 랭킹 | **주간 경쟁 랭킹 미반영**(담합 방지 — 공통 표준). 미션·재미 전용. 토너먼트는 별도 이벤트 랭킹 |
| 게스트 | 링크 관전 허용, 착석은 로그인 필수 |

- 1차 구현 시 선반영 사항: 룰 엔진의 상태를 **직렬화 가능한 턴 로그**로 설계(§9 시뮬레이터와 동일 요건이라 추가 비용 없음) — 이것이 곧 실시간 동기화 페이로드가 된다.

## 7. 경제 (사행성 선제 차단)

- **인게임 머니(투어 머니)는 판 안에서만 존재하고 판이 끝나면 소멸.** CP와 완전 분리.
- **CP 베팅·판돈 절대 금지** — 주사위 게임에 실질 재화를 걸면 사행성 이슈가 된다. 팬덤 서비스에서 이 선은 넘지 않는다.
- CP 보상은 기존 문법 그대로: 데일리 미션 풀 편입("투어 대국 1판", "독점 승리 1회") + 주간 랭킹 보상(기존 스케일).
- 모두의마블식 과금 모델(다이스 뽑기·캐릭터 강화)은 **전부 배제** — 확률형 없음 원칙(아지트와 동일).

## 8. 무결성

- **주사위 = 서버 발급 시드 결정론.** 대국 시작 시 매치ID+시드 발급 → 클라는 시드 기반 굴림 → 턴 로그(굴림·선택) 서버 저장 → 서버 리플레이 재현 검증. 기존 CELEB MATCH 패턴 그대로이며, 턴제라 검증 비용이 가장 낮다.
- "주사위 조작" 민원 대응: 결과 화면에 시드 공개 옵션(공정성 증빙) 검토 — 오픈 이슈.
- AI 판이므로 부정의 실익이 작지만, 주간 랭킹(승수·자산)이 보상과 연결되므로 검증은 유지.

## 9. 기술 검토

- **렌더링**: 2D 보드, 표준 웹 렌더. 말 이동·주사위는 CSS/경량 캔버스 연출. WebGL 불필요.
- **레이아웃**: 세로 화면에 정사각 보드 + 상단 자산 바 + 하단 액션 시트. 24칸 보드는 세로 화면에서 40칸보다 칸 크기 확보에 유리(압축의 부수 이득).
- **상태 관리**: 대국 상태는 클라 진행 + 종료 시 턴 로그 일괄 제출(AI전이라 실시간 서버 불필요). 프라이빗 룸(2차)에서만 실시간 채널 도입.
- **관리자 확장**: 카드 수치·티켓 배율·AI 승률 파라미터 원격 튜닝 + 대국 통계(평균 판 길이·파산율·승률) 대시보드.
- **시뮬레이터**: 룰 엔진을 UI와 분리 구현 → 헤드리스 자동 대국 수천 판으로 밸런스 리포트 생성(§2-5). 이 분리가 서버 리플레이 검증기와 코드 공유까지 해결한다(퍼즐의 클라/서버 공유 엔진 패턴과 동일).

## 10. 아트 방향

- CELEB MATCH 톤(글로시 캔디·바이올렛 네온) 유지. 보드는 "네온 투어 맵" — 도시칸은 랜드마크 미니 일러.
- 필요 에셋(런칭): 보드판 1 + 도시 타일 16 + 특수칸 8 + 스타 카드 일러 30(공용 프레임 + 아이콘 30으로 물량 압축 가능) + 공연장 4단계 아이콘 + 말 4종(멤버 심볼·치비) + 주사위/이동/파산·승리 연출.
- 아트 물량 중간 규모(아지트보다 적고 레이싱 3D보다 저렴). 카드 일러는 "프레임 공용+아이콘 차등"으로 30장을 아이콘 30개 수준으로 압축하는 것을 권장.
