## 1. 컨셉

**"제시어를 60초 안에 그려서 올리면, 다른 팬들이 그리는 과정을 리플레이로 보며 맞히는 비동기 그림 퀴즈."**

- 캐치마인드의 원형은 실시간 방(출제자+참가자 동시 접속)이지만, 이 장르를 **비동기로 성공시킨 검증 모델이 Draw Something**이다: 그림을 그려 보내면 상대가 나중에 맞힌다. 핵심 재미는 완성된 그림이 아니라 **"그려지는 과정"의 스트로크 리플레이** — 선이 하나씩 그어지며 "아! 알았다!" 하는 순간이 이 장르의 본질이고, 이것은 동시 접속 없이 완벽히 재현된다.
- 팬덤 훅: 제시어에 **V01D·음악 카테고리**(노래 제목, 악기, 무대 용어, 팬덤 밈)를 넣어 "팬이라서 맞히는" 그림 퀴즈가 된다. 잘 그린 그림보다 **못 그렸는데 맞혀지는 그림**이 웃음 콘텐츠가 되는 장르 — 그림 실력이 진입장벽이 아니다.
- 허브 내 포지션: 퍼즐(두뇌)·레이싱(반사신경)·아지트(애정)·월드투어(운+전략)에 이어 **"창작+유머, 팬들 사이의 상호작용"** 축. 유저가 콘텐츠를 만드는 첫 게임(UGC).

### 명칭
- 게임명 **CELEB 스케치** 확정 (CELEB 시리즈 패밀리 네이밍). "캐치마인드"는 넷마블 상표 — 마케팅 문구에서도 사용 금지.

## 2. 확정 전제 (리서치·실측 근거)

| # | 확인된 사실 | 기획 반영 |
|---|------------|-----------|
| 1 | **실시간 '랜덤 공개 방'은 현재 유저 풀에서 성립 불가** — 일 방문 ~63명 실측. 단, **초대 링크 파티룸은 유저가 상대를 데려오므로 규모와 무관하게 성립** (공통 전략 원칙①) | **비동기 구조가 기본 + 초대 파티룸을 1차 범위에 포함.** 랜덤 공개 방만 지표 게이트 뒤로 |
| 2 | **Draw Something이 비동기+스트로크 리플레이로 장르 성립을 증명** ([설계 분석](https://slate.com/technology/2012/03/draw-something-the-amazingly-addictive-guess-my-sketch-game.html)) — "무엇을 그렸나"가 아니라 "어떻게 그렸나"를 재생하는 것이 핵심 재미 | 그림은 이미지가 아닌 **스트로크 로그(벡터)**로 저장, 맞히기 화면에서 그려지는 과정을 재생 |
| 3 | 정답 입력은 자유 타이핑이 아닌 **글자 타일 조합**(Draw Something 방식) | 타이핑 마찰·오타 판정 문제 제거 + **한국어(음절 타일)/영어/일어 3언어 대응**이 구조적으로 해결됨 |
| 4 | **유저 제작 그림(UGC) = 모더레이션이 최대 리스크** | §6에 전면 설계. 자유 텍스트 입력을 시스템에서 원천 제거(제시어는 시스템 제공만 선택)해 리스크 표면을 "그림"으로만 한정 |
| 5 | 모바일 캔버스 드로잉·스트로크 재생은 표준 웹 기술로 충분(WebGL 불필요) | 기술 리스크 없음. 스트로크 로그는 이미지보다 저장 용량도 작음(수 KB) |

## 3. 코어 루프 (두 개의 맞물린 루프)

### 그리기 루프 (출제)
```
[그리기 시작] → 제시어 3개 중 1택 (난이도 ★~★★★)
 → 60초 드로잉 (펜·색 8·굵기 3·지우개·되돌리기)
 → 제출 → (검수 통과 후) 맞히기 풀에 공개
 → 내 그림 성적 알림: "7명 중 5명이 맞혔어요!" → 출제 점수 획득
```

### 맞히기 루프 (소비)
```
[맞히기 시작] → 풀에서 그림 배정 (본 적 없는 그림)
 → 스트로크 리플레이 재생 (배속 가능)
 → 글자 타일로 정답 조합 (시도 3회 · 힌트 사용 가능)
 → 정답! → 점수 + 다음 그림 (연속 플레이)
```

- **상호 보상 구조**(Draw Something의 협력 설계 계승): 맞힌 사람과 그린 사람이 함께 점수를 얻는다. 그린 그림이 많이 맞혀질수록 출제자 점수 상승 → "맞히기 쉽고 재밌게 그리는" 방향으로 자연 정렬(악의적 낙서의 동기 자체를 줄이는 인센티브 설계).
- **데일리 그림 퀴즈** (2026-08-19 확정·구현 — Draw Something 데일리 챌린지 + Drawception Top Games 벤치마크): 전일 맞히기 성적 상위 5장 **자동 선정**(한 번 선정된 그림 재선정 영구 금지), KST 리셋, 전원 동일 문제. **선정 작가 +20 CP**("내 그림이 뽑혔다" = 그리기 동기), 완주(내 그림 제외 전부 풀이) 보너스 +10 CP. 관리자는 부적절 선정 교체만.
- **주간 베스트 스케치** (2026-08-19 확정·구현 — §7 경쟁 랭킹 두 트랙을 대체): 지난주 데일리 선정작 중 누적 정답 수 최고 1장을 명예의 전당(스케치 홈)에 노출, **작가에게 드로우 티켓 1장**. 장르 표준(경쟁 랭킹 없음, 노출·명예 보상)에 맞춘 결정 — 경쟁 축은 기존 매치 주간 랭킹이 담당.

## 4. 시스템 상세

### 4.1 드로잉 도구 (의도적 제한)
- 팔레트 8색 + 굵기 3단 + 지우개 + 되돌리기(3회) + 전체 지우기. 제한 시간 60초(제시어 난이도 ★★★는 90초).
- 도구를 제한하는 이유: ① 잘 그리기 대회가 아니라 전달력 게임 ② 스트로크 로그 단순화 ③ 저품질 기기에서도 균등한 조건.
- 텍스트·글자 그리기 금지 규칙(정답 글자를 쓰면 반칙) — 신고 사유 항목화. 자동 판별은 시도하지 않는다(비용 대비 오탐, 신고+검수로 처리).

### 4.2 제시어 (시스템 제공 — 자유 출제 없음)
| 카테고리 | 예시 | 비고 |
|----------|------|------|
| V01D·음악 | 기타, 앵콜, 응원봉, 무대, 드럼 스틱 | 팬덤 훅 카테고리 |
| 일상·사물 | 우산, 라면, 지하철 | 보편 |
| 동물·자연 | 고래, 무지개 | 보편 |
| 행동·개념(고난도) | 지각, 부끄러움 | ★★★ |

- 런칭 볼륨 **300개**(한국어 우선, 영/일 번역 병행). 관리자 카탈로그로 등록·수정(브랜드명·실존 인물명은 제시어에서 배제 — 초상·상표 리스크 차단).
- 출제 시 3개 제시(난이도 섞음) 중 1택 — 선택권이 그리기 부담을 낮춘다.

### 4.3 맞히기 입력 — 글자 타일
- **유저 언어별 타일 (2026-08-19 전면 개선 — 한 언어 타일을 전 유저에게 내보내던 결함 수정)**: 한국어=음절(10타일)·영어=알파벳(12타일, 대문자)·일본어=**가나(12타일)**. 한자 일본어 단어는 가나 읽기 데이터(약 130종)로 타일화, 판정도 가나 입력 허용. 더미는 실제 단어에 흔한 글자로 구성(정답이 티 나지 않게), 힌트·정답 공개도 유저 언어 기준.
- 시도 3회. 힌트: 첫 글자 공개(소액 CP 소모 — 가벼운 CP 소비처).
- 타일 세트는 서버가 생성해 배정(더미 구성이 클라 임의가 아니어야 난이도 공정).

### 4.4 콜드스타트 (비동기 UGC의 고전적 함정)
- 맞힐 그림이 없으면 루프가 죽는다. 대응:
  - ~~운영 시드 그림 50장~~ → **생략 확정 (2026-08-19)**: 벤치마크 전 게임이 시드 없이 유저 콘텐츠만으로 운영. 베타 중 실유저 공급이 이미 시작됐고 데일리 퀴즈가 소비를 견인 — 필요 시 오픈 주간 10장 내외만 운영 재량
  - 첫 진입 동선을 "맞히기"가 아닌 **"그리기 먼저"**로 유도(첫 그림 제출 보상) — 공급 우선 확보
  - 그림 1장은 여러 명이 맞힐 수 있으므로(1:N 소비) 공급 부담은 구조적으로 낮음

## 5. 소셜·바이럴

- **내 그림 성적표**: 정답률·맞힌 사람 수·"이 그림을 3초 만에 맞혔어요" 알림 — 출제자에게 돌아오는 재미.
- **그림 공유 카드**: 완성 그림+제시어 가리기 처리 → "이거 뭐게?" 이미지 공유(기존 공유카드 인프라). 링크로 열면 **비로그인 게스트도 맞히기 1회 체험** 후 가입 유도 — 허브 전체의 신규 유입 루프로 작동 가능.

## 5.5 파티룸 — 초대 링크 실시간 (1차 범위)

공통 멀티 전략 원칙①(초대 링크)·②(정기 이벤트 타임)의 첫 적용 게임. **스트로크 중계는 화이트보드 수준의 검증된 기술이라 허브 전체의 실시간 파일럿으로 최적.**

| 항목 | 설계 |
|------|------|
| 인원 | 3~8인 (2인도 시작 가능하되 3인+ 권장 안내) |
| 개설·입장 | 방 개설 → 초대 링크 공유(오픈채팅·커뮤니티) → 링크 입장. 랜덤 공개 방 없음 |
| 라운드 | 출제자 로테이션. 그리기 90초 — **그리는 과정이 전원에게 실시간 중계**, 나머지는 글자 타일로 경쟁 맞히기 |
| 점수 | 빨리 맞힐수록 가산 + 출제자는 맞힌 인원수 비례(비동기와 동일한 상호 보상 철학) |
| 라운드 수 | 인원×2 라운드(최대 16), 한 판 10~15분 |
| 이탈·AFK | 공통 표준(전략 문서 §5): 출제 차례 무응답 시 라운드 스킵, 재입장 허용, 전원 이탈 시 방 해산 |
| 랭킹 | **주간 경쟁 랭킹 미반영**(담합 가능 — 공통 표준). 재미·소셜 전용, 미션("친구와 1판")만 연동 |
| 기술 | Supabase Realtime 채널: 스트로크 브로드캐스트 + 프레즌스 + 정답 이벤트. 정답 판정·점수 확정은 서버 RPC(중계와 권위 분리) |
| 게스트 | 링크 입장 시 관전+맞히기 체험 허용, 점수·보상은 로그인 필수 — 파티룸 자체가 신규 유입 루프 |

- **정기 스케치 타임 → "호스트 쇼" 형태로 재정의 (2026-08-19, Gartic on Stream 벤치마크)**: 유저끼리 정해진 시간에 모이는 방식 대신, **호스트 1명(운영 계정·V01D 라이브 연계)이 그리고 전원이 맞히는 방송형 이벤트**. 파티룸(초대 링크, 본 절)은 원안 유지 — W3 설계에 반영.

## 6. 모더레이션 (이 게임의 최대 리스크 — 전면 설계)

| 장치 | 내용 |
|------|------|
| 리스크 표면 축소 | 자유 텍스트 입력이 시스템에 존재하지 않음(제시어 선택제·타일 입력) → 텍스트 유해물 원천 차단. 남는 표면은 **그림 하나** |
| **AI 1차 검수** (2026-08-19 확정 — 전수 사전 검수의 운영자 병목 해소) | 제출 즉시 스트로크 로그를 서버가 이미지로 렌더해 비전 AI가 판정: **정상 → 즉시 공개 / 의심(글자 감지·애매) → 보류 큐 / 명백 위반 → 자동 반려**. AI 장애·키 부재 시 보류 큐 폴백(공개가 멈출지언정 사고는 안 남). 글자 반칙 감지도 AI가 1차 수행 |
| 운영자 역할 | 전수 검수 아님 — **AI 보류 건 + 신고 누적 건만** 처리 (현 규모 주 수 건 예상). 검수 큐에 스트로크 리플레이 뷰어 내장 |
| 신고 + 임계 자동 비공개 | 맞히기 화면 신고(부적절·글자 반칙 2사유). **신규 출제자 그림 2회·신뢰 출제자(승인 10장+·비공개 이력 0) 5회** 누적 시 자동 비공개 → 운영자 사후 확인(승인=복구). Drawception 검증 모델(§14-2 벤치마크) |
| 제재 | 경고 → 그리기 기능 정지(맞히기는 허용) → 계정 제재. 기존 관리자 제재 체계 확장 |
| 증거 보존 | 스트로크 로그가 곧 증거(누가 언제 무엇을 그렸는지 재현 가능) + AI 판정 결과 저장 |
| 규모 확대 시 | AI 1차가 규모를 흡수하므로 별도 전환 불필요 — 신뢰 등급은 신고 임계 차등에만 사용 |

## 7. 경제 (기존 CP 통합)

- 획득: 데일리 미션 풀 편입("그림 1장 그리기", "N문제 맞히기" — 구현 완료) + 정답 상호 보상(정답자 +5·출제자 +3) + 데일리 퀴즈 선정 +20·완주 +10 + 주간 베스트 드로우 티켓 1장. ~~주간 랭킹 두 트랙~~ → **주간 베스트로 대체** (2026-08-19, §3 — 장르 벤치마크상 경쟁 랭킹은 이 장르의 리텐션 축이 아님).
- 소비: 힌트(첫 글자 공개) 소액 CP — 부담 없는 반복 소비처.
- 확률형 없음(허브 공통 원칙).

## 8. 무결성

- **정답 판정은 서버 RPC** — 클라이언트에 정답 평문 미전송. 시도 3회 제한 + 요청 빈도 제한(브루트포스 차단).
- 점수 적립(맞힘·출제 성적) 전부 서버 권위 — 기존 지갑·점수 패턴과 동일.
- 스트로크 로그 = 조작 검증·모더레이션 증거 겸용. 별도 리플레이 시뮬레이션이 필요 없는(물리·RNG 없음) 가장 검증 부담 낮은 장르.

## 9. 기술 검토

- **캔버스**: 표준 2D 캔버스 + 포인터 이벤트. 스트로크 = (색·굵기·좌표열·타임스탬프) 벡터 로그 → 재생은 로그 순차 드로잉. 저장 수 KB/장(이미지 업로드 불필요 — 썸네일만 서버 생성 또는 최초 재생 시 클라 렌더).
- **배정 로직**: "본 적 없는 그림 중 정답률 데이터가 적은 것 우선" — 새 그림에 노출 기회 보장(공급자 경험 보호).
- **관리자 확장**: 제시어 카탈로그(3언어), 검수 큐(리플레이 뷰어 포함), 신고 처리, 데일리 퀴즈 큐레이션, 출제/정답 통계.
- **아트 물량 최소**: 게임 자체가 유저 그림이 콘텐츠. 필요한 건 UI(캔버스 도구·타일)·결과 연출·시드 그림 50장뿐 — **5종 중 아트 비용 최저**.
